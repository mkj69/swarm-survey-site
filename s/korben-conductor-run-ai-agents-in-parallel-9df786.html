一句话

Conductor 把多 agent 编程组织成隔离工作区与人工审阅流程，但本文没有证明并行能带来多少效率提升。

主要内容

  • Korben 介绍：Conductor 是 Melty Labs 开发的 macOS 应用；应用免费，模型使用费用另付。
  • 支持 Claude Code 和 Codex，每个 agent 使用独立 git worktree 与分支，减少同时修改文件的干扰。
  • 提供差异查看、人工审阅后合并、逐轮回退，以及 MCP 和自定义命令支持。
