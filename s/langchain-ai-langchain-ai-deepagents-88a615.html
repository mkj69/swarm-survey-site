功能齐备、开箱即用的智能体运行框架（agent harness）。 The batteries-included agent harness.
Deep Agents 是一个开源的智能体运行框架——提供具有预设设计取向、开箱即用的智能体。 Deep Agents is an open source agent harness — an opinionated agent that runs out of the box. 可扩展、覆写或替换任意组件。 Extend, override, or replace any piece.
**原则：** **Principles:**
**明确的设计取向**——默认配置针对长程、多步骤任务进行了调优 **Opinionated** — defaults tuned for long-horizon, multi-step work
**可扩展**——无需创建分叉即可覆写或替换任意组件 **Extensible** — override or replace any piece without forking
**模型无关**——适用于任何支持工具调用的大语言模型（LLM）：前沿模型、开放权重模型或本地模型 **Model-agnostic** — works with any LLM that supports tool calling: frontier, open-weight, or local
**可用于生产环境**——基于 LangGraph 构建（支持流式传输、持久化和检查点机制），并通过 LangSmith 为追踪、评估和部署提供一流支持 **Production-ready** — built on LangGraph (streaming, persistence, checkpointing) with first-class tracing, evaluation, and deployment via LangSmith
**功能包括：** **Features include:**
**子智能体**——将任务委派给具有独立上下文窗口的智能体 **Sub-agents** — delegate tasks to agents with isolated context windows
**文件系统**——通过可插拔的本地、沙箱或远程后端读取、写入、编辑或搜索文件 **Filesystem** — read, write, edit, or search over pluggable local, sandboxed, or remote backends
**上下文管理**——概括冗长的对话线程，并将工具输出转存到磁盘 **Context management** — summarize long threads and offload tool outputs to disk
**Shell 访问**——在所选的沙箱中运行命令 **Shell access** — run commands in your sandbox of choice
**持久记忆**——通过可插拔的状态后端和存储后端实现跨会话记忆检索 **Persistent memory** — pluggable state and store backends for cross-session recall
**人在回路（Human-in-the-loop）**——在工具调用执行前批准、编辑或拒绝调用 **Human-in-the-loop** — approve, edit, or reject tool calls before they run
**技能**——智能体可按需加载的可复用行为 **Skills** — reusable behaviors the agent can load on demand
**工具**——接入自定义函数或任意 MCP 服务器 **Tools** — bring your own functions or any MCP server
Deep Agents 提供 JavaScript/TypeScript 库——参见 [deepagents.js](https://github.com/langchain-ai/deepagentsjs)。 Deep Agents is available as a JavaScript/TypeScript library — see [deepagents.js](https://github.com/langchain-ai/deepagentsjs).

快速入门Quickstart
uv add deepagents
from deepagents import create_deep_agent

agent = create_deep_agent(
    model="openai:gpt-6-astra",
    system_prompt="You are a research assistant.",
)
result = agent.invoke({"messages": "Research LangGraph and write a summary"})
该智能体能够制定计划、读写文件，并管理自身的上下文。 The agent can plan, read/write files, and manage its own context. 可添加自定义工具、更换模型、自定义提示词、配置子智能体等。 Add your own tools, swap models, customize prompts, configure sub-agents, and more. 完整详情请参阅[文档](https://docs.langchain.com/oss/python/deepagents/overview)。 See the [documentation](https://docs.langchain.com/oss/python/deepagents/overview) for full details.

常见问题FAQ
这与 LangGraph 或 LangChain 有何不同？How is this different from LangGraph or LangChain?
LangGraph 是图运行时。 LangGraph is the graph runtime. LangChain 的 `create_agent` 是构建于其上的极简智能体运行框架。 LangChain's `create_agent` is a minimal agent harness on top of it. Deep Agents 是构建于 `create_agent` 之上、具有更明确设计取向的运行框架——采用相同的构建模块，但内置了文件系统、子智能体、上下文管理和技能。 Deep Agents is a more opinionated harness on top of `create_agent` — same building blocks, but with filesystem, sub-agents, context management, and skills bundled in. 关于三者之间的关系，请参阅 [LangChain 生态系统概览](https://docs.langchain.com/oss/python/concepts/products)。 For how the three relate, see the [LangChain ecosystem overview](https://docs.langchain.com/oss/python/concepts/products).
它能与开放权重模型或本地模型配合使用吗？Does this work with open-weight or local models?
可以。 Yes. 任何支持工具调用的模型均可使用——包括通过前沿模型 API（OpenAI、Anthropic、Google）提供的模型、托管于 Baseten 或 Fireworks 等服务商的开放权重模型，以及通过 Ollama、vLLM 或 llama.cpp 自行托管的模型。 Any model that supports tool calling works — frontier APIs (OpenAI, Anthropic, Google), open-weight models hosted on providers like Baseten or Fireworks, and self-hosted models via Ollama, vLLM, or llama.cpp. 可使用任意 [LangChain 聊天模型](https://docs.langchain.com/oss/python/langchain/models)。 Use any [LangChain chat model](https://docs.langchain.com/oss/python/langchain/models).
我可以在生产环境中使用它吗？Can I use this in production?
可以！ Yes! Deep Agents 基于 LangGraph 构建，专为生产环境中的智能体部署而设计。 Deep Agents is built on LangGraph, designed for production agent deployments. 将其与 [LangSmith](https://docs.langchain.com/langsmith/home) 配合使用，可进行追踪、评估和监控。 Pair it with [LangSmith](https://docs.langchain.com/langsmith/home) for tracing, evaluation, and monitoring. 完整指南请参阅[部署到生产环境](https://docs.langchain.com/oss/python/deepagents/going-to-production)。 See [Going to production](https://docs.langchain.com/oss/python/deepagents/going-to-production) for the full guide.
何时应使用 Deep Agents，何时应直接使用 LangChain 或 LangGraph？When should I use Deep Agents vs. LangChain or LangGraph directly?
三者是同一技术栈中的不同层级——有关它们之间的关系，请参阅 [LangChain 生态系统概览](https://docs.langchain.com/oss/python/concepts/products)。 All three are layers in the same stack — see the [LangChain ecosystem overview](https://docs.langchain.com/oss/python/concepts/products) for how they relate. 当你希望开箱即用地获得完整的智能体运行框架（harness），包括规划、上下文管理和任务委派时，请使用 **Deep Agents**。 Use **Deep Agents** when you want the full harness — planning, context management, delegation — out of the box. 当你希望使用更轻量、且不捆绑中间件的运行框架时，请使用 [**LangChain 的 `create_agent`**](https://docs.langchain.com/oss/python/langchain/agents)。 Use [**LangChain's `create_agent`**](https://docs.langchain.com/oss/python/langchain/agents) when you want a lighter harness without the bundled middleware. 当智能体循环本身的结构不符合需求、需要自定义图时，请转而使用更底层的 [**LangGraph**](https://docs.langchain.com/oss/python/langgraph/overview)。 Drop to [**LangGraph**](https://docs.langchain.com/oss/python/langgraph/overview) when the agent loop itself isn't the right shape and you need a custom graph.
这些层级可以组合使用：任何 LangGraph `CompiledStateGraph` 都可以作为子智能体传入 Deep Agent，因此，自定义编排可以与运行框架的默认机制共同使用。 The layers compose: any LangGraph `CompiledStateGraph` can be passed in as a sub-agent to a Deep Agent, so custom orchestration plugs in alongside the harness's defaults.

安全性Security
Deep Agents 遵循“信任 LLM”的模型。 Deep Agents follows a "trust the LLM" model. 智能体可以执行其工具所允许的任何操作。 The agent can do anything its tools allow. 应在工具或沙箱层面强制实施边界限制，而不是指望模型自我约束。 Enforce boundaries at the tool/sandbox level, not by expecting the model to self-police. 更多信息请参阅[安全政策](https://github.com/langchain-ai/deepagents?tab=security-ov-file)。 See the [security policy](https://github.com/langchain-ai/deepagents?tab=security-ov-file) for more information.
