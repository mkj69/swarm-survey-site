一句话

这篇论文在短链实验中观察到幻觉净衰减，但事实准确率也随之下降，说明增加串行 agent 可能降低幻觉评分，却未必提高答案的整体可靠性。

主要内容

  • 研究把回答拆成可核验的原子声明，结合参考事实匹配与 LLM 评判打分，沿交互链追踪错误的保留、修正与变化。
  • 基准包含 500 次级联实验：250 条双 agent 链、250 条三 agent 链，覆盖 10 个知识领域，使用 GPT-5.3、DeepSeek-V3 和 LLaMA-3-70B-Instruct。
  • 三 agent 链中，首尾幻觉分数从 0.422 降至 0.272，报告的放大因子为 0.644，表示净衰减；同期事实准确率从 0.789 降至 0.769。
  • 作者报告每次相邻 agent 精炼平均降低幻觉分数 0.072，同时伴随事实一致性和回答质量的小幅损失。
  • 模型比较呈现可靠性与效率的取舍：LLaMA 的幻觉分数最低，GPT-5.3 生成更快。材料还描述了并行共识、层级协调及长链实验，但截取部分未提供足够结果来评价其效果。

证据与可信度

上述数字属于论文作者报告的实验测量，未作独立核验。响应总数可由实验设计核算：250×2＋250×3＝1,250；0.272÷0.422 约等于报告的 0.644。

幻觉分数是作者构建的混合评估指标，不能直接理解为错误声明占比。其可信度依赖参考事实覆盖、声明拆分和 LLM 裁判的校准。现有片段不足以核查人工标注、评估器细节及统计显著性；模型间差异也缺少完整配置与对照信息。

对 swarm scaling 的意义

它对“交互必然放大错误”提供了有条件的反例：在所测短串行链中，平均幻觉指标下降。但这并不证明 agent 越多越好，更不能外推到大规模并行 swarm。

关键启示是把幻觉抑制与事实保留分开评估。后续 agent 可能减少无依据内容，也可能删减、弱化有用事实；准确率下降使这一风险值得关注，但片段尚不能确定具体机制。扩展系统时应同时追踪错误修复、正确声明保留、语义漂移及成本，避免仅凭最终幻觉分数判断扩展收益。
