SLIMSLIM
**SLIM（安全低延迟交互式消息传递，Secure Low-Latency Interactive Messaging）**是新一代 **SLIM (Secure Low-Latency Interactive Messaging)** is a next-generation
通信框架，为以下协议提供安全、可扩展的传输层： communication framework that provides the secure, scalable transport layer for
AI 智能体协议，例如 [A2A（智能体间通信，Agent-to-Agent）](https://a2a.ai) 和 AI agent protocols like [A2A (Agent-to-Agent)](https://a2a.ai) and
[MCP（模型上下文协议，Model Context Protocol）](https://modelcontextprotocol.io)。 [MCP (Model Context Protocol)](https://modelcontextprotocol.io).

架构Architecture
SLIM 采用 SLIM uses a
[分布式架构](https://docs.agntcy.org/slim/overview/#slim-components) [distributed architecture](https://docs.agntcy.org/slim/overview/#slim-components)
，包含三个主要组件： with three main components:
**数据平面（Data Plane）**：纯消息路由层，依据 **Data Plane**: Pure message routing layer that forwards packets based on
层次化名称转发数据包，不检查应用内容 hierarchical names without inspecting application content
**会话层（Session Layer）**：负责可靠交付、端到端 MLS 加密，以及 **Session Layer**: Handles reliable delivery, end-to-end MLS encryption, and
群组成员管理 group membership management
**控制平面（Control Plane）**：管理以下节点的配置、监控和编排： **Control Plane**: Manages configuration, monitoring, and orchestration of
SLIM 路由节点 SLIM routing nodes
这种分离设计支持高效部署：SLIM 路由节点仅运行 This separation enables efficient deployment: SLIM routing nodes run only the
轻量级数据平面，而应用程序使用包含完整 lightweight data plane, while applications use language bindings with the full
协议栈（数据平面客户端 + [会话层](https://docs.agntcy.org/slim/slim-data-plane/) + stack (data plane client + [session layer](https://docs.agntcy.org/slim/slim-data-plane/) +
[SLIMRPC](https://docs.agntcy.org/slim/slim-rpc/)）的语言绑定，以实现安全且功能丰富的 [SLIMRPC](https://docs.agntcy.org/slim/slim-rpc/)) for secure, feature-rich
通信。 communication.
