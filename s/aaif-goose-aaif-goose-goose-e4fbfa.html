goose 是一款在你的计算机上运行的通用 AI 智能体。 goose is a general-purpose AI agent that runs on your machine. 它不仅可用于编程，还可用于研究、写作、自动化、数据分析，或任何你需要完成的任务。 Not just for code — use it for research, writing, automation, data analysis, or anything you need to get done.
一款适用于 macOS、Linux 和 Windows 的原生桌面应用。 A native desktop app for macOS, Linux, and Windows. 一个功能完整的命令行界面（CLI），用于终端工作流。 A full CLI for terminal workflows. 一个可将其嵌入任何环境的 API。 An API to embed it anywhere. 使用 Rust 构建，兼顾性能与可移植性。 Built in Rust for performance and portability.
goose 支持 15+ 家服务提供商，包括 Anthropic、OpenAI、Google、Ollama、OpenRouter、Azure、Bedrock 等。 goose works with 15+ providers — Anthropic, OpenAI, Google, Ollama, OpenRouter, Azure, Bedrock, and more. 可使用 API 密钥，或通过 [ACP](https://goose-docs.ai/docs/guides/acp-providers) 使用你现有的 Claude、ChatGPT 或 Gemini 订阅。 Use API keys or your existing Claude, ChatGPT, or Gemini subscriptions via [ACP](https://goose-docs.ai/docs/guides/acp-providers). 通过[模型上下文协议（Model Context Protocol）](https://modelcontextprotocol.io/)这一开放标准，连接 70+ 个扩展。 Connect to 70+ extensions via the [Model Context Protocol](https://modelcontextprotocol.io/) open standard.
goose 是 Linux 基金会旗下 [Agentic AI Foundation（AAIF，智能体 AI 基金会）](https://aaif.io/) 的一部分。 goose is part of the [Agentic AI Foundation (AAIF)](https://aaif.io/) at the Linux Foundation.
