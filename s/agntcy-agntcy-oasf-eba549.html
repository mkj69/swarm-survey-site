开放智能体模式框架Open Agentic Schema Framework
[开放智能体模式框架（Open Agentic Schema Framework，OASF）](https://schema.oasf.outshift.com/)是一套标准化的模式系统，用于 The [Open Agentic Schema Framework (OASF)](https://schema.oasf.outshift.com/) is a standardized schema system for
定义和管理 AI 智能体的能力、交互和元数据。 defining and managing AI agent capabilities, interactions, and metadata.
它提供了一种结构化方式，利用基于属性的 It provides a structured way to describe agent attributes, capabilities, and relationships using attribute-based
分类体系来描述智能体的属性、能力和关系。 taxonomies.
该框架包含开发工具、模式验证和热重载功能，以支持快速的模式开发， The framework includes development tools, schema validation, and hot-reload capabilities for rapid schema development,
所有这些均通过基于 Taskfile 的工作流进行管理。 all managed through a Taskfile-based workflow.
OASF 为可互操作的 AI 智能体系统奠定基础，使分布式系统之间能够以一致的方式定义和发现智能体的 OASF serves as the foundation for interoperable AI agent systems, enabling consistent definition and discovery of agent
能力。 capabilities across distributed systems.
OASF 在数据建模 OASF is highly inspired from [OCSF (Open Cybersecurity Schema Framework)](https://ocsf.io/) in terms of data modeling
理念以及实现方面，都深受 [OCSF（开放网络安全模式框架）](https://ocsf.io/)的启发。 philosophy but also in terms of implementation.
模式更新工作流沿用了 OCSF 开发的工作流，而 [OASF 服务器](https://github.com/agntcy/oasf-server)是 The schema update workflows reproduce those developed by OCSF, and the [OASF server](https://github.com/agntcy/oasf-server) is a
OCSF 模式服务器的衍生作品。 derivative work of the OCSF schema server.
功能Features
OASF 为智能体 AI 内容表示定义了一套标准，旨在： OASF defines a set of standards for agentic AI content representation that aims to:
定义通用数据结构，以促进内容标准化、验证和互操作。 Define common data structure to facilitate content standardization, validation, and interoperability.
确保智能体的唯一标识，以满足内容发现和使用的需求。 Ensure unique agent identification to address content discovery and consumption.
提供扩展能力，以支持第三方功能。 Provide extension capabilities to enable third-party features.

模式版本管理与不可变性Schema Versioning and Immutability
模式的某个版本一经发布，原则上不再对该版本进行任何更改，但不破坏兼容性的修复除外 Once a schema version is released, no changes to that version of the schema are expected, except for non-breaking fixes
例如文档更新或轻微的错误修正。 such as documentation updates or minor bug corrections.
模式版本发布后进行的任何删除、添加或结构性更改，都将纳入模式的下一个 Any deletions, additions, or structural changes made after a schema version is released will be part of the next schema
版本。 version.
这一不可变性策略确保了依赖特定模式 This immutability policy ensures backward compatibility and stability for systems that depend on specific schema
版本的系统具有向后兼容性和稳定性，同时允许框架通过发布新版本不断演进和改进。 versions, while allowing the framework to evolve and improve over time through new version releases.
