bd - Beadsbd - Beads
**由 [Dolt](https://github.com/dolthub/dolt) 驱动、面向 AI 智能体的分布式图结构议题跟踪工具。** **Distributed graph issue tracker for AI agents, powered by [Dolt](https://github.com/dolthub/dolt).**
**平台：** macOS、Linux、Windows、FreeBSD **Platforms:** macOS, Linux, Windows, FreeBSD
**文档：** https://beads.gascity.com/ **Docs:** https://beads.gascity.com/
Beads 为编程智能体提供持久化的结构化记忆。 Beads provides a persistent, structured memory for coding agents. 它用能够感知依赖关系的图替代杂乱的 Markdown 计划，使智能体能够在不丢失上下文的情况下处理长期任务。 It replaces messy markdown plans with a dependency-aware graph, allowing agents to handle long-horizon tasks without losing context.

    close -->|blockers released| ready

🛠 功能🛠 Features
**由 [Dolt](https://github.com/dolthub/dolt) 驱动：** 支持版本控制的 SQL 数据库，具备单元格级合并、原生分支功能，以及通过 Dolt 远程仓库进行同步的内置功能。 **[Dolt](https://github.com/dolthub/dolt)-Powered:** Version-controlled SQL database with cell-level merge, native branching, and built-in sync via Dolt remotes.
**针对智能体优化：** JSON 输出、依赖关系跟踪，以及自动检测已具备执行条件的任务。 **Agent-Optimized:** JSON output, dependency tracking, and auto-ready task detection.
**零冲突：** 基于哈希的 ID（`bd-a1b2`）可防止多智能体/多分支工作流程中的合并冲突。 **Zero Conflict:** Hash-based IDs (`bd-a1b2`) prevent merge collisions in multi-agent/multi-branch workflows.
**压缩：** 通过语义层面的“记忆衰减”概括较早已关闭的任务，以节省上下文窗口空间。 **Compaction:** Semantic "memory decay" summarizes old closed tasks to save context window.
**消息传递：** 提供消息议题类型，支持线程（`--thread`）、短暂生命周期和邮件委派。 **Messaging:** Message issue type with threading (`--thread`), ephemeral lifecycle, and mail delegation.
**图链接：** 提供用于知识图谱的 `relates-to`、`duplicates`、`supersedes` 和 `replies-to` 关系。 **Graph Links:** `relates-to`, `duplicates`, `supersedes`, and `replies-to` for knowledge graphs.

🚀 无需 Git 即可使用🚀 Git-Free Usage
Beads 无需 git 即可运行。 Beads works without git. Dolt 数据库是存储后端——git The Dolt database is the storage backend — git
集成（钩子、仓库发现、身份信息）是可选的。 integration (hooks, repo discovery, identity) is optional. 
# Initialize without git
export BEADS_DIR=/path/to/your/project/.beads
bd init --quiet --stealth

# All core commands work with zero git calls
bd create "Fix auth bug" -p 1 -t bug
bd ready --json
bd update bd-a1b2 --claim
bd prime
bd close bd-a1b2 "Fixed"
`BEADS_DIR` 告诉 bd 应将 `.beads/` 数据库目录放在哪里， `BEADS_DIR` tells bd where to put the `.beads/` database directory,
从而绕过 git 仓库发现。`--stealth` 在配置中设置 `no-git-ops: true`， bypassing git repo discovery. `--stealth` sets `no-git-ops: true` in
禁用 bd 自身的 git 钩子安装和 git 命令。 config, disabling bd's own git hook installation and git commands. 它 It
不会停止 Dolt 网络同步；若要停止同步，请设置 `dolt.local-only: true`。 does not stop Dolt network sync; set `dolt.local-only: true` for that.
这适用于以下场景： This is useful for:
**非 git 版本控制系统（VCS）**（Sapling、Jujutsu、Piper）——无需 `.git/` 目录 **Non-git VCS** (Sapling, Jujutsu, Piper) — no `.git/` directory needed
**单体仓库（Monorepos）**——将 `BEADS_DIR` 指向特定子目录 **Monorepos** — point `BEADS_DIR` at a specific subdirectory
**CI/CD**——独立进行任务跟踪，不产生仓库级副作用 **CI/CD** — isolated task tracking without repo-level side effects
**评估/测试**——在 `/tmp` 中使用临时数据库 **Evaluation/testing** — ephemeral databases in `/tmp`
