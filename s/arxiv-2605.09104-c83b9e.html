一句话

这篇综述把多智能体扩展重新表述为经济问题：专业分工带来的收益，能否覆盖通信、同步与协调产生的额外成本。

主要内容

  • 统一分析目标：在满足回答质量要求的前提下，最小化总成本；成本不仅包括 token 和算力，也包括人的参与时间及等待成本。
  • 按组织规模划分瓶颈：单智能体关注内部推理、工具调用与记忆的资源分配；多智能体关注协作摩擦；开放生态关注共享算力拥塞与资源定价。安全则作为影响质量和成本的约束贯穿其中。
  • 多智能体的关键代价：状态同步、重复传递上下文、格式对齐和冲突处理，被解释为内部交易成本。增加角色和连接关系，需要同时衡量专业化收益与维持一致性的负担。
  • 单体优化仍是基础：片段梳理了推理压缩、缓存、量化、工具路由和记忆复用等方法，并尝试用要素替代、成本压缩与投资摊销解释它们。
  • 后续研究方向：提出可微 token 预算、记忆资本积累与动态 token 市场，但片段未展示这些方向的验证结果。

对 swarm scaling 的意义

它提供了一个有用的评估视角：扩展 swarm 时，应把任务质量与完整协作成本放在一起比较，尤其单独记录通信 token、重复上下文、同步等待和协调开销。

据此可以提出待验证的问题：新增 agent 的专业化收益，何时不足以补偿新增协作成本？这有助于设计规模、拓扑与预算实验，但材料尚不能给出最佳 agent 数量，也不能证明某种组织结构普遍最优。
