Directory（dir）支持在分布式对等网络中发布、交换和发现有关记录的信息。 The Directory (dir) allows publication, exchange, and discovery of information about records over a distributed peer-to-peer network.
它利用 [OASF](https://github.com/agntcy/oasf) 描述 AI 智能体，并提供一组 API 和工具，用于存储、发布记录，以及根据记录的属性和约束条件在网络中发现记录。 It leverages [OASF](https://github.com/agntcy/oasf) to describe AI agents and provides a set of APIs and tools to store, publish, and discover records across the network by their attributes and constraints.
Directory 还利用 [CSIT](https://github.com/agntcy/csit) 在不同版本、环境和功能之间开展持续的系统集成与测试。 Directory also leverages [CSIT](https://github.com/agntcy/csit) for continuous system integration and testing across different versions, environments, and features.

使用 dirctl daemonUsing dirctl daemon
运行本地 Directory 实例的最快方式是使用内置守护进程。 The fastest way to run a local Directory instance is the built-in daemon. 它将 gRPC apiserver 和 reconciler 整合到单个进程中，并内嵌 SQLite 和本地 OCI 存储。 It bundles the gRPC apiserver and reconciler into a single process with embedded SQLite and a local OCI store. 
dirctl daemon start
默认情况下，所有状态均存储在 `~/.agntcy/dir/` 下。 All state is stored under `~/.agntcy/dir/` by default. 守护进程监听 `localhost:8888`，可通过 `dirctl daemon stop` 和 `dirctl daemon status` 进行管理。 The daemon listens on `localhost:8888` and can be managed with `dirctl daemon stop` and `dirctl daemon status`.
可以使用自定义配置文件连接外部数据库（例如 PostgreSQL）或远程 OCI 注册表，以替代内置 SQLite 和本地存储： A custom configuration file can be used to connect to external databases (e.g. PostgreSQL) or remote OCI registries instead of the built-in SQLite and local store: 
dirctl daemon start --config /path/to/daemon.config.yaml
