OpenTelemetry 语义约定OpenTelemetry Semantic Conventions
语义约定定义了一组通用的（语义）属性，这些属性 Semantic Conventions define a common set of (semantic) attributes which
在收集、生成和使用数据时赋予数据含义。 provide meaning to data when collecting, producing and consuming it.
