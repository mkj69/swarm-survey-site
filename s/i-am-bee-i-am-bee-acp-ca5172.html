智能体通信协议（Agent Communication Protocol，ACP） Agent Communication Protocol (ACP)
🚀 重要更新🚀 IMPORTANT UPDATE

**ACP 是一种用于 AI 智能体、应用程序与人类之间通信的开放协议。** **ACP is an open protocol for communication between AI agents, applications, and humans.**
现代 AI 智能体往往由不同团队基于不同框架和基础设施各自独立构建。 Modern AI agents are often built in isolation, across different frameworks, teams, and infrastructures.
这种碎片化状况减缓了创新，也使智能体更难有效协作。 This fragmentation slows innovation and makes it harder for agents to work together effectively.
ACP 通过支持智能体使用多模态消息进行通信与协调，解决了这一问题。 ACP solves this by enabling agents to communicate and coordinate using multimodal messages.
ACP 使智能体能够： ACP enables agents to:
发送和接收内容丰富的消息，例如文本、代码、文件或媒体 Send and receive rich messages — like text, code, files, or media
实时响应、在后台响应或以流式方式响应 Respond in real time, in the background, or as a stream
让其他参与者发现自身具备的能力 Let others discover what they can do
协作执行长时间运行的任务 Collaborate on long-running tasks
在需要时彼此共享状态 Share state with each other when needed
ACP 为 [BeeAI Platform](https://github.com/i-am-bee/beeai-platform) 上的智能体通信提供支持；在该平台上，你可以发现、运行和共享智能体。 ACP powers agent communication on the [BeeAI Platform](https://github.com/i-am-bee/beeai-platform) — a place where you can discover, run, and share agents.

核心概念Core Concepts
| **Concept**      | **Description**  |
| **[Agent Manifest](https://agentcommunicationprotocol.dev/core-concepts/agent-manifest)** | A model describing an agent's capabilities—its name, description, and optional metadata and status—for discovery and composition without exposing implementation details. |
| **[Run](https://agentcommunicationprotocol.dev/core-concepts/agent-run-lifecycle)** | A single agent execution with specific inputs. Supports sync or streaming, with intermediate and final output. |
| **[Message](https://agentcommunicationprotocol.dev/core-concepts/message-structure)** | The core structure for communication, consisting of a sequence of ordered components that form a complete, structured, and multi-modal exchange of information. |
| **[MessagePart](https://agentcommunicationprotocol.dev/core-concepts/message-structure)**  | The individual content units within a `Message`, which can include types like text, image, or JSON. Together, they combine to create structured, multimodal communication. |
| **[Await](https://agentcommunicationprotocol.dev/core-concepts/agent-run-lifecycle#agent-run-await)**  | Let agents pause to request information from the client and resume, enabling interactive exchanges where the agent can wait for external input (data, actions, etc.) before continuing. |
| **[Sessions](https://agentcommunicationprotocol.dev/core-concepts/stateful-agents)**  | Enable agents to maintain state and conversation history across multiple interactions using session identifiers. The SDK automatically manages session state, allowing agents to access complete interaction history within a session. |
快速入门Quickstart
> [!NOTE] > [!NOTE]
> 本指南使用 `uv`。 > This guide uses `uv`. 更多详情请参阅 [`uv` 入门指南](https://agentcommunicationprotocol.dev/introduction/uv-primer)。 See the [`uv` primer](https://agentcommunicationprotocol.dev/introduction/uv-primer) for more details.
**1. **1. 初始化你的项目** Initialize your project** 
uv init --python '>=3.11' my_acp_project
cd my_acp_project
**2. **2. 添加 ACP SDK** Add the ACP SDK** 
uv add acp-sdk
**3. **3. 创建智能体** Create an agent**
让我们创建一个简单的“回声智能体”，它会原样返回收到的任何消息。 Let's create a simple "echo agent" that returns any message it receives.
在项目目录中创建一个 `agent.py` 文件，内容为以下代码： Create an `agent.py` file in your project directory with the following code: 
# agent.py
import asyncio
from collections.abc import AsyncGenerator

from acp_sdk.models import Message
from acp_sdk.server import Context, RunYield, RunYieldResume, Server

server = Server()


@server.agent()
async def echo(
    input: list[Message], context: Context
) -> AsyncGenerator[RunYield, RunYieldResume]:
    """Echoes everything"""
    for message in input:
        await asyncio.sleep(0.5)
        yield {"thought": "I should echo everything"}
        await asyncio.sleep(0.5)
        yield message


server.run()
**4. **4. 启动 ACP 服务器** Start the ACP server** 
uv run agent.py
此时，你的服务器应已在 http://localhost:8000 上运行。 Your server should now be running at http://localhost:8000.
**5. **5. 验证你的智能体是否可用** Verify your agent is available**
在另一个终端中，运行以下 `curl` 命令： In another terminal, run the following `curl` command: 
curl http://localhost:8000/agents
你应该会看到一个包含你的 `echo` 智能体的 JSON 响应，这表明该智能体已可用： You should see a JSON response containing your `echo` agent, confirming it's available: 
{
  "agents": [
    { "name": "echo", "description": "Echoes everything", "metadata": {} }
  ]
}
**6. **6. 通过 HTTP 运行智能体** Run the agent via HTTP**
运行以下 `curl` 命令： Run the following `curl` command: 
curl -X POST http://localhost:8000/runs \
  -H "Content-Type: application/json" \
  -d '{
        "agent_name": "echo",
        "input": [
          {
            "role": "user",
            "parts": [
              {
                "content": "Howdy!",
                "content_type": "text/plain"
              }

响应中应包含原样返回的消息“你好！”： Your response should include the echoed message "Howdy!":

**7. **7. 构建 ACP 客户端** Build an ACP client**
下面是一个用于与你的 `echo` 智能体交互的简单 ACP 客户端。 Here's a simple ACP client to interact with your `echo` agent.
在项目目录中创建一个 `client.py` 文件，内容为以下代码： Create a `client.py` file in your project directory with the following code: 
# client.py
import asyncio

from acp_sdk.client import Client
from acp_sdk.models import Message, MessagePart


async def example() -> None:
    async with Client(base_url="http://localhost:8000") as client:
        run = await client.run_sync(
            agent="echo",
            input=[
                Message(
                    role="user",
                    parts=[MessagePart(content="Howdy to echo from client!!", content_type="text/plain")]
                )
            ],
        )
        print(run.output)


if __name__ == "__main__":
    asyncio.run(example())
**8. **8. 运行 ACP 客户端** Run the ACP client** 
uv run client.py
你应该会看到原样返回的响应打印在控制台中。🎉 You should see the echoed response printed to your console. 🎉
