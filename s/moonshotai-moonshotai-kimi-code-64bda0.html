什么是 Kimi Code CLIWhat is Kimi Code CLI
Kimi Code CLI 是一个在终端中运行的 AI 编程智能体——它可以读取和编辑代码、运行 shell 命令、搜索文件、获取网页，并根据收到的反馈选择下一步操作。 Kimi Code CLI is an AI coding agent that runs in your terminal — it can read and edit code, run shell commands, search files, fetch web pages, and choose the next step based on the feedback it receives. 它开箱即用，支持 Moonshot AI 的 Kimi 模型，也可通过配置使用其他兼容的服务提供商。 It works out of the box with Moonshot AI’s Kimi models and can also be configured to use other compatible providers.

主要功能Key Features
**单一二进制文件分发。** 一条命令即可安装：无需配置 Node.js，无需繁琐调整 PATH，也不会发生全局模块冲突。 **Single-binary distribution.** Install with one command: no Node.js setup, PATH gymnastics, or global module conflicts.
**极速启动。** 终端用户界面（TUI）可在毫秒内就绪，让每次启动会话都轻快流畅。 **Blazing-fast startup.** The TUI is ready in milliseconds, so starting a session never feels heavy.
**专门设计的 TUI。** 界面经过精心调校，从头到尾都针对长时间、专注的智能体会话进行了优化。 **Purpose-built TUI.** A carefully tuned interface, optimized end to end for long, focused agent sessions.
**视频输入。** 将屏幕录像或演示短片拖入聊天，让智能体观看那些难以用语言描述的内容——将参考短片转换为查找表（LUT）、将长视频剪成短视频、将屏幕录像转化为可运行的代码，等等。 **Video input.** Drop a screen recording or demo clip into the chat and let the agent watch what is hard to describe in words — turn a reference clip into a LUT, a long video into a short, a screen recording into working code, and more.
**AI 原生 MCP 配置。** 使用 `/mcp-config`，通过对话添加、编辑模型上下文协议（Model Context Protocol）服务器并完成身份验证，无需手动编辑 JSON。 **AI-native MCP configuration.** Add, edit, and authenticate Model Context Protocol servers conversationally with `/mcp-config`, without hand-editing JSON.
**丰富的插件生态。** 从市场或任意 GitHub 仓库安装技能、MCP 服务器和数据源，每次安装都会预先明确展示其信任级别。 **Rich plugin ecosystem.** Install skills, MCP servers, and data sources from the marketplace or any GitHub repo, with each install's trust level surfaced up front.
**用于专注、并行工作的子智能体。** 在隔离的上下文中调度内置的 `coder`、`explore` 和 `plan` 子智能体，同时保持主对话简洁。 **Subagents for focused, parallel work.** Dispatch built-in `coder`, `explore`, and `plan` subagents in isolated contexts while keeping the main conversation clean.
**生命周期钩子。** 在关键节点运行本地命令，以控制高风险工具调用、审计决策、触发桌面通知，或接入你自己的自动化流程。 **Lifecycle hooks.** Run local commands at key points to gate risky tool calls, audit decisions, trigger desktop notifications, or connect to your own automation.
**编辑器与 IDE 集成（ACP）。** 使用 `kimi acp`，直接从 Zed、JetBrains 或任何 [Agent Client Protocol](https://agentclientprotocol.com/) 客户端操控 Kimi Code CLI 会话。 **Editor & IDE integration (ACP).** Drive a Kimi Code CLI session straight from Zed, JetBrains, or any [Agent Client Protocol](https://agentclientprotocol.com/) client with `kimi acp`.
在编辑器中使用（ACP）Use it in your editor (ACP)
Kimi Code CLI 支持[智能体客户端协议（Agent Client Protocol）](https://agentclientprotocol.com/)，因此兼容 ACP 的编辑器和 IDE（Zed、JetBrains 等）可以通过标准输入输出（stdio）操控会话。 Kimi Code CLI speaks the [Agent Client Protocol](https://agentclientprotocol.com/), so ACP-compatible editors and IDEs (Zed, JetBrains, …) can drive a session over stdio. 登录一次后，将编辑器配置为调用 `kimi acp` 子命令即可——无需再次登录。 Log in once, then point your editor at the `kimi acp` subcommand — no extra login needed.
对于 Zed，请将以下内容添加到 `~/.config/zed/settings.json`： For Zed, add this to `~/.config/zed/settings.json`: 
{
  "agent_servers": {
    "Kimi Code CLI": {
      "type": "custom",
      "command": "kimi",
      "args": ["acp"],
      "env": {}
    }
  }
}
然后，在 Zed 的 Agent 面板中打开一个新对话。 Then open a new conversation in Zed's Agent panel. 有关 JetBrains 的配置和故障排查，请参阅[在 IDE 中使用](https://moonshotai.github.io/kimi-code/en/guides/ides)；有关完整的功能支持矩阵，请参阅 [`kimi acp` 参考文档](https://moonshotai.github.io/kimi-code/en/reference/kimi-acp)。 See [Using in IDEs](https://moonshotai.github.io/kimi-code/en/guides/ides) for JetBrains setup and troubleshooting, and the [`kimi acp` reference](https://moonshotai.github.io/kimi-code/en/reference/kimi-acp) for the full capability matrix.
