智能体连接协议（Agent Connect Protocol）规范Agent Connect Protocol Specification
关于本项目About The Project
本仓库包含由 Agntcy Collective 提出的智能体连接协议（ACP）规范。 This repo contains the specification of Agent Connect Protocol (ACP) proposed by the Agntcy Collective. 智能体连接协议定义了一个标准接口，用于通过 API 调用和配置远程智能体。 The Agent Connect Protocol defines a standard interface to invoke and configure remote agents over an API. 该协议使用 [OpenAPI](https://www.openapis.org/what-is-openapi) 进行描述，后者是一种基于 REST 的模式规范。 The protocol is specified in [OpenAPI](https://www.openapis.org/what-is-openapi) a REST-based schema specification.
有关 ACP 如何融入 [Agntcy 所构想的智能体互联网](https://docs.agntcy.org/)这一整体架构的更多信息，请参阅文档中的[引言。](https://docs.agntcy.org/pages/introduction.html) More about how ACP fits into the bigger picture of the [Internet of Agents as seen by Agntcy](https://docs.agntcy.org/) can be found in the documentation [Introduction.](https://docs.agntcy.org/pages/introduction.html)
