原始 README（旧版，仅供参考） Original README (legacy, for reference only)
Kimi CLI 是一个在终端中运行的 AI 智能体，可帮助你完成软件开发任务和终端操作。 Kimi CLI is an AI agent that runs in the terminal, helping you complete software development tasks and terminal operations. 它能够读取和编辑代码、执行 shell 命令、搜索和获取网页，并在执行过程中自主规划和调整操作。 It can read and edit code, execute shell commands, search and fetch web pages, and autonomously plan and adjust actions during execution.

主要功能Key Features
Shell 命令模式Shell command mode
Kimi CLI 不仅是一个编程智能体，也是一个 shell。 Kimi CLI is not only a coding agent, but also a shell. 你可以按 `Ctrl-X` 切换 shell 命令模式。 You can switch the shell command mode by pressing `Ctrl-X`. 在此模式下，你可以直接运行 shell 命令，无需离开 Kimi CLI。 In this mode, you can directly run shell commands without leaving Kimi CLI.
> [!NOTE] > [!NOTE]
> 尚不支持 `cd` 等 shell 内置命令。 > Built-in shell commands like `cd` are not supported yet.

通过 ACP 与 IDE 集成IDE integration via ACP
Kimi CLI 开箱即支持 [Agent Client Protocol]（智能体客户端协议）。 Kimi CLI supports [Agent Client Protocol] out of the box. 你可以将其与任何兼容 ACP 的编辑器或 IDE 配合使用。 You can use it together with any ACP-compatible editor or IDE.
[Agent Client Protocol]: https://github.com/agentclientprotocol/agent-client-protocol [Agent Client Protocol]: https://github.com/agentclientprotocol/agent-client-protocol
要将 Kimi CLI 与 ACP 客户端配合使用，请务必先在终端中运行 Kimi CLI，并发送 `/login` 以完成登录。 To use Kimi CLI with ACP clients, make sure to run Kimi CLI in the terminal and send `/login` to complete the login first. 随后，你可以配置 ACP 客户端，使其通过命令 `kimi acp` 将 Kimi CLI 作为 ACP 智能体服务器启动。 Then, you can configure your ACP client to start Kimi CLI as an ACP agent server with command `kimi acp`.
例如，要将 Kimi CLI 与 [Zed](https://zed.dev/) 或 [JetBrains](https://blog.jetbrains.com/ai/2025/12/bring-your-own-ai-agent-to-jetbrains-ides/) 配合使用，请将以下配置添加到 `~/.config/zed/settings.json` 或 `~/.jetbrains/acp.json` 文件中： For example, to use Kimi CLI with [Zed](https://zed.dev/) or [JetBrains](https://blog.jetbrains.com/ai/2025/12/bring-your-own-ai-agent-to-jetbrains-ides/), add the following configuration to your `~/.config/zed/settings.json` or `~/.jetbrains/acp.json` file: 
{
  "agent_servers": {
    "Kimi CLI": {
      "type": "custom",
      "command": "kimi",
      "args": ["acp"],
      "env": {}
    }
  }
}
随后，你便可以在 IDE 的智能体面板中创建 Kimi CLI 会话线程。 Then you can create Kimi CLI threads in IDE's agent panel.

MCP 支持MCP support
Kimi CLI 支持 MCP（模型上下文协议，Model Context Protocol）工具。 Kimi CLI supports MCP (Model Context Protocol) tools.
**`kimi mcp` 子命令组** **`kimi mcp` sub-command group**
你可以使用 `kimi mcp` 子命令组管理 MCP 服务器。 You can manage MCP servers with `kimi mcp` sub-command group. 例如： For example: 
# Add streamable HTTP server:
kimi mcp add --transport http context7 https://mcp.context7.com/mcp --header "CONTEXT7_API_KEY: ctx7sk-your-key"

# Add streamable HTTP server with OAuth authorization:
kimi mcp add --transport http --auth oauth linear https://mcp.linear.app/mcp

# Add stdio server:
kimi mcp add --transport stdio chrome-devtools -- npx chrome-devtools-mcp@latest

# List added MCP servers:
kimi mcp list

# Remove an MCP server:
kimi mcp remove chrome-devtools

# Authorize an MCP server:
kimi mcp auth linear
**临时 MCP 配置** **Ad-hoc MCP configuration**
Kimi CLI 还支持通过 CLI 选项临时配置 MCP 服务器。 Kimi CLI also supports ad-hoc MCP server configuration via CLI option.
给定一个采用通用 MCP 配置格式的 MCP 配置文件，如下所示： Given an MCP config file in the well-known MCP config format like the following: 
{
  "mcpServers": {
    "context7": {
      "url": "https://mcp.context7.com/mcp",
      "headers": {
        "CONTEXT7_API_KEY": "YOUR_API_KEY"
      }
    },
    "chrome-devtools": {
      "command": "npx",
      "args": ["-y", "chrome-devtools-mcp@latest"]
    }
  }
}
运行 `kimi` 时使用 `--mcp-config-file` 选项，以连接到指定的 MCP 服务器： Run `kimi` with `--mcp-config-file` option to connect to the specified MCP servers: 
kimi --mcp-config-file /path/to/mcp.json

开发Development
要开发 Kimi CLI，请运行： To develop Kimi CLI, run: 
git clone https://github.com/MoonshotAI/kimi-cli.git
cd kimi-cli

make prepare  # prepare the development environment
随后，你便可以开始开发 Kimi CLI。 Then you can start working on Kimi CLI.
完成修改后，请参考以下命令： Refer to the following commands after you make changes: 
uv run kimi  # run Kimi CLI

make format  # format code
make check  # run linting and type checking
make test  # run tests
make test-kimi-cli  # run Kimi CLI tests only
make test-kosong  # run kosong tests only
make test-pykaos  # run pykaos tests only
make build-web  # build the web UI and sync it into the package (requires Node.js/npm)
make build  # build python packages
make build-bin  # build standalone binary
make help  # show all make targets
注意：`make build` 和 `make build-bin` 会自动运行 `make build-web`，以嵌入 Web 用户界面。 Note: `make build` and `make build-bin` automatically run `make build-web` to embed the web UI.
