系统提示词System Prompt
默认情况下，Claude Code 会在会话的首次请求时构建系统提示词，将其记录下来，并在此后的每次请求中复用，包括恢复会话后的请求。 By default, Claude Code builds the system prompt on a session's first request, records it, and reuses it on every later request, including after you resume the session. 此后，即使修改自定义提示词或 `claude_code` 预设中的 `append` 文本，这些修改也要等到会话被压缩或新会话启动后才会生效。 A changed custom prompt, or changed `append` text on the `claude_code` preset, then has no effect until the session is compacted or you start a new session. 如果希望改为在每次请求时重新构建提示词，例如在反复调整措辞时，请在 `{"type": "preset", ...}` 或 `{"type": "custom", ...}` 字典中将 `snapshot` 设置为 `False`： To rebuild the prompt on every request instead, for example while you iterate on its wording, set `snapshot` to `False` in the `{"type": "preset", ...}` or `{"type": "custom", ...}` dict: 
options = ClaudeAgentOptions(
    system_prompt={"type": "custom", "prompt": "You are a release bot.", "snapshot": False}
)
需要 Claude Code CLI 2.1.257 或更高版本。 Requires Claude Code CLI 2.1.257 or later. 在 2.1.265 之前，使用 `append` 或自定义提示词的会话只有在 `snapshot` 为 True 时才会记录该提示词。 Before 2.1.265, a session with an `append` or custom prompt recorded it only when `snapshot` was True. 详情请参阅[修改系统提示词](https://code.claude.com/docs/en/agent-sdk/modifying-system-prompts#change-the-prompt-of-an-existing-session)。 See [Modifying system prompts](https://code.claude.com/docs/en/agent-sdk/modifying-system-prompts#change-the-prompt-of-an-existing-session) for details.

自定义工具（作为进程内 SDK MCP 服务器）Custom Tools (as In-Process SDK MCP Servers)
**自定义工具**是一个可以提供给 Claude 的 Python 函数，供 Claude 按需调用。 A **custom tool** is a Python function that you can offer to Claude, for Claude to invoke as needed.
自定义工具以进程内 MCP 服务器的形式实现，直接在你的 Python 应用程序中运行，无需像常规 MCP 服务器那样使用独立进程。 Custom tools are implemented in-process MCP servers that run directly within your Python application, eliminating the need for separate processes that regular MCP servers require.
端到端示例请参阅 [MCP 计算器](examples/mcp_calculator.py)。 For an end-to-end example, see [MCP Calculator](examples/mcp_calculator.py).
创建一个简单工具Creating a Simple Tool
from claude_agent_sdk import tool, create_sdk_mcp_server, ClaudeAgentOptions, ClaudeSDKClient

# Define a tool using the @tool decorator
@tool("greet", "Greet a user", {"name": str})
async def greet_user(args):
    return {
        "content": [
            {"type": "text", "text": f"Hello, {args['name']}!"}
        ]
    }

# Create an SDK MCP server
server = create_sdk_mcp_server(
    name="my-tools",
    version="1.0.0",
    tools=[greet_user]
)

# Use it with Claude. allowed_tools pre-approves the tool so it runs
# without a permission prompt; it does not control tool availability.
options = ClaudeAgentOptions(
    mcp_servers={"tools": server},
    allowed_tools=["mcp__tools__greet"]
)

async with ClaudeSDKClient(options=options) as client:
    await client.query("Greet Alice")

    # Extract and print response
    async for msg in client.receive_response():
        print(msg)
相较于外部 MCP 服务器的优势Benefits Over External MCP Servers
**无需管理子进程** - 与应用程序在同一进程中运行 **No subprocess management** - Runs in the same process as your application
**性能更佳** - 工具调用无进程间通信（IPC）开销 **Better performance** - No IPC overhead for tool calls
**部署更简单** - 仅需单个 Python 进程，无需多个进程 **Simpler deployment** - Single Python process instead of multiple
**调试更容易** - 所有代码均在同一进程中运行 **Easier debugging** - All code runs in the same process
**类型安全** - 直接调用带有类型提示的 Python 函数 **Type safety** - Direct Python function calls with type hints

钩子Hooks
**钩子（hook）**是一个 Python 函数，由 Claude Code _应用程序_（_而非_ Claude）在 Claude 智能体循环的特定节点调用。 A **hook** is a Python function that the Claude Code _application_ (_not_ Claude) invokes at specific points of the Claude agent loop. 钩子可以为 Claude 提供确定性处理和自动化反馈。 Hooks can provide deterministic processing and automated feedback for Claude. 更多信息请参阅[使用钩子拦截和控制智能体行为](https://platform.claude.com/docs/en/agent-sdk/hooks)。 Read more in [Intercept and control agent behavior with hooks](https://platform.claude.com/docs/en/agent-sdk/hooks).
更多示例请参阅 examples/hooks.py。 For more examples, see examples/hooks.py.
示例Example
from claude_agent_sdk import ClaudeAgentOptions, ClaudeSDKClient, HookMatcher

async def check_bash_command(input_data, tool_use_id, context):
    tool_name = input_data["tool_name"]
    tool_input = input_data["tool_input"]
    if tool_name != "Bash":
        return {}
    command = tool_input.get("command", "")
    block_patterns = ["foo.sh"]
    for pattern in block_patterns:
        if pattern in command:
            return {
                "hookSpecificOutput": {
                    "hookEventName": "PreToolUse",
                    "permissionDecision": "deny",
                    "permissionDecisionReason": f"Command contains invalid pattern: {pattern}",
                }
            }
    return {}

options = ClaudeAgentOptions(
    allowed_tools=["Bash"],
    hooks={
        "PreToolUse": [
            HookMatcher(matcher="Bash", hooks=[check_bash_command]),
        ],
    }
)

async with ClaudeSDKClient(options=options) as client:
    # Test 1: Command with forbidden pattern (will be blocked)
    await client.query("Run the bash command: ./foo.sh --help")
    async for msg in client.receive_response():
        print(msg)

    print("\n" + "=" * 50 + "\n")

    # Test 2: Safe command that should work
    await client.query("Run the bash command: echo 'Hello from hooks example!'")
    async for msg in client.receive_response():
        print(msg)

错误处理Error Handling
from claude_agent_sdk import (
    ClaudeSDKError,      # Base error
    CLINotFoundError,    # Claude Code not installed
    CLIConnectionError,  # Connection issues
    ProcessError,        # Process failed
    ResultError,         # Run ended with an error result (subclass of ProcessError)
    CLIJSONDecodeError,  # JSON parsing issues
)

try:
    async for message in query(prompt="Hello"):
        pass
except CLINotFoundError:
    print("Please install Claude Code")
except ResultError as e:
    # The CLI reported a terminal error result (also yielded as the final
    # ResultMessage) and exited. Structured fields are on the exception.
    print(f"Run failed: {e.subtype=} {e.terminal_reason=} {e.api_error_status=}")
    print(e.result or e.errors)
except ProcessError as e:
    print(f"Process failed with exit code: {e.exit_code}")
except CLIJSONDecodeError as e:
    print(f"Failed to parse response: {e}")
