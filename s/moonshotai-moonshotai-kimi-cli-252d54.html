Migrate to Kimi Code CLI迁移至 Kimi Code CLI
Install Kimi Code CLI:
安装 Kimi Code CLI：
   # macOS / Linux
   curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
   # Windows (PowerShell)
   irm https://code.kimi.com/kimi-code/install.ps1 | iex
Also available via Homebrew (`brew install kimi-code`) and npm (`npm install -g @moonshot-ai/kimi-code`).
也可通过 Homebrew（`brew install kimi-code`）和 npm（`npm install -g @moonshot-ai/kimi-code`）安装。
Open a new terminal and run `kimi`. On first launch, it detects your Kimi CLI data in `~/.kimi/` and offers to migrate your config, MCP servers, input history, and sessions. You can also run `kimi migrate` at any time. Your original data in `~/.kimi/` is never modified or deleted.
打开一个新终端并运行 `kimi`。首次启动时，它会检测 `~/.kimi/` 中的 Kimi CLI 数据，并提示你迁移配置、MCP 服务器、输入历史记录和会话。你也可以随时运行 `kimi migrate`。`~/.kimi/` 中的原始数据绝不会被修改或删除。
Run `/login` again, and re-authorize your MCP servers. Login credentials, MCP authorizations, and Kimi CLI plugins are not migrated.
再次运行 `/login`，并重新授权你的 MCP 服务器。登录凭据、MCP 授权和 Kimi CLI 插件不会被迁移。
Uninstall the legacy CLI after migrating, e.g. `uv tool uninstall kimi-cli` or `brew uninstall kimi-cli`.
迁移完成后卸载旧版 CLI，例如运行 `uv tool uninstall kimi-cli` 或 `brew uninstall kimi-cli`。
See the full [migration guide](https://moonshotai.github.io/kimi-code/en/guides/migration) for details.
详情请参阅完整的[迁移指南](https://moonshotai.github.io/kimi-code/en/guides/migration)。

Original README (legacy, for reference only)
原始 README（旧版，仅供参考）
Kimi CLI is an AI agent that runs in the terminal, helping you complete software development tasks and terminal operations. It can read and edit code, execute shell commands, search and fetch web pages, and autonomously plan and adjust actions during execution.
Kimi CLI 是一个在终端中运行的 AI 智能体，可帮助你完成软件开发任务和终端操作。它能够读取和编辑代码、执行 shell 命令、搜索和获取网页，并在执行过程中自主规划和调整操作。
Getting Started入门指南
See [Getting Started](https://moonshotai.github.io/kimi-cli/en/guides/getting-started.html) for how to install and start using Kimi CLI.
有关如何安装并开始使用 Kimi CLI，请参阅[入门指南](https://moonshotai.github.io/kimi-cli/en/guides/getting-started.html)。
Key Features主要功能
Shell command modeShell 命令模式
Kimi CLI is not only a coding agent, but also a shell. You can switch the shell command mode by pressing `Ctrl-X`. In this mode, you can directly run shell commands without leaving Kimi CLI.
Kimi CLI 不仅是一个编程智能体，也是一个 shell。你可以按 `Ctrl-X` 切换 shell 命令模式。在此模式下，你可以直接运行 shell 命令，无需离开 Kimi CLI。
> [!NOTE]
> [!NOTE]
> Built-in shell commands like `cd` are not supported yet.
> 尚不支持 `cd` 等 shell 内置命令。
VS Code extensionVS Code 扩展
Kimi CLI can be integrated with [Visual Studio Code](https://code.visualstudio.com/) via the [Kimi Code VS Code Extension](https://marketplace.visualstudio.com/items?itemName=moonshot-ai.kimi-code).
Kimi CLI 可通过 [Kimi Code VS Code 扩展](https://marketplace.visualstudio.com/items?itemName=moonshot-ai.kimi-code)与 [Visual Studio Code](https://code.visualstudio.com/) 集成。
IDE integration via ACP通过 ACP 与 IDE 集成
Kimi CLI supports [Agent Client Protocol] out of the box. You can use it together with any ACP-compatible editor or IDE.
Kimi CLI 开箱即支持 [Agent Client Protocol]（智能体客户端协议）。你可以将其与任何兼容 ACP 的编辑器或 IDE 配合使用。
[Agent Client Protocol]: https://github.com/agentclientprotocol/agent-client-protocol
[Agent Client Protocol]: https://github.com/agentclientprotocol/agent-client-protocol
To use Kimi CLI with ACP clients, make sure to run Kimi CLI in the terminal and send `/login` to complete the login first. Then, you can configure your ACP client to start Kimi CLI as an ACP agent server with command `kimi acp`.
要将 Kimi CLI 与 ACP 客户端配合使用，请务必先在终端中运行 Kimi CLI，并发送 `/login` 以完成登录。随后，你可以配置 ACP 客户端，使其通过命令 `kimi acp` 将 Kimi CLI 作为 ACP 智能体服务器启动。
For example, to use Kimi CLI with [Zed](https://zed.dev/) or [JetBrains](https://blog.jetbrains.com/ai/2025/12/bring-your-own-ai-agent-to-jetbrains-ides/), add the following configuration to your `~/.config/zed/settings.json` or `~/.jetbrains/acp.json` file:
例如，要将 Kimi CLI 与 [Zed](https://zed.dev/) 或 [JetBrains](https://blog.jetbrains.com/ai/2025/12/bring-your-own-ai-agent-to-jetbrains-ides/) 配合使用，请将以下配置添加到 `~/.config/zed/settings.json` 或 `~/.jetbrains/acp.json` 文件中：
{
  "agent_servers": {
    "Kimi CLI": {
      "type": "custom",
      "command": "kimi",
      "args": ["acp"],
      "env": {}
    }
  }
}
Then you can create Kimi CLI threads in IDE's agent panel.
随后，你便可以在 IDE 的智能体面板中创建 Kimi CLI 会话线程。
Zsh integrationZsh 集成
You can use Kimi CLI together with Zsh, to empower your shell experience with AI agent capabilities.
你可以将 Kimi CLI 与 Zsh 配合使用，为 shell 使用体验增添 AI 智能体能力。
Install the [zsh-kimi-cli](https://github.com/MoonshotAI/zsh-kimi-cli) plugin via:
通过以下方式安装 [zsh-kimi-cli](https://github.com/MoonshotAI/zsh-kimi-cli) 插件：
git clone https://github.com/MoonshotAI/zsh-kimi-cli.git \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/kimi-cli
> [!NOTE]
> [!NOTE]
> If you are using a plugin manager other than Oh My Zsh, you may need to refer to the plugin's README for installation instructions.
> 如果你使用的是 Oh My Zsh 以外的插件管理器，可能需要参阅该插件的 README 以了解安装说明。
Then add `kimi-cli` to your Zsh plugin list in `~/.zshrc`:
随后，将 `kimi-cli` 添加到 `~/.zshrc` 中的 Zsh 插件列表：
plugins=(... kimi-cli)
After restarting Zsh, you can switch to agent mode by pressing `Ctrl-X`.
重启 Zsh 后，你可以按 `Ctrl-X` 切换到智能体模式。
MCP supportMCP 支持
Kimi CLI supports MCP (Model Context Protocol) tools.
Kimi CLI 支持 MCP（模型上下文协议，Model Context Protocol）工具。
**`kimi mcp` sub-command group**
**`kimi mcp` 子命令组**
You can manage MCP servers with `kimi mcp` sub-command group. For example:
你可以使用 `kimi mcp` 子命令组管理 MCP 服务器。例如：
# Add streamable HTTP server:
kimi mcp add --transport http context7 https://mcp.context7.com/mcp --header "CONTEXT7_API_KEY: ctx7sk-your-key"

# Add streamable HTTP server with OAuth authorization:
kimi mcp add --transport http --auth oauth linear https://mcp.linear.app/mcp

# Add stdio server:
kimi mcp add --transport stdio chrome-devtools -- npx chrome-devtools-mcp@latest

# List added MCP servers:
kimi mcp list

# Remove an MCP server:
kimi mcp remove chrome-devtools

# Authorize an MCP server:
kimi mcp auth linear
**Ad-hoc MCP configuration**
**临时 MCP 配置**
Kimi CLI also supports ad-hoc MCP server configuration via CLI option.
Kimi CLI 还支持通过 CLI 选项临时配置 MCP 服务器。
Given an MCP config file in the well-known MCP config format like the following:
给定一个采用通用 MCP 配置格式的 MCP 配置文件，如下所示：
{
  "mcpServers": {
    "context7": {
      "url": "https://mcp.context7.com/mcp",
      "headers": {
        "CONTEXT7_API_KEY": "YOUR_API_KEY"
      }
    },
    "chrome-devtools": {
      "command": "npx",
      "args": ["-y", "chrome-devtools-mcp@latest"]
    }
  }
}
Run `kimi` with `--mcp-config-file` option to connect to the specified MCP servers:
运行 `kimi` 时使用 `--mcp-config-file` 选项，以连接到指定的 MCP 服务器：
kimi --mcp-config-file /path/to/mcp.json

Development开发
To develop Kimi CLI, run:
要开发 Kimi CLI，请运行：
git clone https://github.com/MoonshotAI/kimi-cli.git
cd kimi-cli

make prepare  # prepare the development environment
Then you can start working on Kimi CLI.
随后，你便可以开始开发 Kimi CLI。
Refer to the following commands after you make changes:
完成修改后，请参考以下命令：
uv run kimi  # run Kimi CLI

make format  # format code
make check  # run linting and type checking
make test  # run tests
make test-kimi-cli  # run Kimi CLI tests only
make test-kosong  # run kosong tests only
make test-pykaos  # run pykaos tests only
make build-web  # build the web UI and sync it into the package (requires Node.js/npm)
make build  # build python packages
make build-bin  # build standalone binary
make help  # show all make targets
Note: `make build` and `make build-bin` automatically run `make build-web` to embed the web UI.
注意：`make build` 和 `make build-bin` 会自动运行 `make build-web`，以嵌入 Web 用户界面。
