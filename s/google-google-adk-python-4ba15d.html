Agent Development Kit (ADK) is a flexible and modular framework that applies
智能体开发工具包（ADK）是一个灵活的模块化框架，将
software development principles to AI agent creation. It is designed to
软件开发原则应用于 AI 智能体的创建。其设计旨在
simplify building, deploying, and orchestrating agent workflows, from simple

任务到复杂系统的各种场景。尽管针对 Gemini 进行了优化，ADK 并不依赖特定模型，

人工介入（human-in-the-loop）和嵌套工作流。

🚀 Installation🚀 安装
Stable Release (Recommended)稳定版本（推荐）
You can install the latest stable version of ADK using `pip`:
你可以使用 `pip` 安装 ADK 的最新稳定版本：
pip install google-adk
**Requirements:** Python 3.11+.
**要求：**Python 3.11+。
For transitive dependency protection, we recommend installing with our companion
为防范传递依赖带来的风险，我们建议安装时使用我们配套的
constraints files (for python 3.11 to 3.15).
约束文件（适用于 python 3.11 至 3.15）。
Choose the constraints file matching your Python version:
选择与你的 Python 版本相匹配的约束文件：
# For example, for Python 3.11
curl -o constraints-3.11.txt https://raw.githubusercontent.com/google/adk-python/main/constraints-3.11.txt
pip install google-adk -c constraints-3.11.txt
rm constraints-3.11.txt
To install optional integrations, you can use the following command:
要安装可选集成组件，可以使用以下命令：
pip install "google-adk[extensions]"
The release cadence is roughly bi-weekly.
发布频率约为每两周一次。
Development Version开发版本
Bug fixes and new features are merged into the main branch on GitHub first. If you need access to changes that haven't been included in an official PyPI release yet, you can install directly from the main branch:
错误修复和新功能会先合并到 GitHub 上的主分支。如果你需要使用尚未纳入 PyPI 正式版本的更改，可以直接从主分支安装：
pip install git+https://github.com/google/adk-python.git@main
Note: The development version is built directly from the latest code commits. While it includes the newest fixes and features, it may also contain experimental changes or bugs not present in the stable release. Use it primarily for testing upcoming changes or accessing critical fixes before they are officially released.
注意：开发版本直接基于最新提交的代码构建。虽然它包含最新的修复和功能，但也可能包含稳定版本中没有的实验性更改或错误。它主要用于测试即将发布的更改，或在关键修复正式发布之前使用这些修复。
Quick Start快速入门
> **Beginner Note:** ADK applications are built using two main classes:
> **初学者须知：**ADK 应用程序使用两个主要的类构建：
> **`Agent`** (defines an AI's instructions, tools, and behavior) and
> **`Agent`**（定义 AI 的指令、工具和行为）以及
> **`Workflow`** (orchestrates agents and tasks in a graph-based flow).
> **`Workflow`**（在基于图的流程中编排智能体和任务）。
Agent智能体
from google.adk import Agent

root_agent = Agent(
    name="greeting_agent",
    model="gemini-3.5-flash",
    instruction="You are a helpful assistant. Greet the user warmly.",
)
Workflow工作流
from google.adk import Agent, Workflow

generate_fruit_agent = Agent(
    name="generate_fruit_agent",
    instruction="Return the name of a random fruit. Return only the name.",
)

generate_benefit_agent = Agent(
    name="generate_benefit_agent",
    instruction="Tell me a health benefit about the specified fruit.",
)

root_agent = Workflow(
    name="root_agent",
    edges=[("START", generate_fruit_agent, generate_benefit_agent)],
)
Run Locally在本地运行
# Interactive CLI
adk run path/to/my_agent

# Web UI (supports multi-agent directories or pointing directly to a single agent folder)
adk web path/to/agents_dir
