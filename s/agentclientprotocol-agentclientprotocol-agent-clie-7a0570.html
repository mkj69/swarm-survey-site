智能体客户端协议（Agent Client Protocol）Agent Client Protocol
智能体客户端协议（ACP）规范了_代码编辑器_（用于查看和编辑源代码的交互式程序）与_编码智能体_（使用生成式 AI 自主修改代码的程序）之间的通信。 The Agent Client Protocol (ACP) standardizes communication between _code editors_ (interactive programs for viewing and editing source code) and _coding agents_ (programs that use generative AI to autonomously modify code).
更多信息请参阅 [agentclientprotocol.com](https://agentclientprotocol.com/)。 Learn more at [agentclientprotocol.com](https://agentclientprotocol.com/).
Rust crate 与模式制品Rust Crate and Schema Artifacts
本仓库根目录下的 Rust crate 是 [`agent-client-protocol-schema`](https://crates.io/crates/agent-client-protocol-schema)。 This repository's root Rust crate is [`agent-client-protocol-schema`](https://crates.io/crates/agent-client-protocol-schema). 它提供 ACP 线上消息的 Rust 数据模型，包括请求、响应、通知、JSON-RPC 信封以及协议版本类型。 It provides the Rust data model for ACP wire messages, including request, response, notification, JSON-RPC envelope, and protocol-version types. 当你需要直接访问 ACP 协议类型、面向模式的工具或代码生成输入时，请使用此 crate。 Use this crate when you need direct access to ACP protocol types, schema-oriented tooling, or code generation inputs.
如果你正在用 Rust 实现 ACP 智能体或客户端，请从更高层的 [`agent-client-protocol`](https://crates.io/crates/agent-client-protocol) 运行时 crate 入手。 If you are implementing a Rust ACP agent or client, start with the higher-level [`agent-client-protocol`](https://crates.io/crates/agent-client-protocol) runtime crate instead. 该 crate 为 ACP 集成提供客户端和智能体的运行时 API；本模式 crate 则提供更底层的协议类型接口。 That crate provides the client and agent runtime APIs for ACP integrations; this schema crate is the lower-level protocol type surface.
生成的 JSON Schema 制品位于 [`schema/v1`](./schema/v1/) 和 [`schema/v2`](./schema/v2/)。 Generated JSON Schema artifacts live in [`schema/v1`](./schema/v1/) and [`schema/v2`](./schema/v2/). 发布模式版本时，带版本号的 `.json` 文件也会作为附件添加到对应的 [`schema-v*` GitHub 发布版本](https://github.com/agentclientprotocol/agent-client-protocol/releases)中；对于 SDK 生成器和其他发布自动化工具，推荐从此处下载。 When a schema release is published, the versioned `.json` files are also attached to the corresponding [`schema-v*` GitHub release](https://github.com/agentclientprotocol/agent-client-protocol/releases), which is the recommended download surface for SDK generators and other release automation.
版本管理Versioning
Rust crate 版本和 JSON Schema 发布版本分别描述 Rust crate 和 JSON Schema 制品本身的版本。 The Rust crate version and JSON Schema release versions describe the Rust crate and JSON Schema artifacts themselves. Rust crate 发布到 crates.io，而带版本号的 JSON Schema 文件则作为附件添加到 GitHub 发布版本中，并不以 crate 的形式发布。 The Rust crate is published to crates.io, while the versioned JSON Schema files are attached to GitHub releases rather than published as crates. 这些版本遵循相应制品的兼容性预期，涵盖 Rust API、生成的模式结构、制品布局，以及下游 SDK 或代码生成器可能使用的其他细节。 These versions follow the compatibility expectations of those artifacts: Rust APIs, generated schema structure, artifact layout, and other details that downstream SDKs or code generators may consume.
**当前稳定的 ACP 协议版本为 `1`。** **The current stable ACP protocol version is `1`.**
ACP 的线上兼容性由在 `initialize` 期间通过 `protocolVersion` 交换的协议版本单独决定。 ACP wire compatibility is determined separately by the protocol version exchanged during `initialize` via `protocolVersion`. 带版本号的 `schema/*/meta*.json` 文件中的 `version` 字段也描述了相应模式所表示的 ACP 协议版本。 The `version` field in the versioned `schema/*/meta*.json` files also describes the ACP protocol version that the corresponding schema represents.
这意味着，两个版本的 JSON Schema 制品可以描述同一个线上兼容的 ACP 协议版本，同时为 SDK 生成器提供不同的模式结构。 This means two versions of the JSON Schema artifacts can describe the same wire-compatible ACP protocol version while having different schema structure for SDK generators. 例如，某个发布版本可能改变 JSON Schema 中定义的组织方式、命名方式或输出方式，从而影响下游代码生成，但不会改变 ACP 客户端与智能体之间交换的 JSON 消息。 For example, a release might change how definitions are organized, named, or emitted in the JSON Schema in a way that affects downstream code generation without changing the JSON messages exchanged by ACP clients and agents.
使用方不应仅根据 crate 或模式的发布版本来推断线上兼容性。 Consumers should not infer wire compatibility from the crate or schema release version alone. 请使用协商确定的 `protocolVersion` 来判断 ACP 线上协议的结构及其兼容性破坏级别。 Use the negotiated `protocolVersion` to determine the ACP wire protocol shape and breaking-compatibility level. 在同一协议版本内，请根据交换的能力信息来判断支持哪些可选的 ACP 消息和功能。 Within a protocol version, use the exchanged capabilities to decide which optional ACP messages and features are supported. 请使用制品版本来管理与本仓库的 Rust 和模式输出之间的兼容性。 Use artifact versions to manage compatibility with this repository's Rust and schema outputs.
