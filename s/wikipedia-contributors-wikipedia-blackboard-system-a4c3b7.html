黑板系统（blackboard system）是一种基于黑板架构模型的人工智能方法，其中，一组具有不同专长的知识源从问题描述出发，迭代更新一个称为“黑板”的公共知识库，直至得到解决方案。 A blackboard system is an artificial intelligence approach based on the blackboard architectural model, where a common knowledge base, the "blackboard", is iteratively updated by a diverse group of specialist knowledge sources, starting with a problem specification and ending with a solution. 当某个知识源的内部约束与黑板状态相匹配时，该知识源便将一个局部解写入黑板，以更新黑板。 Each knowledge source updates the blackboard with a partial solution when its internal constraints match the blackboard state. 通过这种方式，各个专家协同解决问题。 In this way, the specialists work together to solve the problem. 黑板模型最初旨在处理复杂且定义不明确的问题，这类问题的解决方案由各个局部解汇总而成。 The blackboard model was originally designed as a way to handle complex, ill-defined problems, where the solution is the sum of its parts.
比喻Metaphor
以下情境提供了一个简单的比喻，有助于理解黑板的运作方式： The following scenario provides a simple metaphor that gives some insight into how a blackboard functions:
一组专家坐在一间配有大黑板的房间里。 A group of specialists are seated in a room with a large blackboard. 他们以团队形式集思广益，寻求问题的解决方案，并将黑板作为协同制定解决方案的工作空间。 They work as a team to brainstorm a solution to a problem, using the blackboard as the workplace for cooperatively developing the solution.
当问题的具体要求被写到黑板上时，讨论便开始了。 The session begins when the problem specifications are written onto the blackboard. 所有专家都注视着黑板，寻找机会，将自己的专业知识应用于逐步形成的解决方案。 The specialists all watch the blackboard, looking for an opportunity to apply their expertise to the developing solution. 当有人在黑板上写下的内容使另一位专家能够运用其专业知识时，后者便将自己的贡献记录在黑板上，希望由此使其他专家也能进一步运用各自的专业知识。 When someone writes something on the blackboard that allows another specialist to apply their expertise, the second specialist records their contribution on the blackboard, hopefully enabling other specialists to then apply their expertise. 向黑板添加贡献的这一过程会持续进行，直到问题得到解决。 This process of adding contributions to the blackboard continues until the problem has been solved.
组成部分Components
黑板系统应用由三个主要部分组成 A blackboard-system application consists of three major components
称为知识源（knowledge sources，KSs）的专家软件模块。 The software specialist modules, which are called knowledge sources (KSs). 与黑板前的人类专家一样，每个知识源都提供应用所需的特定专业知识。 Like the human experts at a blackboard, each knowledge source provides specific expertise needed by the application.
黑板，即用于存放问题、局部解、建议以及各方所贡献信息的共享存储库。 The blackboard, a shared repository of problems, partial solutions, suggestions, and contributed information. 黑板可以被视为一个动态“文库”，其中收录了其他知识源最近“发布”的、针对当前问题的贡献。 The blackboard can be thought of as a dynamic "library" of contributions to the current problem that have been recently "published" by other knowledge sources.
控制外壳（control shell），负责控制系统中问题求解活动的流程。 The control shell, which controls the flow of problem-solving activity in the system. 正如热切的人类专家需要一位主持人，以防他们在争抢粉笔时相互踩踏，KSs 也需要一种机制，以最有效且协调一致的方式组织它们的运作。 Just as the eager human specialists need a moderator to prevent them from trampling each other in a mad dash to grab the chalk, KSs need a mechanism to organize their use in the most effective and coherent fashion. 在黑板系统中，这一机制由控制外壳提供。 In a blackboard system, this is provided by the control shell.
可学习任务建模语言Learnable Task Modeling Language
黑板系统是多智能体系统中的中心空间。 A blackboard system is the central space in a multi-agent system. 它用于描述世界，并充当智能体之间的通信平台。 It's used for describing the world as a communication platform for agents. 要在计算机程序中实现黑板，需要一种能够存储事实的机器可读表示法。 To realize a blackboard in a computer program, a machine readable notation is needed in which facts can be stored. 一种尝试是使用 SQL 数据库，另一种选择是可学习任务建模语言（Learnable Task Modeling Language，LTML）。 One attempt in doing so is a SQL database, another option is the Learnable Task Modeling Language (LTML). LTML 规划语言的语法与 PDDL 相似，但增加了控制结构和 OWL-S 模型等额外功能。 The syntax of the LTML planning language is similar to PDDL, but adds extra features like control structures and OWL-S models. LTML 于 2007 年开发，是一个规模大得多的项目 POIROT（Plan Order Induction by Reasoning from One Trial，即通过单次试验推理归纳计划顺序）的一部分，该项目是一个用于过程挖掘的示范学习框架。 LTML was developed in 2007 as part of a much larger project called POIROT (Plan Order Induction by Reasoning from One Trial), which is a Learning from demonstrations framework for process mining. 在 POIROT 中，计划轨迹和假设以 LTML 语法存储，用于创建语义 Web 服务。 In POIROT, Plan traces and hypotheses are stored in the LTML syntax for creating semantic web services.
下面是一个简单的例子：一名人类用户正在计算机游戏中执行一个工作流。 Here is a small example: A human user is executing a workflow in a computer game. 用户按下一些按钮，并与游戏引擎交互。 The user presses some buttons and interacts with the game engine. 在用户与游戏交互的过程中，会生成一条计划轨迹。 While the user interacts with the game, a plan trace is created. 这意味着用户的操作会被存储在日志文件中。 That means the user's actions are stored in a logfile. 日志文件被转换为一种机器可读的表示形式，并添加语义属性以丰富其内容。 The logfile gets transformed into a machine readable notation which is enriched by semantic attributes. 结果是一个采用 LTML 语法的文本文件，该文件被放置到黑板上。 The result is a textfile in the LTML syntax which is put on the blackboard. 智能体（黑板系统中的软件程序）能够解析 LTML 语法。 Agents (software programs in the blackboard system) are able to parse the LTML syntax.
实现Implementations
我们首先考察两个奠基性的黑板系统——BB1 和 GBB——然后探讨当代的实现及其应用。 We first examine two foundational blackboard systems—BB1 and GBB—before exploring contemporary implementations and their applications.
BB1 黑板架构最初受到有关人类如何规划在一次出行中完成多项任务的研究的启发，该研究为海军研究办公室开展，将任务规划用作战术规划的简化示例。 The BB1 blackboard architecture was originally inspired by studies of how humans plan to perform multiple tasks in a trip, used task-planning as a simplified example of tactical planning for the Office of Naval Research. Hayes-Roth & Hayes-Roth 发现，将人类规划建模为一种机会驱动的过程更为贴切，这与当时主要采用自顶向下方式的规划器形成对比： Hayes-Roth & Hayes-Roth found that human planning was more closely modeled as an opportunistic process, in contrast to the primarily top-down planners used at the time:
尽管我们的规划观与逐次求精模型并不矛盾，但二者仍有一些不同。 While not incompatible with successive-refinement models, our view of planning is somewhat different. 我们同样假定，规划过程在由时间维度和抽象维度定义的二维规划空间中进行。 We share the assumption that planning processes operate in a two-dimensional planning space defined on time and abstraction dimensions. 然而，我们假定，人的规划活动在很大程度上是机会驱动的。 However, we assume that people's planning activity is largely opportunistic. 也就是说，在这一过程的每个时点，规划者当前的决策和观察都会提示各种推进计划的机会。 That is, at each point in the process, the planner's current decisions and observations suggest various opportunities for plan development. 规划者随后的决策会跟进其中选定的机会。 The planner's subsequent decisions follow up on selected opportunities. 有时，这些决策序列会沿着有序的路径展开，形成上述条理清晰的自顶向下扩展。 Sometimes, these decision-sequences follow an orderly path and produce a neat top-down expansion as described above. 然而，某些决策和观察也可能提示一些不那么有序的计划推进机会。 However, some decisions and observations might also suggest less orderly opportunities for plan development.
BB1 的一项关键创新是将这种机会驱动的规划模型应用于自身的控制，所使用的黑板模型与其解决领域问题时采用的增量式、机会驱动的问题求解模型相同。 A key innovation of BB1 was that it applied this opportunistic planning model to its own control, using the same blackboard model of incremental, opportunistic, problem-solving that was applied to solve domain problems. 随后，利用控制知识源进行的元层推理便可监测规划和问题求解是否按预期进行，或是否陷入停滞。 Meta-level reasoning with control knowledge sources could then monitor whether planning and problem-solving were proceeding as expected or stalled. 如果陷入停滞，BB1 可以随着条件的变化（例如正在考虑的目标或剩余时间的变化）从一种策略切换到另一种策略。 If stalled, BB1 could switch from one strategy to another as conditions – such as the goals being considered or the time remaining – changed. BB1 曾应用于多个领域：施工现场规划、根据 X 射线晶体学推断蛋白质的 3-D 结构、智能教学系统以及实时患者监测。 BB1 was applied in multiple domains: construction site planning, inferring 3-D protein structures from X-ray crystallography, intelligent tutoring systems, and real-time patient monitoring.
BB1 还支持为广泛的问题类别设计领域通用的语言框架。 BB1 also allowed domain-general language frameworks to be designed for wide classes of problems. 例如，ACCORD 语言框架定义了一种解决配置问题的特定方法。 For example, the ACCORD language framework defined a particular approach to solving configuration problems. 这种问题求解方法通过逐一添加对象和约束，增量式地构建解决方案。 The problem-solving approach was to incrementally assemble a solution by adding objects and constraints, one at a time. ACCORD 语言框架中的动作以简短的类英语命令或句子的形式呈现，用于指定优先执行的动作、触发 KSes 的事件、执行 KS 动作的前置条件，以及用于丢弃不再相关的 KS 动作的消除条件。 Actions in the ACCORD language framework appear as short English-like commands or sentences for specifying preferred actions, events to trigger KSes, preconditions to run a KS action, and obviation conditions to discard a KS action that is no longer relevant.
GBB 注重效率，而 BB1 则更注重复杂推理和机会驱动的规划。 GBB focused on efficiency, in contrast to BB1, which focused more on sophisticated reasoning and opportunistic planning. GBB 允许黑板具有多个维度，各维度既可以有序，也可以无序，并进一步提高模式匹配的效率，从而提升整体效率。 GBB improves efficiency by allowing blackboards to be multi-dimensional, where dimensions can be either ordered or not, and then by increasing the efficiency of pattern matching. GBB1 是 GBB 的控制外壳之一，它实现了 BB1 风格的控制，同时改进了效率。 GBB1, one of GBB's control shells implements BB1's style of control while adding efficiency improvements.
其他知名的早期学术黑板系统包括 Hearsay II 语音识别系统，以及 Douglas Hofstadter 的 Copycat 和 Numbo 项目。 Other well-known of early academic blackboard systems are the Hearsay II speech recognition system and Douglas Hofstadter's Copycat and Numbo projects.

Adobe Acrobat Capture（现已停用），它使用黑板系统对图像页面进行分解和识别，以理解页面上的对象、文本和字体。 Adobe Acrobat Capture (now discontinued), as it used a blackboard system to decompose and recognize image pages to understand the objects, text, and fonts on the page. 该功能目前以“OCR 文本识别”的名称内置于 Adobe Acrobat 零售版中。 This function is currently built into the retail version of Adobe Acrobat as "OCR Text Recognition". 一种用于波斯语文本的类似 OCR 黑板系统的详细资料已进入公有领域。 Details of a similar OCR blackboard for Farsi text are in the public domain.
黑板系统经常用于许多军事 C4ISTAR 系统中，以检测和跟踪目标。 Blackboard systems are used routinely in many military C4ISTAR systems for detecting and tracking objects. 当前应用的另一个例子是游戏 AI，黑板系统在该领域被视为一种标准 AI 工具，用于帮助为电子游戏添加 AI。 Another example of current use is in Game AI, where they are considered a standard AI tool to help with adding AI to video games.
近期进展Recent developments
在现代贝叶斯机器学习框架下，已有研究构建了类黑板系统，利用智能体添加和删除贝叶斯网络节点。 Blackboard-like systems have been constructed within modern Bayesian machine learning settings, using agents to add and remove Bayesian network nodes. 在这些“贝叶斯黑板”系统中，启发式方法可以被解释为在可能结构空间中进行 Metropolis Hastings 采样时的提议和接受操作，从而获得更严格的概率意义。 In these 'Bayesian Blackboard' systems, the heuristics can acquire more rigorous probabilistic meanings as proposal and acceptances in Metropolis Hastings sampling though the space of possible structures. 反过来，利用这些映射，现有的结构空间上的 Metropolis-Hastings 采样器如今也可以被视为黑板系统的某种形式，即使其作者并未如此命名。 Conversely, using these mappings, existing Metropolis-Hastings samplers over structural spaces may now thus be viewed as forms of blackboard systems even when not named as such by the authors. 例如，这类采样器常见于音乐转录算法中。 Such samplers are commonly found in musical transcription algorithms for example.
黑板系统还被用于构建大规模的媒体内容标注智能系统，使传统社会科学研究中的部分工作实现自动化。 Blackboard systems have also been used to build large-scale intelligent systems for the annotation of media content, automating parts of traditional social science research. 在这一领域，将各种 AI 算法集成到单一智能系统中的问题自然会出现，而黑板提供了一种方式，使一组分布式、模块化的自然语言处理算法能够各自在一个中央空间中标注数据，而无须协调彼此的行为。 In this domain, the problem of integrating various AI algorithms into a single intelligent system arises spontaneously, with blackboards providing a way for a collection of distributed, modular natural language processing algorithms to each annotate the data in a central space, without needing to coordinate their behavior.
