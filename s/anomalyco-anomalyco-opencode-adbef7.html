Installation安装
# YOLO
curl -fsSL https://opencode.ai/v2/install | bash

# Package managers
npm i -g @opencode/cli@latest      # or bun/pnpm/yarn
brew install anomalyco/tap/opencode-v2 # macOS and Linux (recommended, always up to date)
brew install opencode              # macOS and Linux (official brew formula, updated less)
sudo pacman -S opencode            # Arch Linux (Stable)
paru -S opencode-beta              # Arch Linux (Latest from AUR)
mise use -g opencode               # Any OS
nix run github:anomalyco/opencode  # Nix
> [!TIP]
> [!TIP]
> Remove versions older than 0.1.x before installing.
> 安装前，请卸载早于 0.1.x 的版本。

Agents智能体
OpenCode includes two built-in agents you can switch between with the `Tab` key.
OpenCode 包含两个内置智能体，可通过 `Tab` 键切换。
**build** - Default, full-access agent for development work
**build** - 默认智能体，拥有完整访问权限，用于开发工作
**plan** - Read-only agent for analysis and code exploration
**plan** - 只读智能体，用于分析和代码探索
Denies file edits by default
默认禁止编辑文件
Asks permission before running bash commands
运行 bash 命令前会请求许可
Ideal for exploring unfamiliar codebases or planning changes
非常适合探索不熟悉的代码库或规划更改
Also included is a **general** subagent for complex searches and multistep tasks.
此外，还包含一个 **general** 子智能体，用于复杂搜索和多步骤任务。
This is used internally and can be invoked using `@general` in messages.
该子智能体在内部使用，也可在消息中通过 `@general` 调用。
Learn more about [agents](https://opencode.ai/v2/docs/agents).
进一步了解[智能体（agents）](https://opencode.ai/v2/docs/agents)。
