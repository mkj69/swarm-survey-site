什么是 MCP？What is MCP?
[模型上下文协议](https://modelcontextprotocol.io)使你能够构建服务器，以安全、标准化的方式向大语言模型（LLM）应用提供数据和功能。 The [Model Context Protocol](https://modelcontextprotocol.io) lets you build servers that expose data and functionality to LLM applications in a secure, standardized way. 可以将其理解为一种专为 LLM 交互设计的 Web API。 Think of it like a web API, but designed for LLM interactions. 使用此 SDK，你可以： With this SDK you can:
**构建 MCP 服务器**，向任何 MCP 宿主提供工具、资源和提示词 **Build MCP servers** that expose tools, resources, and prompts to any MCP host
**构建 MCP 客户端**，连接到任何 MCP 服务器 **Build MCP clients** that connect to any MCP server
支持所有标准传输方式：stdio、Streamable HTTP 和 SSE Speak every standard transport: stdio, Streamable HTTP, and SSE

安装Installation
uv add "mcp[cli]"      # or: pip install "mcp[cli]"
`cli` 可选依赖在 SDK 的基础上增加了 `mcp` 命令行工具（`mcp dev`、`mcp run`、`mcp install`）；如果不需要该工具，只安装 `mcp` 即可。 The `cli` extra adds the `mcp` command-line tool (`mcp dev`, `mcp run`, `mcp install`) on top of the SDK; install plain `mcp` if you don't need it. 对于一次性命令，无须创建项目即可使用 `uv run --with "mcp[cli]" mcp ...`。 For one-off commands, `uv run --with "mcp[cli]" mcp ...` works without a project.
用 15 行代码构建服务器A server in 15 lines
创建一个 `server.py`： Create a `server.py`: 
from mcp.server import MCPServer

mcp = MCPServer("Demo")


@mcp.tool()
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b


@mcp.resource("greeting://{name}")
def greeting(name: str) -> str:
    """Greet someone by name."""
    return f"Hello, {name}!"
_完整示例：[docs_src/index/tutorial001.py](https://github.com/modelcontextprotocol/python-sdk/blob/main/docs_src/index/tutorial001.py)_ _Full example: [docs_src/index/tutorial001.py](https://github.com/modelcontextprotocol/python-sdk/blob/main/docs_src/index/tutorial001.py)_
这就是一个完整的 MCP 服务器：包含一个工具和一个模板化资源。 That's a complete MCP server: one tool, one templated resource. 在 [MCP Inspector](https://github.com/modelcontextprotocol/inspector) 中打开它： Open it in the [MCP Inspector](https://github.com/modelcontextprotocol/inspector): 
uv run mcp dev server.py
以 `a=1`、`b=2` 调用 `add`，即可得到返回值 `3`。 Call `add` with `a=1`, `b=2` and you get `3` back.
请注意，你**没有**编写以下内容：JSON Schema（`a: int, b: int` _就是_模式）、请求解析代码、验证代码或协议处理代码。 Notice what you did **not** write: no JSON Schema (`a: int, b: int` _is_ the schema), no request parsing, no validation code, no protocol handling. 只需两个带类型提示的 Python 函数和一个文档字符串。 Two type-hinted Python functions and a docstring.
接下来可按照[入门指南](https://py.sdk.modelcontextprotocol.io/get-started/)继续。 [Get started](https://py.sdk.modelcontextprotocol.io/get-started/) takes it from here.
用 10 行代码构建客户端A client in 10 lines
同一个包也提供了完整的 MCP **客户端**。 The same package is a full MCP **client**. 通过 HTTP 运行 `server.py` 并提供服务： Serve `server.py` over HTTP: 
uv run mcp run server.py --transport streamable-http
然后让一个 `Client` 连接到它： then point a `Client` at it: 
import asyncio

from mcp import Client


async def main() -> None:
    async with Client("http://localhost:8000/mcp") as client:
        result = await client.call_tool("add", {"a": 1, "b": 2})
        print(result.structured_content)  # {'result': 3}


asyncio.run(main())
使用 URL 表示采用 Streamable HTTP，即部署时使用的传输方式。`Client` 也可以将本地服务器作为 stdio 子进程启动，或接受任何自定义传输方式；其余内容参见[客户端](https://py.sdk.modelcontextprotocol.io/client/)。 A URL means Streamable HTTP, the transport you deploy. `Client` can also launch a local server as a stdio subprocess or take any custom transport; [Clients](https://py.sdk.modelcontextprotocol.io/client/) has the rest.
