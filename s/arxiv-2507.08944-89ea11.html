一句话

M1-Parallel 通过让多个智能体团队同时尝试同一任务，用额外推理成本换取更短等待时间；收益来自执行路径的差异，而非把串行步骤直接并行化。

主要内容

  • 框架基于 Magentic-One，每个团队独立规划、调用工具并动态调整路径，中央管理器通过异步消息协调执行。
  • 两种模式对应不同目标：早停模式采用最先返回的答案并终止其他团队；聚合模式收集多个答案及执行日志，再生成最终答案。
  • 在 GAIA 上，三个团队早停相较单团队提速 1.6—1.8 倍，任务完成率保持相当，推理费用升至 1.7—1.8 倍。五个团队提速 1.8—2.2 倍，费用升至 2.2—2.6 倍，新增团队带来的收益已趋缓。
  • 三团队聚合在三个难度等级平均分别多解出 3、5、1 道题，但通常等待更久，费用达到基线的 2.5—3.4 倍。
  • 显式要求生成不同计划没有明确优于重复采样；作者观察到，为追求差异而添加的多余步骤可能拖累表现。
  • 聚合器仍是瓶颈：读取日志的 LLM 通常优于多数投票，但仍落后于“只要任一答案正确就算成功”的理想上界。

证据与可信度

这是论文作者报告的实验结果，所给正文覆盖方法、实验与结论，但抓取内容未呈现图表中的全部原始数值，未作独立核验。

实验使用 GAIA 验证集，三个等级分别有 53、86、26 道题；主实验每题运行 5 次，图中报告 95% 置信区间。基础模型为 GPT-4o 指定版本。延迟按提交任务至返回答案的墙钟时间测量；费用依据输入、输出 token 和当时 API 单价估算，仅代表 LLM 推理费用。

“最高 2.2 倍”对应五团队配置，不能当作默认三团队的普遍收益。另一本地 Qwen3-32B 实验受单卡内存限制，未真正并发执行，其延迟收益由独立运行的最小、最大耗时推算，属于理想并发条件下的估计。早停也没有正确性验证器，完成率相当不意味着每次最快返回的答案都正确。

对 swarm scaling 的意义

它展示了团队级冗余探索的价值：即使任务内部有严格依赖，也能通过并行尝试完整路径降低等待时间。扩容是否有效，取决于路径耗时差异、停止规则和答案选择能力。

结果同时提示扩展边界：团队数增加并不带来线性加速；若目标是提高正确率，聚合器能否识别已有正确答案，比单纯增加候选更关键。强制制造计划差异也不等于有效探索。
