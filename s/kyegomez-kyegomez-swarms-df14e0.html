使用 `max_loops="auto"` 的自主智能体Autonomous Agent with `max_loops="auto"`
设置 `max_loops="auto"` 可让智能体自行判断任务何时完成。 Setting `max_loops="auto"` lets the agent decide for itself when the task is complete. 它会持续推理并采取行动，直到满足停止条件，而不是在固定次数的迭代后停止。 It keeps reasoning and acting until it reaches a stopping condition, rather than halting after a fixed number of iterations. 对于事先无法确定步骤数量的开放式多步骤任务，推荐使用此模式。 This is the recommended mode for open-ended, multi-step tasks where the number of steps isn't known in advance. 
from swarms import Agent

agent = Agent(
    agent_name="Autonomous-Research-Agent",
    agent_description="An autonomous agent that conducts multi-step research independently.",
    system_prompt=(
        "You are an autonomous research agent. Break down complex tasks into steps, "
        "execute each step thoroughly, and signal completion only when the full task is done."
    ),
    model_name="gpt-5.4",
    max_loops="auto",       # Agent decides when it's done; no fixed iteration cap
    autosave=True,
    verbose=True,
)

# The agent will keep looping (planning, executing, and reflecting) until it
# determines the task is fully complete.
result = agent.run(
    "Research the current state of quantum computing, identify the top three "
    "hardware approaches, and summarize the key challenges each faces."
)
print(result)
**何时使用 `max_loops="auto"`：** **When to use `max_loops="auto"`:**
开放式研究或分析任务 Open-ended research or analysis tasks
需要迭代完善的任务（例如，撰写 → 审阅 → 修改） Tasks that require iterative refinement (e.g., write → review → revise)
步骤数量取决于中间结果的任何工作流 Any workflow where the number of steps depends on intermediate results
**何时使用固定的 `max_loops` 值：** **When to use a fixed `max_loops` value:**
对延迟或成本敏感的生产流水线 Latency-sensitive or cost-sensitive production pipelines
步骤数量明确且有界的任务 Tasks with a well-defined, bounded number of steps

一个**智能体群（Swarm）**由多个协同工作的智能体组成。 A **Swarm** consists of multiple agents working together. 这个简单示例创建了一个由两个智能体组成的工作流，用于开展研究并撰写博客文章。 This simple example creates a two-agent workflow for researching and writing a blog post. GraphWorkflowGraphWorkflow
`GraphWorkflow` 将智能体作为有向无环图（Directed Acyclic Graph，DAG）中的节点进行编排。 `GraphWorkflow` orchestrates agents as nodes in a Directed Acyclic Graph (DAG). 每个节点都是一个智能体，每条边都声明一项依赖关系，因此一个节点只有在其所有上游节点都完成后才会运行。 Each node is an agent and each edge declares a dependency, so a node only runs after every upstream node has finished. 拓扑排序可保证执行顺序正确，而相互独立的分支会自动并行运行。 A topological sort guarantees correct execution order, while independent branches run in parallel automatically.
因此，当工作流包含扇出 / 扇入或菱形模式、条件依赖关系，或任何无法用严格线性流程或扁平并行批次表示的结构时，`GraphWorkflow` 都是合适的选择。 This makes `GraphWorkflow` the right choice when your workflow has fan-out / fan-in or diamond patterns, conditional dependencies, or any structure that doesn't fit a strict line or a flat parallel batch. 节点级回调允许你在节点完成时介入处理，以实现流式输出和进度跟踪。 Per-node callbacks let you hook into node completion for streaming and progress tracking. [进一步了解 GraphWorkflow](https://docs.swarms.world/api/graph-workflow) [Learn more about GraphWorkflow](https://docs.swarms.world/api/graph-workflow) 
from swarms import Agent, GraphWorkflow, Node, Edge, NodeType

# Define agents
researcher = Agent(agent_name="Researcher", system_prompt="Research the given topic and produce key findings.", model_name="gpt-5.4")
writer     = Agent(agent_name="Writer",     system_prompt="Write a clear article from the research provided.", model_name="gpt-5.4")
reviewer   = Agent(agent_name="Reviewer",   system_prompt="Review the article for accuracy and clarity.",      model_name="gpt-5.4")
publisher  = Agent(agent_name="Publisher",  system_prompt="Format the final reviewed article for publication.", model_name="gpt-5.4")

# Build the graph: Researcher -> Writer -> Reviewer -> Publisher
workflow = GraphWorkflow()
workflow.add_node(Node(id="researcher", type=NodeType.AGENT, agent=researcher))
workflow.add_node(Node(id="writer",     type=NodeType.AGENT, agent=writer))
workflow.add_node(Node(id="reviewer",   type=NodeType.AGENT, agent=reviewer))
workflow.add_node(Node(id="publisher",  type=NodeType.AGENT, agent=publisher))

workflow.add_edge(Edge(source="researcher", target="writer"))
workflow.add_edge(Edge(source="writer",     target="reviewer"))
workflow.add_edge(Edge(source="reviewer",   target="publisher"))

workflow.set_entry_points(["researcher"])
workflow.set_end_points(["publisher"])

# Run the graph
results = workflow.run("Produce a short article on the rise of small language models.")
print(results)
SwarmRouter：通用智能体群编排器SwarmRouter: The Universal Swarm Orchestrator
`SwarmRouter` 提供统一接口来运行任意类型的智能体群，从而简化复杂工作流的构建。 The `SwarmRouter` simplifies building complex workflows by providing a single interface to run any type of swarm. 你只需更改 `swarm_type` 参数，即可动态选择所需的智能体群，而无需导入和管理不同的智能体群类。 Instead of importing and managing different swarm classes, you can dynamically select the one you need just by changing the `swarm_type` parameter. [阅读完整文档](https://docs.swarms.world/api/swarm-router) [Read the full documentation](https://docs.swarms.world/api/swarm-router)
这使你的代码更简洁、更灵活，让你能够轻松切换不同的多智能体策略。 This makes your code cleaner and more flexible, allowing you to switch between different multi-agent strategies with ease. 下面给出一个完整示例，展示如何定义智能体，然后使用 `SwarmRouter` 以不同的协作策略执行同一任务。 Here's a complete example that shows how to define agents and then use `SwarmRouter` to execute the same task using different collaborative strategies. 
from swarms import Agent, SwarmRouter, SwarmType

# Define a few generic agents
writer = Agent(agent_name="Writer", system_prompt="You are a creative writer.", model_name="gpt-5.4")
editor = Agent(agent_name="Editor", system_prompt="You are an expert editor for stories.", model_name="gpt-5.4")
reviewer = Agent(agent_name="Reviewer", system_prompt="You are a final reviewer who gives a score.", model_name="gpt-5.4")

# The agents and task will be the same for all examples
agents = [writer, editor, reviewer]
task = "Write a short story about a robot who discovers music."

# --- Example 1: SequentialWorkflow ---
# Agents run one after another in a chain: Writer -> Editor -> Reviewer.
print("Running a Sequential Workflow...")
sequential_router = SwarmRouter(swarm_type=SwarmType.SequentialWorkflow, agents=agents)
sequential_output = sequential_router.run(task)
print(f"Final Sequential Output:\n{sequential_output}\n")

# --- Example 2: ConcurrentWorkflow ---
# All agents receive the same initial task and run at the same time.
print("Running a Concurrent Workflow...")
concurrent_router = SwarmRouter(swarm_type=SwarmType.ConcurrentWorkflow, agents=agents)
concurrent_outputs = concurrent_router.run(task)
# This returns a dictionary of each agent's output
for agent_name, output in concurrent_outputs.items():
    print(f"Output from {agent_name}:\n{output}\n")

# --- Example 3: MixtureOfAgents ---
# All agents run in parallel, and a special 'aggregator' agent synthesizes their outputs.
print("Running a Mixture of Agents Workflow...")
aggregator = Agent(
    agent_name="Aggregator",
    system_prompt="Combine the story, edits, and review into a final document.",
    model_name="gpt-5.4"
)
moa_router = SwarmRouter(
    swarm_type=SwarmType.MixtureOfAgents,
    agents=agents,
    aggregator_agent=aggregator, # MoA requires an aggregator
)
aggregated_output = moa_router.run(task)
print(f"Final Aggregated Output:\n{aggregated_output}\n")

GroupChatGroupChat
`GroupChat` 是一种异步群聊机制，由智能体自行决定是否参与回应。 `GroupChat` is an asynchronous, self-selecting groupchat. 所有智能体并行监听；对于每条广播消息，其余每个智能体都会被强制要求调用 `respond(score, message)` 函数，以决定是否参与回应，得分高于 `threshold` 的回复将被广播。 All agents listen in parallel; for each broadcast message, every other agent runs a forced `respond(score, message)` function call to decide whether to chime in, and replies above `threshold` are broadcast. 当已发布的消息数达到 `max_loops`，或没有任何回复的得分超过 `threshold` 时，聊天结束。 The chat ends when `max_loops` messages have been posted or when no reply clears `threshold`. 这里没有固定的发言顺序：多个智能体可以同时回应同一条消息，而保持沉默的智能体则继续保持沉默。 There is no turn order: multiple agents can react to the same message at the same time, and silent agents stay silent. 
from swarms import Agent, GroupChat, RESPOND_TOOL

# Every agent MUST carry RESPOND_TOOL so the chat can ask it whether to speak.

    agent_name="TechOptimist",
    system_prompt="Argue for the benefits of AI in society.",

    max_loops=1,
    persistent_memory=False,
    tools_list_dictionary=[RESPOND_TOOL],
)
tech_critic = Agent(
    agent_name="TechCritic",
    system_prompt="Argue against the unchecked advancement of AI.",
    model_name="gpt-5.4",
    max_loops=1,
    persistent_memory=False,
    tools_list_dictionary=[RESPOND_TOOL],
)

chat = GroupChat(
    agents=[tech_optimist, tech_critic],
    max_loops=10,       # hard cap on total messages posted
    threshold=0.5,      # min decision score (0..1) to publish a reply
)

result = chat.run("Let's discuss the societal impact of artificial intelligence.")
print(result)

社交算法Social Algorithms
**社交算法（Social Algorithms）**提供了一个灵活的框架，用于定义智能体之间的自定义通信模式。 **Social Algorithms** provide a flexible framework for defining custom communication patterns between agents. 你可以将任意社交算法作为可调用对象上传，由它定义通信顺序，使智能体能够以复杂的方式相互交流。 You can upload any arbitrary social algorithm as a callable that defines the sequence of communication, enabling agents to talk to each other in sophisticated ways. from swarms import Agent, SocialAlgorithms

# Define a custom social algorithm
def research_analysis_synthesis_algorithm(agents, task, **kwargs):
    # Agent 1 researches the topic
    research_result = agents[0].run(f"Research: {task}")
    
    # Agent 2 analyzes the research
    analysis = agents[1].run(f"Analyze this research: {research_result}")
    
    # Agent 3 synthesizes the findings
    synthesis = agents[2].run(f"Synthesize: {research_result} + {analysis}")
    
    return {
        "research": research_result,
        "analysis": analysis,
        "synthesis": synthesis
    }

# Create agents
researcher = Agent(
  agent_name="Researcher",
  agent_description="Expert in comprehensive research and information gathering.",
  model_name="gpt-5.4"
)
analyst = Agent(
  agent_name="Analyst",
  agent_description="Specialist in analyzing and interpreting data.",
  model_name="gpt-5.4"
)
synthesizer = Agent(
  agent_name="Synthesizer",
  agent_description="Focused on synthesizing and integrating research insights.",
  model_name="gpt-5.4"
)

# Create social algorithm
social_alg = SocialAlgorithms(
    name="Research-Analysis-Synthesis",
    agents=[researcher, analyst, synthesizer],
    social_algorithm=research_analysis_synthesis_algorithm,
    verbose=True
)

# Run the algorithm
result = social_alg.run("The impact of AI on healthcare")
print(result.final_outputs)
