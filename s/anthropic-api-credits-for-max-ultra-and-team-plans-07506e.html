一句话

Anthropic 将订阅附带额度接入 API 与 agent 开发，但它降低的是试验费用，并不能直接证明 swarm 的并发能力或规模收益。

主要内容

  • Max 每月附带 100 美元，Ultra 为 200 美元；Team 按 Standard 席位每人 20 美元、Premium 席位每人 100 美元汇总，组织每月最高 500 美元，折扣 Team 同样适用。
  • 额度覆盖 Claude API、Managed Agents、Agent SDK 和控制台 Playground；不覆盖 Claude Code、Claude 应用额外用量及其他云平台。
  • 需将订阅关联到一个 Console 组织，新订阅者须满 7 天才能领取。额度按账期发放，年付方案按月发放，到期不结转。
  • 同一组织的所有 API key 和 workspace 共用余额，可用 workspace 支出上限约束项目费用。额度耗尽且无其他余额时，API 请求停止；销售开票组织的超额用量照常计费。
  • 关联后组织至少进入 Start 层级，月额度超过 200 美元则至少进入 Build 层级；附带额度不计入进一步升级层级的条件。

证据与可信度

材料是 Anthropic 官方产品规则说明，金额、适用范围和限制属于厂商公布的条款，非实测结果，未提供独立核验。

文中示例可直接复算：3 个 Standard 加 2 个 Premium 席位，每月为 3×20＋2×100＝260 美元；增加一个 Premium 席位后，下月为 360 美元。页面还称批处理 API 可节省 50% 费用，但没有提供 swarm 场景的成本或性能测试。

对 swarm scaling 的意义

  • 额度池能支持多 agent 原型试验，但多个 agent 会竞争同一余额，增加 API key 并不会增加预算。
  • 月度预算与扩展容量是两回事：额度用量仍计入组织支出上限，速率限制继续适用，不能把附带金额换算成可并发 agent 数。
  • 到期不结转、额度刷新与自然月支出上限重置时间不同，会影响持续实验的排期。
  • 模型选择、重复上下文缓存和非即时任务批处理，是材料给出的降本路径；它没有证明扩大 swarm 后的成功率、吞吐或边际收益。
