Python 如何实现 AI How Python does AI
智能体、实时语音、图像生成、嵌入（embeddings）。 Agents, realtime voice, image generation, embeddings. 每一种模型、每一种接口，均提供端到端类型支持。 Every model, every interface, typed end to end.
**Pydantic AI** 是面向 Python 的 AI SDK：它提供具有类型支持且[可扩展](https://pydantic.dev/docs/ai/guides/extensibility/)的智能体循环，只需替换一个字符串即可切换到[任意模型](https://pydantic.dev/docs/ai/models/overview/)，并在提供商发生故障时[回退到另一个模型](https://pydantic.dev/docs/ai/capabilities/model-fallback/)。 **Pydantic AI** is the Python AI SDK: a typed, [extensible](https://pydantic.dev/docs/ai/guides/extensibility/) agent loop with [every model](https://pydantic.dev/docs/ai/models/overview/) a string swap away, and [another one to fall back to](https://pydantic.dev/docs/ai/capabilities/model-fallback/) when a provider fails. 同一个智能体[可在你需要的任何环境中运行](https://pydantic.dev/docs/ai/overview/interfaces/)：作为 [Web 前端](https://pydantic.dev/docs/ai/integrations/ui/overview/)的后端、在[终端](https://pydantic.dev/docs/ai/integrations/cli/)中、在[语音通话](https://pydantic.dev/docs/ai/realtime/overview/)中、在[持久化后台队列](https://pydantic.dev/docs/ai/capabilities/durable_execution/overview/)中、在 [GitHub Actions](https://pydantic.dev/docs/ai/harness/gh-aw/) 中，或作为一个可调用其 [`run()`](https://pydantic.dev/docs/ai/core-concepts/agent/#running-agents) 方法的普通对象。 The same agent [runs everywhere you need it](https://pydantic.dev/docs/ai/overview/interfaces/): behind a [web frontend](https://pydantic.dev/docs/ai/integrations/ui/overview/), in the [terminal](https://pydantic.dev/docs/ai/integrations/cli/), on a [voice call](https://pydantic.dev/docs/ai/realtime/overview/), on a [durable background queue](https://pydantic.dev/docs/ai/capabilities/durable_execution/overview/), in [GitHub Actions](https://pydantic.dev/docs/ai/harness/gh-aw/), or as a plain object you call [`run()`](https://pydantic.dev/docs/ai/core-concepts/agent/#running-agents) on. 同一套工具还内置了[图像生成](https://pydantic.dev/docs/ai/guides/image-generation/)和[嵌入](https://pydantic.dev/docs/ai/guides/embeddings/)功能。 [Image generation](https://pydantic.dev/docs/ai/guides/image-generation/) and [embeddings](https://pydantic.dev/docs/ai/guides/embeddings/) come in the same box.
**[Pydantic AI Harness](https://pydantic.dev/docs/ai/harness/)** 提供智能体执行复杂、长时间运行任务所需的一切，并以可装配的[能力](https://pydantic.dev/docs/ai/capabilities/overview/)形式提供：从[记忆](https://pydantic.dev/docs/ai/harness/memory/)、[护栏](https://pydantic.dev/docs/ai/harness/guardrails/)和[子智能体](https://pydantic.dev/docs/ai/harness/subagents/)，到[规划](https://pydantic.dev/docs/ai/harness/planning/)、[上下文管理](https://pydantic.dev/docs/ai/harness/compaction/)和[持久化](https://pydantic.dev/docs/ai/core-concepts/persistence/)，乃至完整的[编程智能体](https://pydantic.dev/docs/ai/harness/coder/)。 **[Pydantic AI Harness](https://pydantic.dev/docs/ai/harness/)** has everything an agent needs for complex, long-running work, snapped on as [capabilities](https://pydantic.dev/docs/ai/capabilities/overview/), from [memory](https://pydantic.dev/docs/ai/harness/memory/), [guardrails](https://pydantic.dev/docs/ai/harness/guardrails/), and [sub-agents](https://pydantic.dev/docs/ai/harness/subagents/) to [planning](https://pydantic.dev/docs/ai/harness/planning/), [context management](https://pydantic.dev/docs/ai/harness/compaction/), and [persistence](https://pydantic.dev/docs/ai/core-concepts/persistence/), up to a complete [coding agent](https://pydantic.dev/docs/ai/harness/coder/).
[Pydantic Evals](https://pydantic.dev/docs/ai/evals/evals/) 可基于数据集或[实时生产流量](https://pydantic.dev/docs/ai/evals/online-evaluation/)，对智能体的最终输出和[工具调用轨迹](https://pydantic.dev/docs/ai/evals/evaluators/agentic/)进行评分；当单个智能体循环不足以满足需求时，[Pydantic Graph](https://pydantic.dev/docs/ai/graph/graph/) 可提供具有类型支持的控制流。 [Pydantic Evals](https://pydantic.dev/docs/ai/evals/evals/) grades an agent's final outputs and [tool-call trajectories](https://pydantic.dev/docs/ai/evals/evaluators/agentic/), on datasets or [live production traffic](https://pydantic.dev/docs/ai/evals/online-evaluation/), and [Pydantic Graph](https://pydantic.dev/docs/ai/graph/graph/) gives you typed control flow when one agent loop is not enough. 两者都是独立的开源包；持续更新模型定价的 [genai-prices](https://github.com/pydantic/genai-prices)，以及用于运行模型编写的代码的沙箱化 Python 解释器 [Monty](https://github.com/pydantic/monty)，也同样如此。 Both are separate open-source packages, and so are [genai-prices](https://github.com/pydantic/genai-prices), which keeps model pricing current, and [Monty](https://github.com/pydantic/monty), the sandboxed Python interpreter that runs model-written code.
[Pydantic Logfire](https://pydantic.dev/logfire?utm_source=github&utm_medium=readme&utm_campaign=pydantic-ai) 是一个能够观测整个应用而不局限于 LLM 调用的 AI 工程平台；[Pydantic AI Gateway](https://pydantic.dev/ai-gateway?utm_source=github&utm_medium=readme&utm_campaign=pydantic-ai) 则让你通过一个密钥访问所有模型，并提供实时成本监控和预算控制；我们的[插桩](https://pydantic.dev/docs/ai/integrations/logfire/)采用标准 OpenTelemetry，因此可与你现有的任何后端配合使用。 [Pydantic Logfire](https://pydantic.dev/logfire?utm_source=github&utm_medium=readme&utm_campaign=pydantic-ai) is the AI engineering platform that sees your whole app, not just the LLM calls, and the [Pydantic AI Gateway](https://pydantic.dev/ai-gateway?utm_source=github&utm_medium=readme&utm_campaign=pydantic-ai) is one key for every model with real-time cost monitoring and budget control; our [instrumentation](https://pydantic.dev/docs/ai/integrations/logfire/) is plain OpenTelemetry, so any backend you already run works.
完整文档请参见 [pydantic.dev/docs/ai](https://pydantic.dev/docs/ai/)。 View the complete documentation at [pydantic.dev/docs/ai](https://pydantic.dev/docs/ai/).

从具有类型支持的简单数据提取，到复杂、长时间运行的多智能体协作，Pydantic AI 和 [Pydantic AI Harness](https://pydantic.dev/docs/ai/harness/) 都能满足你的需求。 From simple typed data extraction to complex, long-running multi-agent collaboration, Pydantic AI and [Pydantic AI Harness](https://pydantic.dev/docs/ai/harness/) have got you covered.
编程智能体Coding agent
终端中的完整编程智能体：提供以工作区为根目录的[文件访问](https://pydantic.dev/docs/ai/harness/filesystem/)、基于允许列表的 [shell](https://pydantic.dev/docs/ai/harness/shell/)、[代码仓库概况了解](https://pydantic.dev/docs/ai/harness/repo-context/)、[规划](https://pydantic.dev/docs/ai/harness/planning/)，以及可支持长时间会话的[上下文管理](https://pydantic.dev/docs/ai/harness/compaction/)。 A complete coding agent in your terminal: workspace-rooted [file access](https://pydantic.dev/docs/ai/harness/filesystem/), allowlisted [shell](https://pydantic.dev/docs/ai/harness/shell/), [repo orientation](https://pydantic.dev/docs/ai/harness/repo-context/), [planning](https://pydantic.dev/docs/ai/harness/planning/), and [context management](https://pydantic.dev/docs/ai/harness/compaction/) that survives long sessions. 此处还一并装配了[网页搜索](https://pydantic.dev/docs/ai/capabilities/web-search/)和提供第二意见的[顾问](https://pydantic.dev/docs/ai/harness/advisor/)： Here with [web search](https://pydantic.dev/docs/ai/capabilities/web-search/) and a second-opinion [advisor](https://pydantic.dev/docs/ai/harness/advisor/) snapped on alongside:

)
agent.to_cli_sync()

数据提取Data extraction
为智能体指定[输出类型](https://pydantic.dev/docs/ai/core-concepts/output/)和[工具](https://pydantic.dev/docs/ai/tools-toolsets/tools/)，每次运行都会返回经过验证且具有明确类型的结果： Give the agent an [output type](https://pydantic.dev/docs/ai/core-concepts/output/) and [tools](https://pydantic.dev/docs/ai/tools-toolsets/tools/), and every run comes back validated and typed: 
uv add pydantic-ai
from typing import Literal

from pydantic import BaseModel, Field

from pydantic_ai import Agent, RunContext


class Sentiment(BaseModel):
    label: Literal['positive', 'negative', 'neutral']
    score: float = Field(ge=-1, le=1)


agent = Agent('openai:gpt-6.1-sol', output_type=Sentiment)


@agent.tool
def recent_reviews(ctx: RunContext, product: str) -> list[str]:
    """Fetch recent review snippets for a product."""
    return ['The new release fixed everything I complained about!']


result = agent.run_sync('How are people feeling about the Extract app?')
print(result.output)
#> label='positive' score=0.9
[`@agent.tool`](https://pydantic.dev/docs/ai/tools-toolsets/tools/) 函数接收一个携带所需依赖项的 [`RunContext`](https://pydantic.dev/docs/ai/core-concepts/dependencies/)；其函数签名的其余部分和文档字符串共同构成工具模式（schema），参数会在代码运行前得到验证，并且此次运行保证返回一个 `Sentiment`，因此你的 IDE、类型检查器和 LLM 对返回类型的认定完全一致。 The [`@agent.tool`](https://pydantic.dev/docs/ai/tools-toolsets/tools/) function receives a [`RunContext`](https://pydantic.dev/docs/ai/core-concepts/dependencies/) that carries your dependencies in; the rest of its signature and its docstring become the tool schema, arguments are validated before your code runs, and the run is guaranteed to return a `Sentiment`, so your IDE, type checker, and the LLM all agree on the returned type.
**动手构建 →** [智能体](https://pydantic.dev/docs/ai/core-concepts/agent/)、[函数工具](https://pydantic.dev/docs/ai/tools-toolsets/tools/)和[结构化输出](https://pydantic.dev/docs/ai/core-concepts/output/) **Build this →** [Agents](https://pydantic.dev/docs/ai/core-concepts/agent/), [Function Tools](https://pydantic.dev/docs/ai/tools-toolsets/tools/), and [Structured Output](https://pydantic.dev/docs/ai/core-concepts/output/)
持久化工作流Durable workflow
接入 [`TemporalDurability`](https://pydantic.dev/docs/ai/capabilities/durable_execution/temporal/) 后，同一个智能体即可在 [Temporal](https://pydantic.dev/docs/ai/capabilities/durable_execution/temporal/) 工作流中以[持久化执行](https://pydantic.dev/docs/ai/capabilities/durable_execution/overview/)方式运行：每次模型调用和工具调用都会成为一项持久化活动，因此，通过后台队列处理的运行能够在重启、故障和长时间等待后继续执行： Attach [`TemporalDurability`](https://pydantic.dev/docs/ai/capabilities/durable_execution/temporal/) and the same agent runs inside a [Temporal](https://pydantic.dev/docs/ai/capabilities/durable_execution/temporal/) workflow under [durable execution](https://pydantic.dev/docs/ai/capabilities/durable_execution/overview/): every model and tool call becomes a durable activity, so a run working through a background queue survives restarts, failures, and long waits: 
uv add "pydantic-ai[temporal]"
from temporalio import workflow

from pydantic_ai import Agent
from pydantic_ai.capabilities import WebFetch, WebSearch
from pydantic_ai.durable_exec.temporal import PydanticAIWorkflow, TemporalDurability

agent = Agent(
    'openai:gpt-6.1-sol',
    instructions='Research the topic and write a structured brief.',
    name='researcher',
    capabilities=[WebSearch(), WebFetch(), TemporalDurability()],
)


@workflow.defn
class ResearchWorkflow(PydanticAIWorkflow):
    __pydantic_ai_agents__ = [agent]

    @workflow.run
    async def run(self, topic: str) -> str:
        result = await agent.run(f'Write a brief on: {topic}')
        return result.output
[DBOS](https://pydantic.dev/docs/ai/capabilities/durable_execution/dbos/) 和 [Prefect](https://pydantic.dev/docs/ai/capabilities/durable_execution/prefect/) 也以相同方式接入，均为第一方支持且由双方共同维护，此外还提供了与 [Restate、AWS Lambda、Airflow、Absurd、pgtask 和 Azure Durable Task](https://pydantic.dev/docs/ai/capabilities/durable_execution/overview/) 的集成。 [DBOS](https://pydantic.dev/docs/ai/capabilities/durable_execution/dbos/) and [Prefect](https://pydantic.dev/docs/ai/capabilities/durable_execution/prefect/) attach the same way, first-party and co-maintained, with [Restate, AWS Lambda, Airflow, Absurd, pgtask, and Azure Durable Task](https://pydantic.dev/docs/ai/capabilities/durable_execution/overview/) integrations besides.
保存、恢复运行以及从运行创建分支都不需要引擎：Pydantic AI Harness 中的 [`StepPersistence`](https://pydantic.dev/docs/ai/harness/step-persistence/) 会像检查点保存器一样，将每个已完成步骤的快照保存到你选择的存储中（参见[持久化](https://pydantic.dev/docs/ai/core-concepts/persistence/)）。 Saving, resuming, and forking a run need no engine: [`StepPersistence`](https://pydantic.dev/docs/ai/harness/step-persistence/) from Pydantic AI Harness snapshots every settled step to a store you choose, the way a checkpointer does (see [Persistence](https://pydantic.dev/docs/ai/core-concepts/persistence/)). 引擎用于恢复在某个步骤执行过程中崩溃的运行。 The engine is for recovering a run that crashes partway through a step.
**动手构建 →** [持久化执行](https://pydantic.dev/docs/ai/capabilities/durable_execution/overview/) **Build this →** [Durable Execution](https://pydantic.dev/docs/ai/capabilities/durable_execution/overview/)

让同一个智能体参与实时语音会话，并同时使用其[工具](https://pydantic.dev/docs/ai/realtime/tools/)和[能力](https://pydantic.dev/docs/ai/realtime/capabilities/)： Put the same agent on a live voice session, [tools](https://pydantic.dev/docs/ai/realtime/tools/) and [capabilities](https://pydantic.dev/docs/ai/realtime/capabilities/) included:

import asyncio

from pydantic_ai import Agent
from pydantic_ai.capabilities import MCP

agent = Agent(
    instructions='You are a helpful voice assistant.',
    capabilities=[MCP('https://internal.example.com/mcp')],  # capabilities work in voice too
)

@agent.tool_plain
def order_status(order_id: str) -> str:
    """Look up the status of an order."""
    return f'Order {order_id}: shipped, arriving Thursday.'

async with agent.realtime('openai:gpt-realtime-2.1').session() as session:
    microphone = asyncio.create_task(session.send_audio(microphone_chunks()))  # your microphone → the model
    speaker = asyncio.create_task(play_audio(session.stream_audio()))  # model audio → your speaker
    async for part in session.stream_transcripts():
        print(f'{part.speaker}: {part.transcript}')
模型可以在对话过程中一边继续说话，一边调用你的工具，而且每个会话都接入了[可观测性埋点](https://pydantic.dev/docs/ai/integrations/logfire/)；语音只是另一种前端形式，可基于 OpenAI Realtime、Gemini Live、Azure 和 xAI Grok Voice 使用。 The model calls your tools mid-conversation while it keeps talking, and every session is [instrumented](https://pydantic.dev/docs/ai/integrations/logfire/); voice is just another frontend, on OpenAI Realtime, Gemini Live, Azure, and xAI Grok Voice.

from pydantic_ai import ImageGenerator

为何选择 Pydantic AIWhy Pydantic AI
**一个 Python API，适用于任何模型。** 支持[几乎所有模型和提供商](https://pydantic.dev/docs/ai/models/overview/)（OpenAI、Anthropic、Google、Bedrock、Azure AI Foundry、Groq、Mistral、xAI、Ollama 以及其他数十家），只需更改一个字符串即可切换，也可通过 [Pydantic AI Gateway](https://pydantic.dev/docs/ai/overview/gateway/) 使用：一个密钥即可访问所有这些模型和提供商，并内置故障转移和成本监控功能。 **Any model, one Python API.** [Virtually every model and provider](https://pydantic.dev/docs/ai/models/overview/) (OpenAI, Anthropic, Google, Bedrock, Azure AI Foundry, Groq, Mistral, xAI, Ollama, and dozens more), swappable with a string, or through the [Pydantic AI Gateway](https://pydantic.dev/docs/ai/overview/gateway/): one key for all of them, with failover and cost monitoring built in. 任何核心功能都不绑定于单一供应商。 No flagship feature is locked to one vendor.
**端到端类型化。**[结构化输出](https://pydantic.dev/docs/ai/core-concepts/output/)、类型化的[依赖注入](https://pydantic.dev/docs/ai/core-concepts/dependencies/)、[类型化工具](https://pydantic.dev/docs/ai/tools-toolsets/tools/)：你的 IDE、类型检查器和编程智能体都知道你的智能体会返回什么，从而将整类错误的发现时机从运行时提前到代码编写时。 **Typed end to end.** [Structured outputs](https://pydantic.dev/docs/ai/core-concepts/output/), typed [dependency injection](https://pydantic.dev/docs/ai/core-concepts/dependencies/), [typed tools](https://pydantic.dev/docs/ai/tools-toolsets/tools/): your IDE, type checker, and coding agent all know what your agent returns, moving whole classes of errors from runtime to write-time. 当普通控制流不足以满足需求时，[Pydantic Graph](https://pydantic.dev/docs/ai/graph/graph/) 可为基于图的工作流提供同样的类型支持。 When plain control flow isn't enough, [Pydantic Graph](https://pydantic.dev/docs/ai/graph/graph/) brings the same typing to graph-based workflows.
**以测量为依据，而非凭感觉。**原生支持 OpenTelemetry 的[插桩](https://pydantic.dev/docs/ai/integrations/logfire/#using-logfire)可与任何 OTel 后端配合使用；运行一次 `uvx logfire-cli wizard --task pydantic-ai` 即可启用 [Pydantic Logfire](https://pydantic.dev/logfire/llm-observability?utm_source=github&utm_medium=readme&utm_campaign=pydantic-ai)，实现实时调试、追踪，以及由 [genai-prices](https://github.com/pydantic/genai-prices) 支持的成本跟踪。 **Measured, not vibes.** OpenTelemetry-native [instrumentation](https://pydantic.dev/docs/ai/integrations/logfire/#using-logfire) works with any OTel backend; run `uvx logfire-cli wizard --task pydantic-ai` once to light up [Pydantic Logfire](https://pydantic.dev/logfire/llm-observability?utm_source=github&utm_medium=readme&utm_campaign=pydantic-ai) for real-time debugging, tracing, and cost tracking backed by [genai-prices](https://github.com/pydantic/genai-prices). [Pydantic Evals](https://pydantic.dev/docs/ai/evals/evals/) 根据代码中定义的数据集，或通过[在线评估](https://pydantic.dev/docs/ai/evals/online-evaluation/)根据实时生产流量的抽样，对最终输出和[工具调用轨迹](https://pydantic.dev/docs/ai/evals/evaluators/agentic/)进行评分。 [Pydantic Evals](https://pydantic.dev/docs/ai/evals/evals/) grades final outputs and [tool-call trajectories](https://pydantic.dev/docs/ai/evals/evaluators/agentic/), against datasets in code or, with [online evaluation](https://pydantic.dev/docs/ai/evals/online-evaluation/), a sample of live production traffic.
**功能齐备，灵活组合。**只需一种原语——[能力（capability）](https://pydantic.dev/docs/ai/capabilities/overview/)——即可将[工具](https://pydantic.dev/docs/ai/tools-toolsets/tools/)、[指令](https://pydantic.dev/docs/ai/core-concepts/agent/#instructions)、[钩子](https://pydantic.dev/docs/ai/core-concepts/hooks/)和[模型设置](https://pydantic.dev/docs/ai/core-concepts/agent/#model-run-settings)封装为可复用的单元。 **Batteries, composably.** One primitive, the [capability](https://pydantic.dev/docs/ai/capabilities/overview/), bundles [tools](https://pydantic.dev/docs/ai/tools-toolsets/tools/), [instructions](https://pydantic.dev/docs/ai/core-concepts/agent/#instructions), [hooks](https://pydantic.dev/docs/ai/core-concepts/hooks/), and [model settings](https://pydantic.dev/docs/ai/core-concepts/agent/#model-run-settings) into reusable units. 核心部分提供 [MCP](https://pydantic.dev/docs/ai/capabilities/mcp/) 和[网络搜索](https://pydantic.dev/docs/ai/capabilities/web-search/)等基础功能，[Harness](https://pydantic.dev/docs/ai/harness/) 提供其余所有功能，而 [Coder](https://pydantic.dev/docs/ai/harness/coder/) 和 [Researcher](https://pydantic.dev/docs/ai/harness/researcher/) 等完整智能体也只是由能力组合而成：它们如何组装，就能如何拆解。 Core ships fundamentals like [MCP](https://pydantic.dev/docs/ai/capabilities/mcp/) and [web search](https://pydantic.dev/docs/ai/capabilities/web-search/), the [Harness](https://pydantic.dev/docs/ai/harness/) ships everything else, and complete agents like [Coder](https://pydantic.dev/docs/ai/harness/coder/) and [Researcher](https://pydantic.dev/docs/ai/harness/researcher/) are just capabilities composed: they come apart the way they went together. 也可以使用 [YAML/JSON 智能体规范](https://pydantic.dev/docs/ai/core-concepts/agent-spec/)，完全无需编写代码。 Or skip code entirely with [YAML/JSON agent specs](https://pydantic.dev/docs/ai/core-concepts/agent-spec/).
**[覆盖各种交互界面](https://pydantic.dev/docs/ai/overview/interfaces/)。**同一份智能体定义可作为 [CLI](https://pydantic.dev/docs/ai/integrations/cli/)、[内置网页聊天界面](https://pydantic.dev/docs/ai/guides/web/)或[实时语音](https://pydantic.dev/docs/ai/realtime/overview/)应用运行（OpenAI Realtime、Gemini Live、Azure、xAI Grok Voice）；[UI 事件流](https://pydantic.dev/docs/ai/integrations/ui/overview/)（AG-UI、Vercel AI）可将其连接到你自己的前端或其他任何系统；[ACP](https://pydantic.dev/docs/ai/harness/acp/) 可将其作为编辑器智能体提供服务；[GitHub Agentic Workflows](https://pydantic.dev/docs/ai/harness/gh-aw/) 则可针对议题、拉取请求或按计划以无界面模式运行它。 **[Every interface](https://pydantic.dev/docs/ai/overview/interfaces/).** One agent definition runs as a [CLI](https://pydantic.dev/docs/ai/integrations/cli/), a [built-in web chat](https://pydantic.dev/docs/ai/guides/web/), or [realtime speech](https://pydantic.dev/docs/ai/realtime/overview/) (OpenAI Realtime, Gemini Live, Azure, xAI Grok Voice); [UI event streams](https://pydantic.dev/docs/ai/integrations/ui/overview/) (AG-UI, Vercel AI) connect it to your own frontend or anything else; [ACP](https://pydantic.dev/docs/ai/harness/acp/) serves it as an editor agent; and [GitHub Agentic Workflows](https://pydantic.dev/docs/ai/harness/gh-aw/) runs it headless on issues, pull requests or a schedule.

from dataclasses import dataclass

from pydantic import BaseModel, Field

from pydantic_ai import Agent, Capability, RunContext

from bank_database import DatabaseConn


@dataclass
class SupportDependencies:  # inject any client: DB pools, HTTP APIs, user info
    customer_id: int
    db: DatabaseConn


class SupportOutput(BaseModel):
    support_advice: str = Field(description='Advice returned to the customer')
    block_card: bool = Field(description="Whether to block the customer's card")
    risk: int = Field(description='Risk level of query', ge=0, le=10)


customer_context = Capability[SupportDependencies](  # a reusable unit of tools + instructions
    id='customer-context',
    description="Who the customer is and what's on their account.",
)


@customer_context.instructions
async def add_customer_name(ctx: RunContext[SupportDependencies]) -> str:
    customer_name = await ctx.deps.db.customer_name(id=ctx.deps.customer_id)
    return f"The customer's name is {customer_name!r}"


@customer_context.tool  # signature and docstring become the tool schema the LLM sees
async def customer_balance(
    ctx: RunContext[SupportDependencies], include_pending: bool
) -> float:
    """Returns the customer's current account balance."""
    return await ctx.deps.db.customer_balance(
        id=ctx.deps.customer_id,
        include_pending=include_pending,
    )


refunds = Capability[SupportDependencies](  # deferred: loads on demand, like a skill
    id='refunds',
    description='Refund eligibility and refund status.',
    defer_loading=True,
)


@refunds.tool
async def refund_status(ctx: RunContext[SupportDependencies]) -> str:
    """Look up the refund status for the customer's most recent charge."""
    return await ctx.deps.db.refund_status(id=ctx.deps.customer_id)


support_agent = Agent(
    'openai:gpt-6.1-sol',
    deps_type=SupportDependencies,
    output_type=SupportOutput,  # the run returns a validated SupportOutput, typed as such
    instructions=(
        'You are a support agent in our bank, give the '
        'customer support and judge the risk level of their query.'
    ),
    capabilities=[customer_context, refunds],
)


...  # in a real use case: more tools, longer instructions


async def main():
    deps = SupportDependencies(customer_id=123, db=DatabaseConn())
    result = await support_agent.run('What is my balance?', deps=deps)
    print(result.output)
    """
    support_advice='Hello John, your current account balance, including pending transactions, is $123.45.' block_card=False risk=1
    """

    result = await support_agent.run('I just lost my card!', deps=deps)
    print(result.output)
    """
    support_advice="I'm sorry to hear that, John. We are temporarily blocking your card to prevent unauthorized transactions." block_card=True risk=8
    """

    result = await support_agent.run(  # the model loads `refunds` on demand, then answers
        'Was I refunded for the duplicate charge on my last statement?', deps=deps
    )
    print(result.output)
    """
    support_advice='Good news, John: the duplicate charge on your last statement was refunded on 2026-05-01.' block_card=False risk=1
    """
