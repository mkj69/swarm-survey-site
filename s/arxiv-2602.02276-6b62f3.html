一句话

Kimi K2.5 的 Agent Swarm 把“如何拆任务、何时并行”变成可训练的编排能力，并报告了宽搜索任务上的速度与质量收益。

主要内容

  • 只训练编排器：PARL 冻结子 agent，其执行轨迹不进入优化目标；编排器通过强化学习掌握任务分解、子 agent 创建与调度。作者希望借此减少联合训练中的信用分配歧义和不稳定性。
  • 同时防止两种退化：用并行辅助奖励鼓励探索，避免始终串行；用子任务完成奖励约束无效创建，避免靠大量启动 agent 获取奖励。两项辅助奖励的权重在训练中逐渐降至零。
  • 围绕最长分支优化：以“关键步数”衡量执行成本，并行组的耗时由最慢子 agent 决定。这使均衡拆分任务比单纯增加并发数更有价值。
  • 任务分布诱导并行：训练覆盖宽搜索、多分支深搜索及长文档分析等任务，不直接在提示中要求并行。
  • 多模态联合训练是模型基础，但本文对蜂群研究更直接的贡献，是编排器训练方法及其评测口径。

证据与可信度

材料为 Kimi 团队技术报告的抓取片段，末尾截断，部分公式与表格缺失，未读到全文。

作者报告：宽搜索场景相较单 agent，推理最高加速 4.5 倍，条目级 F1 从 72.8% 升至 79.0%，即增加 6.2 个百分点，由两数相减得到。这属于厂商自报的实验结果，所给材料没有独立核验。

“最高”不能代表平均收益，也不能据此断言质量提升与最高加速在同一配置下同时出现。片段未展示这些结果对应的完整硬件、并发规模、总计算量与统计波动；关键步数也不能直接等同于实际耗时或费用。

对 swarm scaling 的意义

这份材料支持一个值得检验的方向：扩展蜂群能力，需要学习有效分工与调度，而非仅增加 agent 数量。冻结执行者、集中训练编排器，提供了较清晰的研究切口。

其奖励设计也揭示了扩展中的核心矛盾：并行不足会限制速度，无效并行则浪费资源。后续应重点检验不同并发规模下的质量、实际延迟与总成本曲线；现有片段尚不足以证明普遍的蜂群规模收益。
