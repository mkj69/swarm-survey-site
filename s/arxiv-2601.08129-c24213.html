摘要Abstract
当前的多智能体大语言模型（LLM）框架依赖于借鉴人类组织结构的显式编排模式：规划者向执行者分派任务，管理者协调工作者，而层级式控制流支配智能体之间的交互。 Current multi-agent large language model (LLM) frameworks rely on explicit orchestration patterns borrowed from human organizational structures: planners delegate to executors, managers coordinate workers, and hierarchical control flow governs agent interactions. 这些方法存在协调开销，随着智能体数量和任务复杂度的增加，其扩展性较差。 These approaches suffer from coordination overhead that scales poorly with agent count and task complexity. 我们提出了一种受自然协调机制启发、根本不同的范式：智能体在共享产物上进行局部操作，仅由可测量的质量信号所导出的压力梯度引导，同时通过时间衰减防止过早收敛。 We propose a fundamentally different paradigm inspired by natural coordination mechanisms: agents operate locally on a shared artifact, guided only by pressure gradients derived from measurable quality signals, with temporal decay preventing premature convergence. 我们将其形式化为压力景观上的优化问题，并证明了在温和条件下的收敛保证。 We formalize this as optimization over a pressure landscape and prove convergence guarantees under mild conditions.
在会议室调度任务共计 1350 次试验（每种策略 270 次）的实证研究中，压力场协调的求解成功率达到基于对话的协调的 $4\times$，并超过层级控制的 $30\times$（48.5% vs 11.1% vs 1.5%；所有两两比较均为 $p<0.001$）。 Empirically, on meeting room scheduling across 1350 total trials (270 per strategy), pressure-field coordination achieves $4\times$ higher solve rates than conversation-based coordination and over $30\times$ higher than hierarchical control (48.5% vs 11.1% vs 1.5%; all pairwise comparisons $p<0.001$ ). 消融研究表明，时间衰减具有益处。 Ablation studies suggest temporal decay is beneficial. 在简单问题上，压力场方法的求解成功率达到 86.7%，而表现次优的基线为 33.3%。 On easy problems, pressure-field achieves 86.7% solve rate compared to 33.3% for the next-best baseline. 基础模型使这一方法成为可能：其广泛的预训练和零样本推理能力使其仅凭局部压力信号就能生成提升质量的修补方案，而无需特定领域的协调协议。 Foundation models enable this approach: their broad pretraining and zero-shot reasoning allow quality-improving patches from local pressure signals alone, without domain-specific coordination protocols. 这表明，约束驱动的涌现为多智能体 AI 提供了一种更简单、更有效的基础。 This suggests that constraint-driven emergence offers a simpler and more effective foundation for multi-agent AI.

3 问题形式化3 Problem Formulation
我们将制品改进形式化为压力景观上的动力系统，而非具有目标状态的优化问题。 We formalize artifact refinement as a dynamical system over a pressure landscape rather than an optimization problem with a target state. 系统通过局部行动和持续衰减不断演化，最终稳定在代表可接受制品状态的稳定吸引域中。 The system evolves through local actions and continuous decay, settling into stable basins that represent acceptable artifact states.
3.1 状态空间3.1 State Space
一个制品由 $n$ 个区域组成，对于 $i\in\{1,\ldots,n\}$，其内容为 $c_{i}\in\mathcal{C}$，其中 $\mathcal{C}$ 是任意内容空间（字符串、抽象语法树节点等）。 An artifact consists of $n$ regions with content $c_{i}\in\mathcal{C}$ for $i\in\{1,\ldots,n\}$ , where $\mathcal{C}$ is an arbitrary content space (strings, Abstract Syntax Tree nodes, etc.). 每个区域还带有辅助状态 $h_{i}\in\mathcal{H}$，表示置信度、适应度和历史信息。 Each region also carries auxiliary state $h_{i}\in\mathcal{H}$ representing confidence, fitness, and history. 区域是制品的被动划分单元；智能体则是主动的提案者，负责观察区域并生成补丁。 Regions are passive subdivisions of the artifact; agents are active proposers that observe regions and generate patches.
完整的系统状态为： The full system state is: 
| | $s=((c_{1},h_{1}),\ldots,(c_{n},h_{n}))\in(\mathcal{C}\times\mathcal{H})^{n}$ |
3.2 压力景观3.2 Pressure Landscape
信号函数 $\sigma:\mathcal{C}\to\mathbb{R}^{d}$ 将内容映射为可测量的特征。 A signal function $\sigma:\mathcal{C}\to\mathbb{R}^{d}$ maps content to measurable features. 信号具有局部性：$\sigma(c_{i})$ 仅取决于区域 $i$。 Signals are local: $\sigma(c_{i})$ depends only on region $i$ .
压力函数 $\phi:\mathbb{R}^{d}\to\mathbb{R}_{\geq 0}$ 将信号映射为表示“不良程度”的标量。 A pressure function $\phi:\mathbb{R}^{d}\to\mathbb{R}_{\geq 0}$ maps signals to scalar “badness.” 我们考虑 $k$ 个压力维度，其权重为 $\mathbf{w}\in\mathbb{R}^{k}_{>0}$。 We consider $k$ pressure axes with weights $\mathbf{w}\in\mathbb{R}^{k}_{>0}$ . 区域压力为： The region pressure is: 
| | $P_{i}(s)=\sum_{j=1}^{k}w_{j}\phi_{j}(\sigma(c_{i}))$ |
制品（artifact）压力为： The artifact pressure is: 
| | $P(s)=\sum_{i=1}^{n}P_{i}(s)$ |
这在制品状态空间上定义了一个景观。 This defines a landscape over artifact states. 低压力区域是制品满足质量约束的“谷地”。 Low-pressure regions are “valleys” where the artifact satisfies quality constraints.

系统以离散时间步（tick）演化。 The system evolves in discrete time steps (ticks). 每个时间步包含四个阶段： Each tick consists of four phases:

| | $f_{i}^{t+1}=f_{i}^{t}\cdot e^{-\lambda_{f}},\quad\gamma_{i}^{t+1}=\gamma_{i}^{t}\cdot e^{-\lambda_{\gamma}}$ |
其中，$\lambda_{f},\lambda_{\gamma}>0$ 为衰减率。 where $\lambda_{f},\lambda_{\gamma}>0$ are decay rates. 衰减机制确保维持稳定需要持续强化。 Decay ensures that stability requires continuous reinforcement.
阶段 2：提议。 Phase 2: Proposal. 对于压力超过激活阈值（$P_{i}>\tau_{\text{act}}$）且未受到抑制的每个区域 $i$，各行动者 $a_{k}:\mathcal{C}\times\mathcal{H}\times\mathbb{R}^{d}\to\mathcal{C}$ 并行提出内容变换方案。 For each region $i$ where pressure exceeds activation threshold ( $P_{i}>\tau_{\text{act}}$ ) and the region is not inhibited, each actor $a_{k}:\mathcal{C}\times\mathcal{H}\times\mathbb{R}^{d}\to\mathcal{C}$ proposes a content transformation in parallel. 每个行动者仅观察局部状态 $(c_{i},h_{i},\sigma(c_{i}))$——行动者之间不进行通信，也不协调各自的提议。 Each actor observes only local state $(c_{i},h_{i},\sigma(c_{i}))$ —actors do not communicate or coordinate their proposals.
阶段 3：验证。 Phase 3: Validation. 当提出多个补丁时，每个补丁都在制品的独立分支上进行验证。 When multiple patches are proposed, each is validated on an independent fork of the artifact. 通过克隆制品状态创建分支；各分支上的验证并行进行。 Forks are created by cloning artifact state; validation proceeds in parallel across forks. 这解决了一个根本性的资源约束：若不进行克隆，就无法使用同一个制品同时测试多个补丁。 This addresses a fundamental resource constraint: a single artifact cannot be used to test multiple patches simultaneously without cloning.
阶段 4：强化。 Phase 4: Reinforcement. 已执行操作的区域会获得适应度和置信度提升，并进入抑制期，以防止立即被再次修改。 Regions where actions were applied receive fitness and confidence boosts, and enter an inhibition period preventing immediate re-modification. 抑制机制使变更能够在制品中传播，并迫使智能体处理其他高压力区域，从而避免围绕局部修复反复振荡。 Inhibition allows changes to propagate through the artifact and forces agents to address other high-pressure regions, preventing oscillation around local fixes.

如果在没有外部扰动的系统动力学下满足以下条件，则状态 $s^{*}$ 是稳定的： A state $s^{*}$ is stable if, under the system dynamics with no external perturbation:
所有区域的压力均低于激活阈值：对所有 $i$，均有 $P_{i}(s^{*})<\tau_{\text{act}}$ All region pressures are below activation threshold: $P_{i}(s^{*})<\tau_{\text{act}}$ for all $i$

收敛性：从初始状态 $s_{0}$ 出发，系统能否到达稳定吸引域？ Convergence: From initial state $s_{0}$ , does the system reach a stable basin? 需要多长时间？ How quickly?

3.5 局部性约束3.5 The Locality Constraint
将我们的设定与集中式优化区分开来的约束是：智能体仅观察局部状态。 The constraint distinguishing our setting from centralized optimization: agents observe only local state. 位于区域 $i$ 的行动者能够看到 $(c_{i},h_{i},\sigma(c_{i}))$，但无法看到： An actor at region $i$ sees $(c_{i},h_{i},\sigma(c_{i}))$ but not:
其他区域的内容 $c_{j}$，其中 $j\neq i$ Other regions’ content $c_{j}$ for $j\neq i$
全局压力 $P(s)$ Global pressure $P(s)$
其他智能体的动作 Other agents’ actions
这排除了协同规划的可能性。 This rules out coordinated planning. 稳定性必须从与降低全局压力相一致的局部激励中涌现。 Stability must emerge from local incentives aligned with global pressure reduction.
4 方法4 Method
现在，我们提出一种完全通过局部决策实现稳定性的协调机制。 We now present a coordination mechanism that achieves stability through purely local decisions. 在适当条件下，制品压力 $P(s)$ 充当势函数：各个智能体的局部改进会降低全局压力，从而保证在无需协调的情况下收敛。 Under appropriate conditions, the artifact pressure $P(s)$ acts as a potential function: local improvements by individual agents decrease global pressure, guaranteeing convergence without coordination.
4.1 压力对齐4.1 Pressure Alignment
局部性约束禁止智能体观测全局状态。 The locality constraint prohibits agents from observing global state. 要使去中心化协调取得成功，我们需要使局部激励与降低全局压力相一致。 For decentralized coordination to succeed, we need local incentives to align with global pressure reduction.
定义 4.1（压力对齐）。Definition 4.1 (Pressure Alignment).
若对于任意区域 $i$、状态 $s$ 以及降低局部压力的动作 $a_{i}$，均满足以下条件，则称该压力系统是对齐的： A pressure system is aligned if for any region $i$ , state $s$ , and action $a_{i}$ that reduces local pressure: 
| | $P_{i}(s^{\prime})<P_{i}(s)\quad\Longrightarrow\quad P(s^{\prime})<P(s)$ |
其中，$s^{\prime}=s[c_{i}\mapsto a_{i}(c_{i})]$ 是应用 $a_{i}$ 后的状态。 where $s^{\prime}=s[c_{i}\mapsto a_{i}(c_{i})]$ is the state after applying $a_{i}$ .
当压力函数可分离时，对齐性自动成立：每个 $P_{i}$ 仅依赖于 $c_{i}$，因此 $P(s)=\sum_{i}P_{i}(s)$，局部改进直接意味着全局改进。 Alignment holds automatically when pressure functions are separable: each $P_{i}$ depends only on $c_{i}$ , so $P(s)=\sum_{i}P_{i}(s)$ and local improvement directly implies global improvement.
更一般地，当跨区域相互作用有界时，对齐性成立： More generally, alignment holds when cross-region interactions are bounded:
定义 4.2（有界耦合）。Definition 4.2 (Bounded Coupling).
若对于区域 $i$ 上的任意动作 $a_{i}$，均满足以下条件，则称该压力系统具有 $\epsilon$ 有界耦合： A pressure system has $\epsilon$ -bounded coupling if for any action $a_{i}$ on region $i$ : 
| | $|P_{j}(s^{\prime})-P_{j}(s)|\leq\epsilon\quad\forall j\neq i$ |
也就是说，修改区域 $i$ 对其他区域压力造成的变化至多为 $\epsilon$。 That is, modifying region $i$ changes other regions’ pressures by at most $\epsilon$ .
在具有 $n$ 个区域且满足 $\epsilon$ 有界耦合的条件下，如果某个局部动作使 $P_{i}$ 降低了 $\delta>(n-1)\epsilon$，则全局压力至少降低 $\delta-(n-1)\epsilon>0$。 Under $\epsilon$ -bounded coupling with $n$ regions, if a local action reduces $P_{i}$ by $\delta>(n-1)\epsilon$ , then global pressure decreases by at least $\delta-(n-1)\epsilon>0$ .
4.2 与势博弈的联系4.2 Connection to Potential Games
对齐的压力系统构成一个势博弈，其中： The aligned pressure system forms a potential game where:
参与者是区域（或在区域上采取动作的智能体） Players are regions (or agents acting on regions)
策略是内容选择 $c_{i}\in\mathcal{C}$ Strategies are content choices $c_{i}\in\mathcal{C}$
势函数为 $\Phi(s)=P(s)$ The potential function is $\Phi(s)=P(s)$
在势博弈中，任何由改进动作组成的序列都会收敛到纳什均衡。 In potential games, any sequence of improving moves converges to a Nash equilibrium. 在我们的设定中，纳什均衡对应于稳定吸引域：在这些状态下，没有任何局部动作能够将压力降至激活阈值以下。 In our setting, Nash equilibria correspond to stable basins: states where no local action can reduce pressure below the activation threshold.
这一联系为我们提供了无需显式协调的收敛保证。 This connection provides our convergence guarantee without requiring explicit coordination.
请注意，这一收敛结果以动作空间有限为前提。 Note that this convergence result assumes finite action spaces. 在实践中，补丁选自大语言模型为每个区域生成的有限提案集合，因此满足这一要求。 In practice, patches are drawn from a finite set of Large Language Model-generated proposals per region, satisfying this requirement. 更根本地说，验证阶段（阶段 2b）隐式地将动作空间离散化：只有降低压力的补丁才会被接受，因此任一状态下的有效动作集都是在该时步生成的、能够降低压力的有限提案集合。 More fundamentally, the validation phase (Phase 2b) implicitly discretizes the action space: only patches that reduce pressure are accepted, so the effective action set at any state is the finite set of pressure-reducing proposals generated that tick. 对于无限内容空间，可以在压力函数满足 Lipschitz 连续性条件时证明其收敛到近似均衡。 For infinite content spaces, convergence to approximate equilibria can be established under Lipschitz continuity conditions on pressure functions.

时步循环通过衰减驱动的探索来实现贪心局部改进： The tick loop implements greedy local improvement with decay-driven exploration:
输入：状态 $s^{t}$，信号函数 $\{\sigma_{j}\}$，压力函数 $\{\phi_{j}\}$，行动者 $\{a_{k}\}$，参数 $(\tau_{\text{act}},\lambda_{f},\lambda_{\gamma},\Delta_{f},\Delta_{\gamma},\kappa)$ Input: State $s^{t}$ , signal functions $\{\sigma_{j}\}$ , pressure functions $\{\phi_{j}\}$ , actors $\{a_{k}\}$ , parameters $(\tau_{\text{act}},\lambda_{f},\lambda_{\gamma},\Delta_{f},\Delta_{\gamma},\kappa)$
阶段 1：衰减 对每个区域 $i$：$\quad f_{i}\leftarrow f_{i}\cdot e^{-\lambda_{f}},\quad\gamma_{i}\leftarrow\gamma_{i}\cdot e^{-\lambda_{\gamma}}$ Phase 1: Decay For each region $i$ : $\quad f_{i}\leftarrow f_{i}\cdot e^{-\lambda_{f}},\quad\gamma_{i}\leftarrow\gamma_{i}\cdot e^{-\lambda_{\gamma}}$
阶段 2：激活与提案 $\mathcal{P}\leftarrow\emptyset$ 对每个满足 $P_{i}(s)\geq\tau_{\text{act}}$ 且未受抑制的区域 $i$：$\boldsymbol{\sigma}_{i}\leftarrow\sigma(c_{i})$ 对每个行动者 $a_{k}$：$\delta\leftarrow a_{k}(c_{i},h_{i},\boldsymbol{\sigma}_{i})$ $\mathcal{P}\leftarrow\mathcal{P}\cup\{(i,\delta,\hat{\Delta}(\delta))\}$ Phase 2: Activation and Proposal $\mathcal{P}\leftarrow\emptyset$ For each region $i$ where $P_{i}(s)\geq\tau_{\text{act}}$ and not inhibited: $\boldsymbol{\sigma}_{i}\leftarrow\sigma(c_{i})$ For each actor $a_{k}$ : $\delta\leftarrow a_{k}(c_{i},h_{i},\boldsymbol{\sigma}_{i})$ $\mathcal{P}\leftarrow\mathcal{P}\cup\{(i,\delta,\hat{\Delta}(\delta))\}$
阶段 3：并行验证与选择 对每个候选补丁 $(i,\delta,\hat{\Delta})\in\mathcal{P}$：创建制品分支：$(f_{\text{id}},A_{f})\leftarrow A.\text{fork}()$ 将 $\delta$ 应用于分支 $A_{f}$ 验证分支（运行测试、检查编译）收集验证结果 $\{(i,\delta,\Delta_{\text{actual}},\text{valid})\}$ 按 $\Delta_{\text{actual}}$ 对已通过验证的补丁排序 贪心地选择排名最前的 $\kappa$ 个互不冲突的补丁 Phase 3: Parallel Validation and Selection For each candidate patch $(i,\delta,\hat{\Delta})\in\mathcal{P}$ : Fork artifact: $(f_{\text{id}},A_{f})\leftarrow A.\text{fork}()$ Apply $\delta$ to fork $A_{f}$ Validate fork (run tests, check compilation) Collect validation results $\{(i,\delta,\Delta_{\text{actual}},\text{valid})\}$ Sort validated patches by $\Delta_{\text{actual}}$ Greedily select top- $\kappa$ non-conflicting patches

返回更新后的状态 $s^{t+1}$ Return updated state $s^{t+1}$
该算法具有三个关键性质： The algorithm has three key properties:
局部性。 Locality. 每个行动者仅观测 $(c_{i},h_{i},\sigma(c_{i}))$。 Each actor observes only $(c_{i},h_{i},\sigma(c_{i}))$ . 不访问任何全局状态。 No global state is accessed.
有界并行性。 Bounded parallelism. 每个时钟步最多应用 $\kappa$ 个补丁，以防止系统抖动。 At most $\kappa$ patches per tick prevents thrashing. 抑制机制可防止对同一区域进行反复修改。 Inhibition prevents repeated modification of the same region.
衰减驱动的探索。 Decay-driven exploration. 即使是稳定区域，其置信度最终也会衰减至阈值以下，从而引发重新评估。 Even stable regions eventually decay below confidence thresholds, attracting re-evaluation. 这可防止系统过早收敛到局部极小值。 This prevents premature convergence to local minima.
4.4 稳定性与终止4.4 Stability and Termination
当满足以下条件时，系统进入稳定吸引域： The system reaches a stable basin when:
所有区域的压力均满足 $P_{i}(s)<\tau_{\text{act}}$ All region pressures satisfy $P_{i}(s)<\tau_{\text{act}}$
衰减得到平衡：适应度保持在维持稳定所需的阈值以上 Decay is balanced: fitness remains above the threshold needed for stability
终止依据的是经济性，而非逻辑条件。 Termination is economic, not logical. 当行动成本（以每个补丁带来的压力降低量衡量）低于收益时，系统便停止行动。 The system stops acting when the cost of action (measured in pressure reduction per patch) falls below the benefit. 这与自然系统一致：活动在梯度趋于平坦时停止，而非在外部宣告某个目标已达成时停止。 This matches natural systems: activity ceases when gradients flatten, not when an external goal is declared achieved.
在实践中，我们还施加预算约束（最大时钟步数或补丁数），以限制计算量。 In practice, we also impose budget constraints (maximum ticks or patches) to bound computation.
5 理论分析5 Theoretical Analysis
我们确立了三个主要结果：(1) 在对齐条件下收敛到稳定吸引域，(2) 稳定吸引域质量的界，以及 (3) 相对于集中式替代方案的扩展特性。 We establish three main results: (1) convergence to stable basins under alignment, (2) bounds on stable basin quality, and (3) scaling properties relative to centralized alternatives.
5.1 对齐条件下的收敛性5.1 Convergence Under Alignment
定理 5.1（收敛性）。Theorem 5.1 (Convergence).
设压力系统满足对齐条件，且耦合以 $\epsilon$ 为界。 Let the pressure system be aligned with $\epsilon$ -bounded coupling. 设 $\delta_{\min}>0$ 为任意已应用补丁带来的局部压力降低量 $P_{i}(s)-P_{i}(s^{\prime})$ 的最小值，并假设 $\delta_{\min}>(n-1)\epsilon$，其中 $n$ 为区域数量。 Let $\delta_{\min}>0$ be the minimum local pressure reduction $P_{i}(s)-P_{i}(s^{\prime})$ from any applied patch, and assume $\delta_{\min}>(n-1)\epsilon$ where $n$ is the number of regions. 那么，从压力为 $P_{0}=P(s_{0})$ 的任意初始状态 $s_{0}$ 出发，系统将在以下时钟步数内进入稳定吸引域： Then from any initial state $s_{0}$ with pressure $P_{0}=P(s_{0})$ , the system reaches a stable basin within: 
| | $T\leq\frac{P_{0}}{\delta_{\min}-(n-1)\epsilon}$ |
个时钟步，前提是成功补丁带来的适应度提升 $\Delta_{f}$ 超过抑制期间的衰减量：$\Delta_{f}>1-e^{-\lambda_{f}\cdot\tau_{\text{inh}}}$。 ticks, provided the fitness boost $\Delta_{f}$ from successful patches exceeds decay during inhibition: $\Delta_{f}>1-e^{-\lambda_{f}\cdot\tau_{\text{inh}}}$ .
证明概要。 Proof sketch. 在满足对齐条件且耦合以 $\epsilon$ 为界的情况下，每个已应用补丁使全局压力至少降低 $\delta_{\min}-(n-1)\epsilon>0$。 Under alignment with $\epsilon$ -bounded coupling, each applied patch reduces global pressure by at least $\delta_{\min}-(n-1)\epsilon>0$ . 由于 $P(s)\geq 0$，且每个时钟步（应用补丁时）的压力降低量均不小于某个固定正值，因此系统必定在上述界限内达到所有区域的压力均不超过 $\tau_{\text{act}}$ 的状态。 Since $P(s)\geq 0$ and decreases by a fixed minimum per tick (when patches are applied), the system must reach a state where no region exceeds $\tau_{\text{act}}$ within the stated bound. 衰减约束确保系统一旦达到稳定状态便能保持稳定：最后若干补丁带来的适应度强化，其持续时间长于衰减将其消耗殆尽所需的时间。 The decay constraint ensures that stability is maintained once reached: fitness reinforcement from the final patches persists longer than the decay erodes it. $\square$ $\square$
该界限较为宽松，但它表明，收敛时间随初始压力变化，而不随状态空间大小或可能的行动数量变化。 The bound is loose but establishes that convergence time scales with initial pressure, not with state space size or number of possible actions.
5.2 吸引域质量5.2 Basin Quality
定理 5.2（吸引域质量）。Theorem 5.2 (Basin Quality).
在任意稳定吸引域 $s^{*}$ 中，产物的压力满足： In any stable basin $s^{*}$ , the artifact pressure satisfies: 
| | $P(s^{*})<n\cdot\tau_{\text{act}}$ |
其中，$n$ 为区域数量，$\tau_{\text{act}}$ 为激活阈值。 where $n$ is the number of regions and $\tau_{\text{act}}$ is the activation threshold.
证明。 Proof. 根据稳定性的定义，对所有 $i$ 均有 $P_{i}(s^{*})<\tau_{\text{act}}$。 By definition of stability, $P_{i}(s^{*})<\tau_{\text{act}}$ for all $i$ . 对所有区域求和，得到：$P(s^{*})=\sum_{i}P_{i}(s^{*})<n\cdot\tau_{\text{act}}$。 Summing over regions: $P(s^{*})=\sum_{i}P_{i}(s^{*})<n\cdot\tau_{\text{act}}$ . $\square$ $\square$
该界是紧的：对抗性初始条件可使系统处于一个各区域压力均略低于阈值的吸引域中。 This bound is tight: adversarial initial conditions can place the system in a basin where each region has pressure just below threshold. 然而，在实践中，行动器（actor）通常会将压力降至远低于 $\tau_{\text{act}}$ 的水平，从而使吸引域内的压力显著降低。 However, in practice, actors typically reduce pressure well below $\tau_{\text{act}}$ , yielding much lower basin pressures.
定理 5.3（吸引域分离）。Theorem 5.3 (Basin Separation).
在压力可分离（零耦合）的条件下，不同的稳定吸引域之间由高度至少为 $\tau_{\text{act}}$ 的压力势垒隔开。 Under separable pressure (zero coupling), distinct stable basins are separated by pressure barriers of height at least $\tau_{\text{act}}$ .
证明概要。 Proof sketch. 从一个吸引域转移到另一个吸引域，要求某个区域的压力超过 $\tau_{\text{act}}$（否则不会触发任何行动）。 Moving from one basin to another requires some region to exceed $\tau_{\text{act}}$ (otherwise no action is triggered). 满足这一超阈值条件所需的最低压力定义了势垒高度。 The minimum such exceedance defines the barrier height. $\square$ $\square$
这解释了为何衰减是必要的：如果没有衰减，系统可能会陷入次优吸引域。 This explains why decay is necessary: without decay, the system can become trapped in suboptimal basins. 衰减会逐渐削弱适应度，最终使系统能够重新评估，并有可能逃逸至压力更低的吸引域。 Decay gradually erodes fitness, eventually allowing re-evaluation and potential escape to lower-pressure basins.
5.3 扩展特性5.3 Scaling Properties
定理 5.4（线性扩展）。Theorem 5.4 (Linear Scaling).
设 $m$ 为区域数量，$n$ 为并行智能体数量。 Let $m$ be the number of regions and $n$ be the number of parallel agents. 每个时步的复杂度为： The per-tick complexity is:
信号计算：$O(m\cdot d)$，其中 $d$ 为信号维度 Signal computation: $O(m\cdot d)$ where $d$ is signal dimension
压力计算：$O(m\cdot k)$，其中 $k$ 为压力轴数量 Pressure computation: $O(m\cdot k)$ where $k$ is the number of pressure axes
补丁提议：$O(m\cdot a)$，其中 $a$ 为行动器数量 Patch proposal: $O(m\cdot a)$ where $a$ is the number of actors
选择：对候选项排序的复杂度为 $O(m\cdot a\cdot\log(m\cdot a))$ Selection: $O(m\cdot a\cdot\log(m\cdot a))$ for sorting candidates

定理 5.5（并行收敛）。Theorem 5.5 (Parallel Convergence).
在与定理 5.1 相同的对齐条件下，若每个时步并行验证 $K$ 个补丁，且这些补丁影响的区域互不相交，则系统达到稳定吸引域所需的时间上界为： Under the same alignment conditions as Theorem 5.1, with $K$ patches validated in parallel per tick where patches affect disjoint regions, the system reaches a stable basin within: 
| | $T\leq\frac{P_{0}}{K\cdot(\delta_{\min}-(n-1)\epsilon)}$ |
这使收敛时间缩短为原来的 $K$ 分之一，同时保持原有保证。 This improves convergence time by factor $K$ while maintaining guarantees.
证明概要。 Proof sketch. 当每个时步应用 $K$ 个互不冲突的补丁时，每个补丁都会使全局压力至少降低 $\delta_{\min}-(n-1)\epsilon$。 When $K$ non-conflicting patches are applied per tick, each reduces global pressure by at least $\delta_{\min}-(n-1)\epsilon$ . 每个时步的总降幅为 $K\cdot(\delta_{\min}-(n-1)\epsilon)$。 The combined reduction is $K\cdot(\delta_{\min}-(n-1)\epsilon)$ per tick. 由此可直接得到该上界。 The bound follows directly. 注意，如果补丁存在冲突（以同一区域为目标），则每个区域只会选中一个补丁，实际加速效果也会随之降低。 Note that if patches conflict (target the same region), only one is selected per region, and effective speedup is reduced. $\square$ $\square$

对齐验证：各区域的压力计算仅使用 gaps、overlaps 和 util_var——这些量都严格局限于各自的时间块。 Alignment verification: The per-region pressure computation uses only gaps, overlaps, and util_var—all strictly local to each time block. unsched 分量仅计入总压力，不计入各区域的压力。 The unsched component is added to total pressure only, not per-region. 这使得各区域的压力具有可分性：对于 $j\neq i$，修改区域 $i$ 对区域 $j$ 的压力没有任何影响，因此满足 $\epsilon=0$ 时的对齐条件（定义 2）。 This makes the per-region pressure separable: modifying region $i$ has zero effect on region $j$ ’s pressure for $j\neq i$ , satisfying the alignment condition (Definition 2) with $\epsilon=0$ . 尽管参会者约束在理论上可能造成跨区域耦合（同一个人参加不同时间块中的会议），但我们的重叠传感器仅统计各时间块内部的重叠，从而消除了这一耦合来源。 While attendee constraints could theoretically create cross-region coupling (the same person attending meetings in different time blocks), our overlap sensor counts overlaps only within each time block, eliminating this coupling source. 实证分析（附录 B）证实，所有观测到的压力改善值均为正，这与压力的可分性一致。 Empirical analysis (Appendix B) confirms that all observed pressure improvements are positive, consistent with separable pressure.
6.1.2 基线6.1.2 Baselines
我们比较了五种协调策略，它们均使用相同的大语言模型（通过 Ollama 运行的 qwen2.5:0.5b/1.5b/3b），以单独考察协调机制的影响： We compare five coordination strategies, all using identical Large Language Models (qwen2.5:0.5b/1.5b/3b via Ollama) to isolate coordination effects:
压力场（我们的方法）：完整系统，包含衰减（适应度半衰期为 5s）、抑制（冷却时间为 2s）、贪心区域选择（每个时钟步选择压力最高的区域）以及并行验证。 Pressure-field (ours): Full system with decay (fitness half-life 5s), inhibition (2s cooldown), greedy region selection (highest-pressure region per tick), and parallel validation. 包含档位升级（开发 $\to$ 均衡 $\to$ 探索）和模型升级（0.5b $\to$ 1.5b $\to$ 3b）。 Includes band escalation (Exploitation $\to$ Balanced $\to$ Exploration) and model escalation (0.5b $\to$ 1.5b $\to$ 3b).
对话：采用 AutoGen 风格的多智能体对话，智能体通过交换消息来协调排程决策。 Conversation: AutoGen-style multi-agent dialogue where agents exchange messages to coordinate scheduling decisions. 智能体通过显式通信讨论冲突并提出解决方案。 Agents discuss conflicts and propose solutions through explicit communication.
层级式：单个智能体在每个时钟步选择压力最高的时间块，提出日程修改方案，并在应用前进行验证（仅接受能够降低压力的补丁）。 Hierarchical: Single agent selects the highest-pressure time block each tick, proposes a schedule change, and validates before applying (only accepts pressure-reducing patches). 使用与压力场方法相同的提示词。 Uses identical prompts to pressure-field. 区别在于：(1) 贪心区域选择始终以最困难的区域为目标；(2) 顺序执行在每个时钟步处理一个区域。 The differences are: (1) greedy region selection always targets the hardest region, and (2) sequential execution processes one region per tick. 这体现了集中式、以质量为准入条件的控制。 This represents centralized, quality-gated control.
顺序式：单个智能体按固定顺序遍历时间块，每次针对一个区域提出日程修改。 Sequential: Single agent iterates through time blocks in fixed order, proposing schedule changes one region at a time. 不采用并行处理、压力引导或补丁验证——应用任何语法有效的补丁，无论其对质量有何影响。 No parallelism, pressure guidance, or patch validation—applies any syntactically valid patch regardless of quality impact.
随机式：随机选择时间块并提出日程修改。 Random: Selects random time blocks and proposes schedule changes. 不进行补丁验证——应用任何语法有效的补丁，无论其对质量有何影响。 No patch validation—applies any syntactically valid patch regardless of quality impact.
关于并行性的说明：压力场方法并行验证多个补丁（每个时间步处理 $K$ 个区域），而层级式方法每次顺序验证一个补丁。 Note on parallelism: Pressure-field validates multiple patches in parallel ( $K$ regions per tick), while hierarchical validates one patch sequentially. 这种不对称性是协调范式固有的，而非实现上的选择：层级式控制要求管理者先选择一个区域，将任务委派给工作者，并在继续之前验证结果——同时向多个工作者委派任务将需要额外的协调协议（任务分配、冲突解决、结果聚合），从而使其转变为一种完全不同的架构。 This asymmetry is inherent to the coordination paradigm, not an implementation choice: hierarchical control requires the manager to select a region, delegate to a worker, and validate the result before proceeding—delegating to multiple workers simultaneously would require additional coordination protocols (work distribution, conflict resolution, result aggregation) that would transform it into a different architecture entirely. 顺序处理的瓶颈是集中式控制的代价。 The sequential bottleneck is the cost of centralized control. 当层级式方法的唯一补丁被拒绝时，该时间步不会取得任何进展；而当压力场方法的某个并行补丁被拒绝时，其他补丁仍可能成功。 When hierarchical’s single patch is rejected, the tick produces no progress; when one of pressure-field’s parallel patches is rejected, others may still succeed.
模型选择依据：我们有意采用能力较为有限的小型模型（0.5b–3b 参数），而非前沿模型。 Model choice rationale: We deliberately use small, minimally-capable models (0.5b–3b parameters) rather than frontier models. 这一设计选择强化了我们的论点：如果协调机制能够使弱模型发挥出有效的性能，那么该机制本身就具有独立于模型能力的价值。 This design choice strengthens our thesis: if the coordination mechanism can extract effective performance from weak models, the mechanism itself is valuable—independent of model capability. 所有策略均使用相同的模型链，从而将协调效应与模型效应分离。 Using identical model chains across all strategies isolates coordination effects from model effects. 我们假设，前沿模型（例如 GPT-4、Claude）会提高所有策略的绝对求解成功率，同时保持其相对排名：协调优势与模型能力正交，因此，即使基线水平提高，压力场方法相对于对话式基线的 $4\times$ 提升也应持续存在。 We hypothesize that frontier models (e.g., GPT-4, Claude) would raise absolute solve rates across all strategies while preserving relative rankings: the coordination advantage is orthogonal to model capability, so pressure-field’s $4\times$ improvement over conversation baselines should persist even as the baseline rises.

6.3.3 负信息素6.3.3 Negative Pheromones
除了正信息素（存储起来用作少样本示例的成功补丁），我们还实现了负信息素：跟踪那些使压力恶化而被拒绝的补丁。 In addition to positive pheromones (successful patches stored for few-shot examples), we implement negative pheromones: tracking rejected patches that worsened pressure. 当智能体反复提出无效补丁（压力停滞在最大值）时，系统会积累拒绝历史，并将指导信息注入后续提示中。 When agents repeatedly propose ineffective patches (pressure stuck at maximum), the system accumulates rejection history and injects guidance into subsequent prompts.
小模型（1.5B 参数）难以遵循“避免”式表述，因此我们采用正向语言：被拒绝的空会议室补丁会转化为“提示：将会议安排在 Room A（改善幅度为 X）。” Unlike the “AVOID” framing that small models (1.5B parameters) struggle to follow, we use positive language: rejected empty-room patches become “TIP: Schedule meetings in Room A (improves by X).” 这将不应采取的做法重新表述为可以尝试的替代做法。 This reframes what not to do as what to try instead.
负信息素以与正向示例相同的速率衰减（每个时间步执行 $\text{weight}\times 0.95$，低于 0.1 时移除），确保过去的失败不会永久阻碍有效方法。 Negative pheromones decay at the same rate as positive examples ( $\text{weight}\times 0.95$ per tick, evicted below 0.1), ensuring that old failures don’t permanently block valid approaches. 每个区域最多 3 条近期拒绝记录会以“更好地安排会议的提示”的形式纳入提示中。 Up to 3 recent rejections per region are included in prompts as “Hints for better scheduling.”

升级机制展示了压力场协调所促成的 FM-MAS 共生关系。 The escalation mechanism demonstrates the FM-MAS symbiosis that pressure-field coordination enables. 传统方法面临两难：要么在所有环节使用能力强的大模型（成本高），要么在所有环节使用高效的小模型（能力有限）。 Traditional approaches face a dilemma: use a large, capable model everywhere (expensive) or use a small, efficient model everywhere (limited). 压力场协调通过梯度驱动的能力调用化解了这一两难：协调机制本身决定何时需要更强的基础模型（Foundation Model）能力。 Pressure-field coordination dissolves this dilemma through gradient-driven capability invocation: the coordination mechanism itself determines when greater Foundation Model capability is needed.
蚁群在利用已知食物来源与探索新食物来源之间取得平衡。 Ant colonies balance exploitation of known food sources against exploration for new ones. 当信息素路径逐渐失效，表明食物来源已经耗尽时，觅食蚂蚁便会放弃沿路径行进，重新开始随机探索，最终发现新的路线，形成下一代信息素路径。 When a pheromone trail grows stale—indicating a depleted source—foragers abandon trail-following and resume random exploration, eventually discovering new paths that become the next generation of trails. 这种利用与探索之间的平衡是痕迹协调（stigmergy）系统的基本特征：必须通过恢复探索行为的机制，抵消过早固守次优解的倾向。 This exploitation-exploration balance is fundamental to stigmergic systems: premature commitment to suboptimal solutions must be counteracted by mechanisms that restore exploratory behavior.
我们的升级机制通过两种互补的动态过程实现这一原则。 Our escalation mechanism implements this principle through two complementary dynamics. 档位升级调节单个模型内部利用与探索之间的权衡：当压力变化速率降至零（即“路径失效”）时，采样参数从利用档（低温度、集中的提案）经过平衡档，转向探索档（高温度、多样化的提案）。 Band escalation governs the exploitation-exploration trade-off within a single model: when pressure velocity drops to zero (the “trail goes cold”), sampling parameters shift from exploitation (low temperature, focused proposals) through balanced to exploration (high temperature, diverse proposals). 这与信息素信号减弱时，蚂蚁从沿路径行进切换为随机游走的行为相呼应。 This mirrors the ant’s behavioral switch from trail-following to random wandering when pheromone signals weaken.

MAS 的贡献：压力梯度为何时升级提供了客观判据。 MAS contribution: The pressure gradient provides the objective criterion for when to escalate. 无需关于“问题难度”的启发式规则；压力变化速率停滞就已足以作为信号。 No heuristics about “problem difficulty” are needed; stagnant pressure velocity is sufficient signal. 协调机制无需显式的能力模型，即可管理异构基础模型的能力。 The coordination mechanism manages heterogeneous Foundation Model capabilities without explicit capability models.
这一双层机制——智能体内部的行为适应（档位升级）与智能体之间的能力升级（模型升级）——遵循了痕迹协调原则：协调由环境信号（压力梯度）涌现，而非源于显式规划。 This two-level mechanism—behavioral adaptation within agents (band escalation) and capability escalation across agents (model escalation)—maintains the stigmergic principle: coordination emerges from environment signals (pressure gradients) rather than explicit planning. 系统并不“决定”进行探索或升级；它只是对压力停滞作出反应，正如蚂蚁对信息素衰减作出反应一样。 The system does not “decide” to explore or escalate; it reacts to pressure stagnation, just as ants react to pheromone decay. 由此实现了基础模型的自适应使用：低成本模型处理容易的区域，高成本模型则留给低成本模型陷入停滞的区域。 The result is adaptive Foundation Model utilization: cheap models handle easy regions, expensive models are reserved for regions where cheap models stall.

7.1 为什么 Pressure-Field 占据优势？7.1 Why Does Pressure-Field Dominate?
我们的结果与显式协调应优于隐式协调这一直觉相悖。 Our results contradict the intuition that explicit coordination should outperform implicit coordination. 我们确定了三个因素，用以解释 pressure-field 的优势： We identify three factors explaining pressure-field’s dominance:
协调开销会损害性能。 Coordination overhead harms performance. 层级式系统将计算预算用于协调，而非求解问题。 Hierarchical systems spend computational budget on coordination rather than problem-solving. 管理者—工作者协议针对每个补丁都需要多次调用大语言模型（规划、委派、执行），而 pressure-field 只需调用一次（提出补丁）。 The manager-worker protocol requires multiple Large Language Model calls per patch (planning, delegation, execution), while pressure-field requires only one (patch proposal). 这种开销会累积：hierarchical 在每个时间步尝试的补丁更少，从而减少了探索。 This overhead compounds: hierarchical attempts fewer patches per tick, reducing exploration.
局部贪心决策对约束满足问题有效。 Local greedy decisions are effective for constraint satisfaction. 会议室调度具有局部性：修复一个时间块中的冲突，很少会在相距较远的时间块中引发冲突。 Meeting room scheduling exhibits locality: fixing a conflict in one time block rarely creates conflicts in distant blocks. 这与 pressure-field 的局部性假设相吻合，使局部贪心优化能够有效发挥作用。 This matches pressure-field’s locality assumption, making greedy local optimization effective. 对于可局部分解的问题，层级式协调中的全局规划并无益处。 Hierarchical coordination’s global planning provides no benefit for locally-decomposable problems.
并行验证放大了 pressure-field 的优势。 Parallel validation amplifies pressure-field’s advantage. Pressure-field 同时验证多个区域的补丁，并为每个区域应用能够降低压力且得分最高的补丁。 Pressure-field validates patches for multiple regions simultaneously, applying the highest-scoring patch per region that reduces pressure. Hierarchical 每次只验证一个补丁，需要多个时间步才能探索备选方案。 Hierarchical validates one patch at a time, requiring multiple ticks to explore alternatives. 对于具有许多有效解的问题，并行探索能够更快地找到解。 On problems with many valid solutions, parallel exploration finds solutions faster.
7.2 失败分析：为什么 Hierarchical 会崩溃7.2 Failure Analysis: Why Hierarchical Collapses
30 $\times$ 的性能差距（48.5% 对比 1.5%）需要更深入的研究。 The 30 $\times$ performance gap (48.5% vs 1.5%) demands deeper investigation. 对 hierarchical 试验的分析揭示了一种灾难性的失败模式：拒绝循环。 Analysis of hierarchical trials reveals a catastrophic failure pattern: the rejection loop.
拒绝循环的机制。 The rejection loop mechanism. Hierarchical 总是选择压力最高的区域进行改进。 Hierarchical always selects the highest-pressure region for improvement. 然而，压力最高的区域之所以压力高，恰恰是因为它们难以改进。 But the highest-pressure regions are high-pressure precisely because they are difficult to improve. 当大语言模型提出的补丁未通过验证（未能降低压力）时，该区域仍然具有最高压力，因此会在下一个时间步再次被选中。 When the Large Language Model proposes a patch that fails validation (does not reduce pressure), the region remains highest-pressure and is selected again next tick. 这形成了一个自我强化的循环：66.7% 的 hierarchical 运行（180/270）在全部 50 个时间步中未应用任何补丁，陷入了反复针对同一难以处理的区域进行尝试的困境。 This creates a self-reinforcing cycle: 66.7% of hierarchical runs (180/270) applied zero patches across all 50 ticks, stuck targeting the same intractable region repeatedly.
拒绝率证实了这一模式。 Rejection rates confirm the pattern. 在所有 hierarchical 试验中，提出的 13,460 个补丁仅有 173 个被接受，拒绝率达 98.7%。 Across all hierarchical trials, only 173 patches were accepted out of 13,460 proposed—a 98.7% rejection rate. 相比之下，pressure-field 的并行探索意味着，即使一个智能体的补丁被拒绝，其他智能体仍可在不同区域取得进展。 By contrast, pressure-field’s parallel exploration means that even if one agent’s patch is rejected, other agents make progress on different regions. 这种非阻塞架构可防止任何单个困难区域导致整个系统停滞。 The non-blocking architecture prevents any single difficult region from stalling the entire system.
架构层面的启示。 The architectural lesson. Hierarchical 的设计体现了一种合理的直觉：将智能处理资源集中于最棘手的问题。 Hierarchical’s design embodies a reasonable intuition: focus intelligent effort on the worst problems. 但当这种设计与严格验证结合时，就会形成一个陷阱：最难的问题难以改进，导致补丁反复被拒绝，进而阻碍所有区域取得进展。 But this creates a trap when combined with strict validation: the hardest problems resist improvement, causing repeated rejection, which blocks progress everywhere. Pressure-field 通过分布式探索避开了这一陷阱——哪里能够取得进展，就在哪里推进，而不是由中央规划者指定必须在哪里取得进展。 Pressure-field avoids this trap through distributed exploration—progress happens where it can, not where a central planner dictates it must.

7.3.1 幻觉过滤与涌现轨迹7.3.1 Hallucination Filtering and Emergent Trajectories
验证阶段（Phase 2b）用于过滤单个基础模型（Foundation Model）产生的幻觉：会增加压力或违反语法约束的补丁会在应用前被拒绝。 The validation phase (Phase 2b) serves as a filter for individual Foundation Model hallucinations: patches that increase pressure or violate syntactic constraints are rejected before application. 这在单次行动层面提供了强有力的保证——任何单次幻觉都无法直接损害产物质量。 This provides strong guarantees at the individual-action level—no single hallucination can directly harm artifact quality.
然而，系统层面的行为由一系列通过验证的补丁涌现而成，轨迹层面的风险仍然存在。 However, system-level behavior emerges from sequences of validated patches, and trajectory-level risks remain. 考虑一个假设场景：某个智能体提出一个补丁，通过一项改动降低区域 $R_{1}$ 的压力，但该改动引入了对区域 $R_{2}$ 的隐蔽依赖。 Consider a hypothetical scenario: an agent proposes a patch that reduces pressure in region $R_{1}$ by making a change that creates a subtle dependency on region $R_{2}$ . 该补丁通过了验证（压力下降），但此后对 $R_{2}$ 的补丁会对 $R_{1}$ 产生不可预测的影响。 The patch is validated (pressure decreased), but subsequent patches to $R_{2}$ now have unpredictable effects on $R_{1}$ . 每个补丁都降低了压力，但涌现出的轨迹形成了局部验证无法察觉的脆弱耦合。 The individual patches are all pressure-reducing, but the emergent trajectory creates fragile coupling that was invisible to local validation.
更一般地说，基于压力降低的验证过滤机制无法检测到： More generally, validation filters based on pressure reduction cannot detect:
一致性漂移：单项改进累积起来，使产物逐渐偏向不一致状态 Coherence drift: Individual improvements that collectively shift the artifact toward an inconsistent state
涌现式钻空子：补丁利用压力函数的弱点，其方式只有经过多个步骤才会显现 Emergent gaming: Patches that exploit pressure function weaknesses in ways only apparent over multiple steps
依赖累积：逐步引入隐藏耦合，降低未来的可改进性 Dependency accumulation: Gradual introduction of hidden couplings that reduce future improvability
缓解轨迹层面的风险需要局部验证之外的机制：定期进行全局一致性检查、记录轨迹以供事后分析，以及在压力函数中不仅对局部质量问题施加惩罚，还对耦合指标施加惩罚。 Mitigating trajectory-level risks requires mechanisms beyond local validation: periodic global coherence checks, trajectory logging for post-hoc analysis, and pressure functions that penalize not just local quality but also coupling metrics. 这些仍有待未来研究。 These remain areas for future work.
7.3.2 衰减校准不当的失效模式7.3.2 Decay Miscalibration Failure Modes
时间衰减对于摆脱局部最优至关重要（定理 5.3），但校准不当的衰减率会引入不同的失效模式： Temporal decay is critical for escaping local optima (Theorem 5.3), but miscalibrated decay rates introduce distinct failure modes:
衰减过快会妨碍系统保持稳定。 Too-fast decay prevents stability. 当适应度的衰减速度超过智能体强化成功区域的速度时，系统就无法维持任何稳定配置。 When fitness decays faster than agents can reinforce successful regions, the system cannot maintain any stable configuration. 已解决的区域会立即重新变为高压力区域，从而触发不必要的返工。 Solved regions immediately become high-pressure again, triggering unnecessary rework. 在极限情况下，过快的衰减会导致持续振荡：智能体打补丁，衰减抹去其效果，智能体再次打补丁，如此无限循环。 In the limit, excessively fast decay produces perpetual oscillation: agents patch, decay erases, agents re-patch, indefinitely.
衰减过慢会使系统陷入局部极小值。 Too-slow decay traps in local minima. 当适应度的衰减时间尺度长于探索时间尺度时，智能体就无法逃离次优吸引域。 When fitness decays slower than the exploration timescale, agents cannot escape suboptimal basins. 早期补丁形成的适应度峰值会无限期持续存在，即使存在更好的解，也会阻碍重新评估。 Early patches establish fitness peaks that persist indefinitely, preventing reconsideration even when better solutions exist. 我们的消融研究提示了这种失效模式：在没有衰减的情况下，我们观察到求解率下降了 10 个百分点，这与智能体持续困于初始吸引域的情况一致（尽管在 $n=30$ 时，该效应未达到统计显著性）。 This is the failure mode our ablation study suggests: without decay, we observed a 10 percentage point reduction in solve rate, consistent with agents remaining trapped in initial basins (though the effect did not reach statistical significance at $n=30$ ).
最优衰减率取决于问题特征：局部极小值更深的困难问题需要更快的衰减以便逃离，而解较为脆弱的问题则需要更慢的衰减以维持稳定。 The optimal decay rate depends on problem characteristics: harder problems with deeper local minima require faster decay to enable escape, while problems with fragile solutions require slower decay to maintain stability. 我们的实验采用固定衰减率（$\lambda_{f}=0.1$，适应度半衰期为 5 秒），对于某些问题实例而言，这可能并非最优。 Our experiments use fixed decay rates ( $\lambda_{f}=0.1$ , fitness half-life 5 seconds), which may be suboptimal for some problem instances. 自适应衰减——根据压力变化速率调整衰减率——是未来工作中一个很有前景的方向。 Adaptive decay—adjusting rates based on pressure velocity—is a promising direction for future work.

7.7.1 基础模型解决 MAS 协调问题7.7.1 Foundation Models Solve a MAS Coordination Problem
传统的多智能体系统协调需要显式枚举动作空间。 Traditional Multi-Agent System coordination requires explicit action space enumeration. 广义部分全局规划（Generalized Partial Global Planning）通过声明的能力与承诺来协调任务；SharedPlans 对动作序列及其前置条件进行推理；组织模型则分配具有指定行为的角色。 Generalized Partial Global Planning coordinates tasks through declared capabilities and commitments; SharedPlans reasons about action sequences and their preconditions; organizational models assign roles with specified behaviors. 所有这些方法都假设，设计者能够枚举智能体可以执行哪些操作，以及在何种条件下执行这些操作。 All these approaches assume that designers can enumerate what agents can do and under what conditions.
对于开放式产物改进——提高代码质量、完善文档、优化配置——这种枚举在计算上是不可行的。 For open-ended artifact refinement—improving code quality, refining documents, optimizing configurations—this enumeration is intractable. 可能的改进空间是无界的；任何有限的动作语言都无法涵盖所有有效补丁。 The space of possible improvements is unbounded; no finite action language captures all valid patches. 传统的多智能体系统（Multi-Agent System）方法要求要么 (a) 将问题限制在动作可枚举且易于处理的子集内，要么 (b) 为每种产物类型开发领域专用的动作表示。 Traditional Multi-Agent System approaches require either (a) restricting the problem to a tractable subset with enumerable actions, or (b) developing domain-specific action representations for each artifact type.
基础模型（Foundation Models）消除了这种枚举要求。 Foundation Models eliminate this enumeration requirement. 它们广泛的预训练隐式涵盖了不同领域的改进策略，无需显式指定动作。 Their broad pretraining provides implicit coverage of improvement strategies across diverse domains without explicit action specification. 大语言模型执行者可以使用同一套接口，为代码、自然语言、结构化数据或配置文件提出补丁：观察局部上下文、接收压力反馈、生成改进提案。 An Large Language Model actor can propose patches for code, natural language, structured data, or configuration files using the same interface: observe local context, receive pressure feedback, generate improvement proposals. 这种“通用执行者”能力使得基于迹的协调（stigmergic coordination）能够应用于某些问题类别，而传统的多智能体系统方法在这些问题上需要大量的领域工程工作。 This “universal actor” capability enables stigmergic coordination on problem classes where traditional Multi-Agent System approaches would require extensive domain engineering.
7.7.2 多智能体系统解决了基础模型的一个问题7.7.2 Multi-Agent Systems Solve a FM Problem
反过来，基础模型面临一个可由多智能体系统协调机制解决的根本问题：如何连贯一致地整合多个输出。 Conversely, Foundation Models face a fundamental problem that Multi-Agent System coordination solves: how to combine multiple outputs coherently. 单个基础模型对每次查询生成一个响应；要扩展到复杂产物，就需要编排多次生成。 A single Foundation Model produces one response per query; scaling to complex artifacts requires orchestrating multiple generations. 当前方法使用临时性的整合策略：投票、排序、思维链聚合，或人在回路中的选择。 Current approaches use ad-hoc combination strategies: voting, ranking, chain-of-thought aggregation, or human-in-the-loop selection.
压力场协调为整合基础模型输出提供了一个具有系统性原理依据的框架。 Pressure-field coordination provides a principled framework for combining Foundation Model outputs. 压力梯度定义了一项客观标准：接受能够降低压力的补丁，拒绝无法降低压力的补丁，而不是通过投票决定哪个响应“最好”，或根据启发式评分对输出进行排序。 Rather than voting on which response is “best” or ranking outputs by heuristic scores, the pressure gradient defines an objective criterion: accept patches that reduce pressure, reject those that do not. 多个基础模型输出依据其对一个明确定义的质量函数的影响展开竞争，而非依据受欢迎程度或任意排序。 Multiple Foundation Model outputs compete not through popularity or arbitrary ranking, but through their effect on a well-defined quality function.
这一视角阐明了压力场协调为何优于基于对话的基线方法。 This framing clarifies why pressure-field coordination outperforms conversation baselines. AutoGen 风格的多智能体对话是一种临时性的整合策略——智能体交换消息，并通过涌现出的共识得出结论。 AutoGen-style multi-agent dialogue is an ad-hoc combination strategy—agents exchange messages and reach conclusions through emergent consensus. 压力场协调用客观梯度取代涌现出的共识：当产物状态能够裁定质量时，就无需协商。 Pressure-field coordination replaces emergent consensus with objective gradients: no negotiation is needed when the artifact state adjudicates quality.

利用 FM 的覆盖广度，通过 MAS 梯度施加约束。 Leverage FM coverage, constrain via MAS gradients. 利用基础模型对解决方案的广泛覆盖，同时使用多智能体系统的协调机制，客观地筛选和整合输出。 Use Foundation Models for their broad solution coverage, but use Multi-Agent System coordination mechanisms to filter and combine outputs objectively.
优先采用基于迹的协调，而非显式协调。 Prefer stigmergic over explicit coordination. 当基础模型充当执行者时，基于迹的协调可以避免显式协议带来的开销，而 FM 未必能够可靠地遵循这些协议。 When Foundation Models serve as actors, stigmergic coordination avoids the overhead of explicit protocols that FMs may not reliably follow.
将压力函数设计为 FM-MAS 的接口。 Design pressure functions as FM-MAS interfaces. 压力函数是关键接口：它必须足够精确地捕捉人类意图，使得基础模型生成的、能够降低压力的输出确实构成改进。 The pressure function is the critical interface: it must capture human intent precisely enough that Foundation Model outputs reducing pressure are genuinely improvements.
我们的实验结果——压力场的求解成功率达到基于对话的基线方法的 $4\times$——为这些原则提供了实证支持。 Our experimental results—pressure-field achieving $4\times$ higher solve rates than conversation baselines—provide empirical support for these principles. 当存在客观梯度时，显式对话的协调开销超过了其组织收益。 The coordination overhead of explicit dialogue exceeds its organizational benefit when objective gradients are available.
7.8 社会影响7.8 Societal Implications
压力场协调引发了超出技术性能范畴的社会层面关切。 Pressure-field coordination raises societal concerns that extend beyond technical performance. 我们识别出三个关键问题——责任归属、古德哈特定律（Goodhart’s Law）所揭示的指标操纵，以及可解释性挑战——这些问题要求在部署时作出审慎的设计选择。 We identify three critical issues—accountability attribution, metric gaming through Goodhart’s Law, and explainability challenges—that require deliberate design choices in deployment.
7.8.1 问责与归因7.8.1 Accountability and Attribution
当协调源于共享压力梯度而非显式委派时，将结果归因于单个智能体就会变得困难。 When coordination emerges from shared pressure gradients rather than explicit delegation, attributing outcomes to individual agents becomes challenging. 在层级系统中，任务分配建立了清晰的责任链。 In hierarchical systems, task assignment creates clear accountability chains. 在压力场协调中，多个智能体可能通过独立的降压动作对同一区域作出贡献，却没有记录表明哪个智能体对该结果“负责”。 In pressure-field coordination, multiple agents may contribute to a region through independent pressure-reducing actions, with no record of which agent “owned” the outcome.
这种责任分散既有益处，也有风险。 This accountability diffusion has both benefits and risks. 其益处是容错性：智能体故障会使性能平缓下降，而不会导致灾难性失效。 The benefit is fault tolerance: agent failures degrade performance gracefully rather than catastrophically. 其风险是故障分析缺乏透明度：要确定哪个智能体提出了有问题的补丁，以及何种压力信号促使其提出该补丁，需要详细的日志记录，而最小化的协调机制本身并不提供这种记录。 The risk is opacity in failure analysis: identifying which agent proposed a problematic patch—and what pressure signal motivated it—requires detailed logging that the minimal coordination mechanism does not inherently provide.
对于受监管领域的部署，这意味着需要增加一项功能：压力场系统必须维护审计日志，记录补丁来源、提出补丁时的压力信号，以及验证结果。 For deployment in regulated domains, this suggests an augmentation requirement: pressure-field systems must maintain audit logs recording patch provenance, pressure signals at proposal time, and validation outcomes. 协调机制仍然保持简单——智能体通过共享状态进行协调——但实际部署需要增设日志基础设施，以保留可追责性。 The coordination mechanism remains simple—agents coordinate through shared state—but operational deployment adds logging infrastructure preserving accountability.
7.8.2 古德哈特定律与指标投机7.8.2 Goodhart’s Law and Metric Gaming
古德哈特定律指出：“当一项度量成为目标时，它就不再是一项好的度量。” Goodhart’s Law states: “When a measure becomes a target, it ceases to be a good measure.” 压力场协调容易受到这一动态机制的影响，因为智能体的优化目标是降低由设计者指定的函数所定义的压力。 Pressure-field coordination is vulnerable to this dynamic because agents are optimized to reduce pressure as defined by designer-specified functions. 如果这些函数未能完全反映真实质量——而这不可避免——智能体就会发现并利用这种偏差。 If those functions imperfectly capture true quality—and they inevitably do—agents will discover and exploit the mismatch.
考虑对复杂度指标施加惩罚的代码质量压力函数。 Consider code quality pressure functions penalizing complexity metrics. 智能体可能通过过度拆分函数来降低复杂度，在改善指标的同时损害可读性。 An agent might reduce complexity by splitting functions excessively, harming readability while improving the metric. 缓解方法不是放弃压力函数，而是对其进行防御性设计：采用多个正交的压力维度，加入用于检测投机策略的对抗性传感器，并审查压力降低是否与人类对质量的判断相关。 The mitigation is not abandoning pressure functions but designing them defensively: use multiple orthogonal pressure axes, include adversarial sensors detecting gaming strategies, and audit whether pressure reduction correlates with human quality judgments. 随着智能体发现可利用的漏洞，压力函数也应随之演进。 Pressure functions should evolve as agents discover exploits.
基础模型引入了二阶投机问题：在互联网规模文本上训练的大语言模型可能隐含地掌握了如何针对特定基准进行投机的知识。 Foundation models introduce second-order gaming concerns: Large Language Models trained on internet-scale text may have implicit knowledge of how to game specific benchmarks. 这表明，基于大语言模型的系统所采用的压力函数应优先使用领域特定的质量信号，使其更难在没有实质性改进的情况下得到优化。 This suggests pressure functions for Large Language Model-based systems should favor domain-specific quality signals harder to optimize without genuine improvement.
7.8.3 可解释性挑战7.8.3 Explainability Challenges
在层级式系统中，解释沿着任务委派链展开：“管理者 X 将任务 Y 分配给工作者 Z，因为条件 C 成立。” In hierarchical systems, explanations follow delegation chains: “Manager X assigned task Y to Worker Z because condition C held.” 在压力场协调中，解释是：“区域 R 的压力较高，智能体 A 提出了补丁 $\Delta$，使压力降低了 $\delta$。” In pressure-field coordination, the explanation is: “Region R had high pressure, agent A proposed patch $\Delta$ reducing pressure by $\delta$ .” 这种解释在机制上是透明的，但在因果上却是不透明的——它描述了发生了什么，却没有解释为何选择了这一特定补丁。 This is mechanistically transparent but causally opaque—it describes what happened without explaining why that particular patch was chosen.
这是涌现式协调固有的可解释性权衡：机制的简单性以决策理由的可理解性为代价。 This is the explainability trade-off inherent to emergent coordination: simplicity in mechanism comes at the cost of legibility in rationale. 对于许多领域——代码格式化、资源优化、日常维护——这种权衡是可以接受的：即使推理过程不透明，结果仍可验证。 For many domains—code formatting, resource optimization, routine maintenance—the trade-off is acceptable: outcomes are verifiable even if reasoning is opaque. 对于需要人类监督的高风险领域，不透明性是不可接受的。 For high-stakes domains requiring human oversight, opacity is unacceptable.
由此得出的设计启示是，应根据领域特点进行部署：压力场协调适用于结果验证成本低的领域，即使其推理透明度有限。 The design implication is domain-dependent deployment: pressure-field coordination suits domains where outcome verification is cheap even if reasoning transparency is limited. 对于需要向人类利益相关方说明理由的领域，尽管存在额外开销，层级式协调仍然是必要的。 For domains requiring justification to human stakeholders, hierarchical coordination remains necessary despite overhead costs.
7.8.4 设计启示7.8.4 Design Implications
这些问题表明，负责任的部署需要满足三项要求：通过全面的审计日志保留补丁来源和压力信号，采用具有多个正交维度的防御性压力函数设计，以及实施适合领域特点的验证，使协调过程的不透明程度与结果的可验证性相匹配。 These concerns suggest three requirements for responsible deployment: comprehensive audit logging preserving patch provenance and pressure signals, defensive pressure function design with multiple orthogonal axes, and domain-appropriate verification matching coordination opacity with outcome verifiability. 协调机制仍然简单——但负责任的部署需要配套基础设施来解决问责、投机和可解释性问题。 The coordination mechanism remains simple—but responsible deployment requires surrounding infrastructure addressing accountability, gaming, and explainability.
8 结论8 Conclusion
我们提出了压力场协调，这是一种用于多智能体系统的去中心化方法，通过共享状态和局部压力梯度实现协调，而非依靠显式编排。 We presented pressure-field coordination, a decentralized approach to Multi-Agent Systems that achieves coordination through shared state and local pressure gradients rather than explicit orchestration.
我们的理论分析确立了压力对齐条件下的收敛保证，且协调开销与智能体数量无关。 Our theoretical analysis establishes convergence guarantees under pressure alignment conditions, with coordination overhead independent of agent count. 在实证研究中，我们针对会议室调度共进行了 1350 次试验（每种策略 270 次），发现： Empirically, on meeting room scheduling across 1350 total trials (270 per strategy), we find:
隐式协调优于显式协调。 Implicit coordination outperforms explicit coordination. 压力场方法的总体求解成功率达到 48.5%——近一半的问题仅通过遵循局部压力得到解决，无需协调器、消息传递或显式任务委派。 Pressure-field achieves 48.5% aggregate solve rate—nearly half of all problems solved through local pressure-following alone, with no coordinator, no message passing, and no explicit task delegation. 相较于层级式控制（$30\times$）和基于对话的协调（$4\times$），其差距既大又具有高度统计显著性（均为 $p<0.001$）。 The gap versus hierarchical control ( $30\times$ ) and conversation-based coordination ( $4\times$ ) is both large and highly significant (all $p<0.001$ ).
压力场方法是唯一能够扩展到更难问题的策略。 Pressure-field is the only strategy that scales to harder problems. 在中等和高难度问题上，压力场方法的求解成功率分别达到 43.3% 和 15.6%，而所有基线方法均为 0%。 On medium and hard problems, pressure-field achieves 43.3% and 15.6% solve rates respectively, while all baselines achieve 0%.
时间衰减表现出有益效果。 Temporal decay shows beneficial effects. 消融研究观察到，启用衰减后性能提高了 10 个百分点，这与关于逃离局部极小值的理论预测一致，但仍需要更大的样本量来确立统计显著性。 Ablation studies observe a 10 percentage point improvement with decay enabled, consistent with theoretical predictions about escaping local minima, though larger samples would be needed to establish statistical significance.
本研究表明，对于约束满足任务，隐式协调可以优于显式协调。 This work demonstrates that implicit coordination can outperform explicit coordination for constraint satisfaction tasks. 压力场方法以更简单的架构实现了这一点：无需协调器智能体，无需显式消息传递，仅依靠共享状态和局部压力梯度。 Pressure-field achieves this with simpler architecture: no coordinator agent, no explicit message passing, just shared state and local pressure gradients.
基础模型的零样本能力消除了对领域特定动作表示的需求；压力场协调消除了对复杂多智能体协议的需求；两者共同使简单的多智能体系统成为可能。 Foundation Models’ zero-shot capabilities eliminate the need for domain-specific action representations; pressure-field coordination eliminates the need for complex multi-agent protocols; together they enable simple Multi-Agent Systems.
这些结果表明，对于具有可度量质量信号和可局部分解结构的领域，通过共享状态进行隐式协调，为显式层级式控制提供了一种不仅更简单、而且更有效的替代方案。 These results suggest that for domains with measurable quality signals and locally-decomposable structure, implicit coordination through shared state offers not just a simpler but a more effective alternative to explicit hierarchical control.

11.1 定理 5.1（收敛性）的证明11.1 Proof of Theorem 5.1 (Convergence)
证明。Proof.
我们证明，系统会在所述界限内达到稳定吸引域。 We show that the system reaches a stable basin within the stated bound.
设定。 Setup. 令 $P^{t}=P(s^{t})$ 表示时刻 $t$ 的全局压力。 Let $P^{t}=P(s^{t})$ denote global pressure at tick $t$ . 在 $\epsilon$ 有界耦合下，当一个补丁使局部压力 $P_{i}$ 降低 $\delta_{i}$ 时，全局压力的变化为： Under $\epsilon$ -bounded coupling, when a patch reduces local pressure $P_{i}$ by $\delta_{i}$ , global pressure changes by: 
| | $P^{t+1}-P^{t}=-\delta_{i}+\sum_{j\neq i}(P_{j}(s^{t+1})-P_{j}(s^{t}))$ |

| | $P^{t+1}-P^{t}\leq-\delta_{i}+(n-1)\epsilon$ |
进展保证。 Progress guarantee. 若 $\delta_{i}\geq\delta_{\min}$ 且 $\delta_{\min}>(n-1)\epsilon$，则： If $\delta_{i}\geq\delta_{\min}$ and $\delta_{\min}>(n-1)\epsilon$ , then: 
| | $P^{t+1}-P^{t}\leq-\delta_{\min}+(n-1)\epsilon<0$ |

终止性。 Termination. 由于对所有状态均有 $P(s)\geq 0$，且在应用补丁时，每个时间步的压力降幅至少为固定值 $\Delta=\delta_{\min}-(n-1)\epsilon$，因此系统必定会达到没有任何区域的压力超过 $\tau_{\text{act}}$ 的状态，所需时间步数不超过： Since $P(s)\geq 0$ for all states and pressure decreases by a fixed minimum $\Delta=\delta_{\min}-(n-1)\epsilon$ per tick (when patches are applied), the system must reach a state where no region exceeds $\tau_{\text{act}}$ within: 
| | $T\leq\frac{P_{0}}{\Delta}=\frac{P_{0}}{\delta_{\min}-(n-1)\epsilon}$ |
个时间步。 ticks. 此时，没有任何区域被激活，系统已达到稳定吸引域。 At this point, no region activates, and the system has reached a stable basin.
稳定性的维持。 Stability maintenance. 衰减约束 $\Delta_{f}>1-e^{-\lambda_{f}\cdot\tau_{\text{inh}}}$ 确保最后几个补丁带来的适应度强化量超过抑制期内的衰减量。 The decay constraint $\Delta_{f}>1-e^{-\lambda_{f}\cdot\tau_{\text{inh}}}$ ensures that fitness reinforcement from the final patches exceeds decay during the inhibition period. 这可防止系统在达到稳定后立即重新激活。∎ This prevents immediate re-activation after reaching stability. ∎
11.2 定理 5.3（吸引域分离）的证明11.2 Proof of Theorem 5.3 (Basin Separation)
证明。Proof.
我们证明，不同的稳定吸引域之间由高度至少为 $\tau_{\text{act}}$ 的压力势垒隔开。 We show that distinct stable basins are separated by pressure barriers of height at least $\tau_{\text{act}}$ .
吸引域的定义。 Basin definition. 稳定吸引域 $B$ 是状态空间中的一个连通区域，其中所有状态对于所有区域 $i$ 均满足 $P_{i}(s)<\tau_{\text{act}}$。 A stable basin $B$ is a connected region of state space where all states satisfy $P_{i}(s)<\tau_{\text{act}}$ for all regions $i$ . 在吸引域内，没有智能体采取行动（压力低于激活阈值）。 Within a basin, no agent takes action (pressure below activation threshold).
转移要求。 Transition requirement. 要从吸引域 $B_{1}$ 转移到另一个不同的吸引域 $B_{2}$，系统必须经过不属于这两个吸引域中任何一个的状态。 To move from basin $B_{1}$ to a distinct basin $B_{2}$ , the system must pass through states not in either basin. 在 $B_{1}$ 的边界处，至少有一个区域 $i$ 必须满足 $P_{i}(s)\geq\tau_{\text{act}}$（否则，根据可分离压力下的连续性，该状态仍将属于 $B_{1}$）。 At the boundary of $B_{1}$ , at least one region $i$ must have $P_{i}(s)\geq\tau_{\text{act}}$ (otherwise, by continuity under separable pressure, the state would still be in $B_{1}$ ).
势垒高度。 Barrier height. 退出吸引域所需达到的最低压力越限值为 $\tau_{\text{act}}$。 The minimum pressure exceedance required to exit a basin is $\tau_{\text{act}}$ . 这定义了分隔吸引域的势垒高度。 This defines the barrier height separating basins.
对衰减的含义。 Implication for decay. 若没有衰减，系统一旦进入某个吸引域，就会无限期地停留其中——适应度始终保持较高水平，从而阻止重新激活。 Without decay, once the system enters a basin, it remains there indefinitely—fitness remains high, preventing re-activation. 衰减会使适应度随时间逐渐降低，最终使压力能够超过 $\tau_{\text{act}}$，从而允许系统转移到压力可能更低的吸引域。∎ Decay erodes fitness over time, eventually allowing pressure to exceed $\tau_{\text{act}}$ and enabling transition to potentially lower-pressure basins. ∎

证明。Proof.
我们分析每个时钟步的计算复杂度。 We analyze the per-tick computational complexity.
信号计算。 Signal computation. 对于 $m$ 个区域中的每一个，计算 $d$ 维信号需要 $O(d)$ 次操作（读取局部内容、计算质量指标）。 For each of $m$ regions, computing $d$ -dimensional signals requires $O(d)$ operations (reading local content, computing quality metrics). 总计：$O(m\cdot d)$。 Total: $O(m\cdot d)$ .
压力计算。 Pressure computation. 对于每个区域，根据 $k$ 个信号轴计算压力需要 $O(k)$ 次操作（加权求和）。 For each region, computing pressure from $k$ signal axes requires $O(k)$ operations (weighted sum). 总计：$O(m\cdot k)$。 Total: $O(m\cdot k)$ .
补丁提议。 Patch proposal. $a$ 个执行者中的每一个都为已激活的区域提出补丁。 Each of $a$ actors proposes patches for activated regions. 在最坏情况下（所有区域均被激活），提议数量为 $O(m\cdot a)$。 In the worst case (all regions activated), this is $O(m\cdot a)$ proposals. 每项提议都涉及一次大语言模型调用，该调用占据了实际运行时间的主要部分，但每次调用的耗时为常数。 Each proposal involves an Large Language Model call, which dominates wall-clock time but is constant per call.

11.4 定理 5.5 的证明（并行收敛）11.4 Proof of Theorem 5.5 (Parallel Convergence)
证明。Proof.
我们将定理 5.1 扩展到并行情形。 We extend Theorem 5.1 to the parallel setting.
设定。 Setup. 假设每个时钟步并行验证 $K$ 个补丁，它们分别针对互不相交的区域 $i_{1},\ldots,i_{K}$。 Suppose $K$ patches are validated in parallel per tick, targeting disjoint regions $i_{1},\ldots,i_{K}$ .

| | $\Delta P_{k}\leq-\delta_{\min}+(n-1)\epsilon$ |

| | $P^{t+1}-P^{t}\leq\sum_{k=1}^{K}\Delta P_{k}\leq K\cdot(-\delta_{\min}+(n-1)\epsilon)$ |

| | $T\leq\frac{P_{0}}{K\cdot(\delta_{\min}-(n-1)\epsilon)}$ |
