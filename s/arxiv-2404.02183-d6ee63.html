摘要Abstract
近年来，利用大语言模型（LLM）智能体进行自动代码生成的进展，使我们向软件自动化开发的未来又迈近了一步。 Recent advancements in automatic code generation using large language model (LLM) agent have brought us closer to the future of automated software development. 然而，由于上下文长度的限制，现有单智能体方法在生成和改进大规模复杂代码库方面面临局限。 However, existing single-agent approaches face limitations in generating and improving large-scale, complex codebases due to constraints in context length. 为应对这一挑战，我们提出了自组织多智能体框架（Self-Organized multi-Agent framework，SoA），这是一种新型多智能体框架，能够以可扩展且高效的方式生成和优化大规模代码。 To tackle this challenge, we propose Self-Organized multi-Agent framework (SoA), a novel multi-agent framework that enables the scalable and efficient generation and optimization of large-scale code. 在 SoA 中，自组织智能体独立运行，生成和修改代码组件，同时通过无缝协作构建整个代码库。 In SoA, self-organized agents operate independently to generate and modify code components while seamlessly collaborating to construct the overall codebase. 我们框架的一项关键特性是根据问题复杂度自动增加智能体数量，从而实现动态扩展。 A key feature of our framework is the automatic multiplication of agents based on problem complexity, allowing for dynamic scalability. 这使得总代码量能够随智能体数量的增加而无限增长，同时每个智能体管理的代码量保持恒定。 This enables the overall code volume to be increased indefinitely according to the number of agents, while the amount of code managed by each agent remains constant. 我们在 HumanEval 基准上评估了 SoA，结果表明，与单智能体系统相比，SoA 中每个智能体处理的代码量显著减少，而整体生成的代码量却大幅增加。 We evaluate SoA on the HumanEval benchmark and demonstrate that, compared to a single-agent system, each agent in SoA handles significantly less code, yet the overall generated code is substantially greater. 此外，SoA 的 Pass@1 准确率比强大的单智能体基线高出 5%。 Moreover, SoA surpasses the powerful single-agent baseline by 5% in terms of Pass@1 accuracy. 11 1 我们的代码将在 https://github.com/tsukushiAI/self-organized-agent 上公开。 11 1 Our code will be available at https://github.com/tsukushiAI/self-organized-agent.

§​ 3 自组织智能体框架§​ 3 Self-organized Agent Framework
我们的自组织智能体（Self-organized Agents，SoA）框架通过让自组织智能体独立生成和修改小规模、简单的代码，实现了大规模复杂代码的高效开发。 Our Self-organized Agents (SoA) framework enables efficient implementation of large-scale and complex code by having self-organized agents independently generate and modify small-scale and simple code. 本节介绍 SoA 的重要组成部分，即智能体以及负责比智能体更抽象的处理工作的层，最后介绍 SoA 框架中的代码生成与修改协议。 In this section, we introduce the important components of SoA, namely the agents and the layers responsible for more abstract processing than the agents, and finally introduce the code generation and modification protocols in the SoA framework.
§​ 3.1 子智能体§​ 3.1 Child Agent
子智能体根据给定函数的文档字符串实现该函数。 Child agents implement a given function based on its docstrings. 如图 2 所示，该智能体结构简单，由两个要素组成：一个大语言模型（LLM）和记忆。 As shown in Figure 2, this agent has a simple structure consisting of two elements: an LLM and memory. LLM 根据给定的文档字符串生成代码，并根据单元测试结果修改代码。 The LLM generates code from the given docstrings and modifies the code based on the results of unit tests. 记忆存储智能体自身生成的代码，并在修改代码时检索最新代码，将其与单元测试反馈一同输入 LLM。 The memory stores the code generated by the agent itself and retrieves the latest code to be input to the LLM along with the unit test feedback during code modification. 只要智能体满足这些最低要求，就可以将现成的智能体（例如 Reflexion）用作子智能体。 If an agent has these minimal specifications, it is possible to use an off-the-shelf agents (e.g., Reflexion) as a Child agent. 我们特意使用简单的智能体，以便在简单的配置下验证 SoA 的有效性。 We deliberately use a simple agent to verify the effectiveness of SoA in a simple setup.

代码修改：赋予子智能体自组织能力与适应能力Code Modification: Empowering Child Agents with Self-Organization and Adaptability
SoA 框架中智能体最显著的特点之一，是能够根据邻近智能体的状态自主改进自身代码。 One of the most remarkable aspects of agents in the SoA framework is their ability to autonomously improve their code based on the state of nearby agents . 这一过程使 SoA 区别于传统的智能体方法，并展示了自组织在代码修改中的作用。 This process sets SoA apart from traditional agent approaches and showcases the power of self-organization in code modification. Reflexion Shinn et al. (2023) 等现有智能体仅依赖单元测试结果，而 SoA 中的子智能体通过独立观察其母智能体的状态，例如修改差异和反馈，突破了这一局限。 While existing agents like Reflexion Shinn et al. (2023) rely solely on the results of unit tests, Child agents in SoA go beyond this limitation by independently observing the state of their mother agent, such as differences in modifications and feedback. 通过从周围环境中收集这些宝贵信息，即使没有明确指令，子智能体也能调整自身行为，并在代码修改方面做出依据更充分的决策。 By gathering this invaluable information from their surrounding environment, Child agents can adapt their behavior and make more informed decisions about code modification, even without explicit instructions. 母智能体产生的修改和反馈是子智能体的重要信息来源。 The modifications and feedback generated by the Mother agent serve as an important source of information for the Child agents. 借助这些认识，子智能体（Child agents）能够更有效地修改自身代码，以高效且具有适应性的方式促进整个代码库的改进。 Armed with these insights, Child agents can more effectively modify their own code, contributing to the overall improvement of the codebase in a way that is both efficient and adaptive. 图 3 展示了这一过程，该过程首先执行单元测试，并从记忆中检索最新实现。 Figure 3 illustrates this process, which begins with the execution of unit tests and the retrieval of the latest implementation from memory. 随后，子智能体利用 LLM 生成代码修改方案，将从母智能体（Mother agent）观察到的信息与测试结果及最新实现细节无缝结合。 The Child agent then harnesses the power of the LLM to create a code modification proposal, seamlessly combining the information observed from the Mother agent with the test results and the latest implementation details. 通过将修改后的代码存入记忆，子智能体建立了一个反馈循环，随着时间的推移持续完善和改进代码库。 By storing the modified code in memory, Child agents create a feedback loop that continuously refines and improves the codebase over time. 这一由自组织和适应性原则驱动的迭代过程，使 SoA 能够高效且有效地处理复杂的代码修改任务。 This iterative process, driven by the principles of self-organization and adaptability, enables SoA to tackle complex code modification tasks with efficiency and effectiveness. 子智能体与其母智能体协同工作，共同构建规模更大、优化程度更高的代码库。 As Child agents work in harmony with their Mother agent, they contribute to the creation of a more optimized and large codebase.
§​ 3.2 母智能体§​ 3.2 Mother Agent
母智能体是一种能够生成新智能体（母智能体或子智能体）的智能体。 The Mother is an agent that generates new agents (Mother or Child). 与子智能体类似，母智能体根据给定的文档字符串独立实现特定的 Python 函数。 Similar to Child agents, the Mother agent independently implements the specific Python function based on its given docstrings. 母智能体与子智能体一样，具有记忆、代码生成能力和自调试功能。 The Mother has memory, code generation capabilities, and self-debugging functions, as same as Child agents. 母智能体的独特之处在于，它能够根据问题的复杂程度生成多个子智能体，并将部分实现工作委派给这些智能体。 The unique feature of the Mother agent is its ability to generate multiple Child agents according to the complexity of the problem and delegate parts of the implementation to these agents. 这种结构使母智能体能够专注于实现抽象过程，而由其生成的子智能体则专注于实现具体过程。 This structure allows the Mother agent to focus on implementing abstract processes, while the Child agents generated by the Mother agent concentrate on implementing concrete processes. 这种分工提高了 SoA 框架的整体效率和灵活性。 This division of labor enhances the overall efficiency and flexibility of the SoA framework.
图 3：代码修改概览。 Figure 3: Overview of code modification. 智能体（母智能体/子智能体）观察母智能体的状态（反馈、旧代码和更新后的代码），并利用这些信息改进各自负责的函数。 Agents (Mother/Child) observe the state of Mother (feedback, old code, and updated code) and use this information to improve the functions for which they are responsible. 层级结构中的下层智能体利用上层智能体的状态修改代码。 The state of the upper agent is used to modify code by lower agents within the hierarchy. 这种状态传播促进了整个层级结构中的协作与信息共享，从而实现高效的代码修改。 This state propagation promotes collaboration and information sharing throughout the hierarchy, enabling efficient code modification.

我们以图 2 所示的 is_sum_of_odds_ten 函数实现为例，说明母智能体的代码生成过程。 We explain the code generation process by the Mother agent using the implementation example of the is_sum_of_odds_ten function shown in Figure 2. 该过程以函数的文档字符串和单元测试为起点，并将其存入记忆，供后续自调试阶段参考。 The starting point is the function’s docstrings and unit tests, which are memorized for reference in the later self-debugging phase. 母智能体的首要任务是根据给定的文档字符串生成实现骨架，其中包括用于提取奇数的 get_odd_numbers 和用于计算这些奇数之和的 sum_of_numbers 等子函数。 The first task of the Mother agent is to generate a skeleton of the implementation from the given docstrings, including subfunctions such as get_odd_numbers to extract odd numbers and sum_of_numbers to calculate their sum. 这些子函数的数量和类型由 LLM 根据问题的复杂程度自动确定。 The number and types of these subfunctions are automatically determined by the LLM based on the complexity of the problem.
需要注意的是，这些子函数尚未实现，母智能体也不会直接实现它们。 It is important to note that these subfunctions are unimplemented, and the Mother agent does not directly implement them. 它将子函数的实现工作委派给其他智能体，从而能够专注于生成骨架，并简化自身的代码生成过程。 Instead, it delegates the implementation of the subfunctions to other agents, allowing the Mother agent to focus on generating the skeleton and streamline its own code generation process. 在生成子函数的文档字符串和单元测试后，这些子函数会被分配给新初始化的智能体来实现。 After the docstrings and unit tests for the subfunctions are generated, they are assigned to newly initialized agents for implementation. 这些智能体各自实现所负责的函数，而不查看母智能体所实现的 is_sum_of_odds_ten 函数的内部细节。 These agents proceed with the implementation of their respective functions without looking at the internals of the is_sum_of_odds_ten function implemented by the Mother agent. 由于同一母智能体下的各个智能体可以异步工作，整个代码生成过程得以简化。 Since agents within the same Mother can work asynchronously, the overall code generation process is streamlined.

母智能体的代码修改过程与子智能体的代码修改过程几乎相同（图 3）。 The Mother’s code modification is almost the same as the Child’s code modification (Figure 3). 它观察来自上层母智能体的信息，并利用这些信息修改自己负责的函数。 It observes information from the upper Mother and uses it to modify the functions it is responsible for. 唯一的区别在于，它生成的反馈以及修改前后的代码会被下层智能体（子智能体或母智能体）使用。 The only difference is that the feedback it generates and the code before and after modification are used by lower-level agents (Child or Mother).
§​ 3.3 自组织智能体流程§​ 3.3 Self-organized Agent Process
自组织智能体（Self-organized Agent，SoA）框架是一种分布式框架，其中多个智能体（包括母智能体和子智能体）反复生成和修改函数。 The Self-organized Agent (SoA) framework is a distributed framework in which multiple agents (including Mother agents and Child agents) repeatedly generate and modify functions. 该框架的核心在于自组织原则，即每个智能体独立运作，无需直接观察整个代码库。 The core of this framework lies in the principle of self-organization, where each agent functions independently without the need to directly observe the entire codebase. 母智能体与子智能体按层级组合，形成一个智能体网络，有效地构建单一的大规模代码库。 The hierarchical combination of Mother agents and Child agents forms an agent network that effectively constructs a single large-scale codebase. 在这种层级结构中，母智能体通过划分任务并将其委派给自己生成的智能体，将复杂问题分解为更易处理的小问题。 In this hierarchical structure, Mother agents decompose complex problems into more manageable smaller problems by dividing tasks and delegating them to the agents they have generated. 尽管每个智能体都是独立的，但所有智能体作为一个整体，能够高效协作以实现同一个函数。 Although each agent is independent, the agents as a whole can work efficiently towards the implementation of a single function. 尽管每个智能体生成、修改和管理的代码量始终很小，但智能体的数量可以扩展，从而能够根据问题的难度无限增加生成的代码量。 Despite the fact that the amount of code each agent generates, modifies, and manages is always small, the number of agents scales, allowing the amount of code generated to be increased indefinitely according to the difficulty of the problem. 详细算法见附录中的算法 1。 Detailed algorithms are presented in Algorithm 1 in the appendix.
图 4：SoA 框架概览。 Figure 4: Overview of the SoA framework. 母智能体（Mother agents）和子智能体（Child agents）以层级方式构建网络，并执行函数生成与修改。 Mother agents and Child agents hierarchically construct a network and perform function generation and modification. 母智能体将任务委派给其他母智能体或子智能体，各智能体独立执行任务，同时作为一个整体有效地实现单个函数。 Mother agents delegate tasks to other Mother agents or Child agents, and each agent independently executes tasks while effectively implementing a single function as a whole.
代码生成Code Generation
SoA 框架中的代码生成过程始于函数的文档字符串（docstrings）和单元测试。 The code generation process in the SoA framework begins with the function’s docstrings and unit tests. 在初始阶段，只有一个已初始化的母智能体，它是树结构的根节点。 In the initial stage, there is only one initialized Mother agent, which is the root of the tree structure. 它根据输入的文档字符串和单元测试，为子任务生成文档字符串和单元测试，并将其传递给它所创建的其他智能体（见 §​ 3.2）。 Based on the input docstrings and unit tests, it generates docstrings and unit tests for subtasks and passes them to other agents it generates (see §​ 3.2). 如果树结构达到预设深度，则将任务传递给子智能体；否则，将任务传递给新创建的母智能体。 If the tree structure reaches a predetermined depth, the tasks are passed to Child agents; otherwise, they are passed to newly generated Mother agents. 通过反复增殖、增加智能体数量，直至创建最后一个智能体，就可以在保持单个智能体所管理的代码量不变的同时生成大规模代码。 By repeatedly proliferating and increasing the number of agents until the last agent, it is possible to generate large-scale code while keeping the amount of code managed by individual agents constant.
代码修改Code Modification
代码生成完成后，流程转入代码修改阶段。 Once code generation is complete, the process transitions to the code modification phase. 首先，将所有智能体的实现合并，形成最终实现。 First, the implementations of all agents are combined to create the final implementation. 使用提供给根母智能体的单元测试评估这一最终实现，并根据结果生成反馈。 This final implementation is evaluated using the unit tests provided to the root Mother, and feedback is generated from the results. 由于不存在比该根母智能体层级更高的智能体，因此不使用图 3 所示的来自更高层级智能体的信息。 Since there are no agents higher than this root Mother, information from higher-level agents as shown in Figure 3 is not used. 修改过程基于这些反馈启动，并将信息从根母智能体传播至子智能体。 The modification process starts based on this feedback and propagates information from the root Mother agent to the Child agents. 每个智能体根据收到的反馈更新其实现，生成新的反馈，并将其传递给下级智能体（见 §​ 3.2）。 Each agent updates its implementation based on the received feedback, generates new feedback, and transmits it to lower-level agents (see §​ 3.2). 最后，子智能体更新各自的实现，流程随之终止（见 §​ 3.1）。 Finally, the Child agents update their own implementations, and the process terminates (see §​ 3.1). 上述一系列过程会重复执行，直至达到预设的最大迭代次数。 This series of processes is repeated until a predetermined maximum number of iterations is reached.

§​ 6 结论§​ 6 Conclusion
在本研究中，我们提出了 Self-organized Agents (SoA)，这是一种利用大语言模型（LLMs）实现高效、可扩展的自动代码生成与优化的新型多智能体框架。 In this work, we introduced Self-organized Agents (SoA), a novel multi-agent framework for efficient and scalable automatic code generation and optimization using large language models (LLMs). SoA 利用自组织和分布式代码生成的能力，克服了单智能体方法在处理大规模复杂代码库时的局限。 SoA addresses the limitations of single-agent approaches in handling large-scale, complex codebases by leveraging the power of self-organization and distributed code generation. 在 SoA 中，自组织智能体独立运行，生成和修改代码组件，同时通过无缝协作构建整个代码库。 In SoA, self-organized agents operate independently to generate and modify code components while seamlessly collaborating to construct the overall codebase. 我们框架的一个关键特性是根据问题复杂度自动增殖智能体，从而实现动态扩展，使总体代码量能够随智能体数量的增加而无限增长，同时每个智能体管理的代码量保持不变。 A key feature of our framework is the automatic multiplication of agents based on problem complexity, allowing for dynamic scalability and enabling the overall code volume to be increased indefinitely according to the number of agents, while the amount of code managed by each agent remains constant.
我们在 HumanEval 基准上评估了 SoA，结果表明，其性能优于先进的单智能体系统 Reflexion，SoA 的 Pass@1 准确率提升了 5%。 We evaluated SoA on the HumanEval benchmark and demonstrated its superior performance compared to Reflexion, a state-of-the-art single-agent system, with SoA achieving a 5% improvement in terms of Pass@1 accuracy. 此外，我们的深入分析揭示了 SoA 出色的可扩展性：与单智能体基线相比，SoA 中每个智能体处理的代码量显著更少，但生成的总体代码量却大幅增加。 Furthermore, our in-depth analysis revealed SoA’s remarkable scalability, as each agent in SoA handles significantly less code compared to the single-agent baseline, yet the overall generated code is substantially greater. 这些结果凸显了 SoA 在高效、高质量地生成和优化大规模代码方面的有效性。 These results highlight the effectiveness of SoA in generating and optimizing large-scale code efficiently and with high quality.
然而，必须承认当前 SoA 实现的局限性。 However, it is essential to acknowledge the limitations of the current implementation of SoA. 该框架的性能可能受到 LLM 的选择以及所生成单元测试质量的影响。 The framework’s performance may be affected by the choice of LLM and the quality of the generated unit tests. 此外，SoA 仅在有限的一组编程任务上进行了评估，其在处理更复杂的现实软件开发项目时的有效性仍有待研究。 Additionally, SoA has been evaluated on a limited set of programming tasks, and its effectiveness in handling more complex, real-world software development projects remains to be investigated. 此外，SoA 中智能体之间的通信与协作机制还可以进一步优化，以提高效率和容错能力。 Furthermore, the communication and collaboration mechanisms among agents in SoA can be further optimized to improve efficiency and fault tolerance.
尽管存在这些局限，我们仍认为 SoA 框架在自动化软件开发领域未来的研究与发展中具有巨大潜力。 Despite these limitations, we believe that the SoA framework has significant potential for future research and development in the field of automatic software development.
