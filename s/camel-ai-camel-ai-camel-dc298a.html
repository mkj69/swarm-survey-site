CAMEL 框架设计原则CAMEL Framework Design Principles
🧬 可演化性 🧬 Evolvability
该框架使多智能体系统能够通过生成数据和与环境交互而持续演化。 The framework enables multi-agent systems to continuously evolve by generating data and interacting with environments. 这种演化可由具有可验证奖励的强化学习或监督学习驱动。 This evolution can be driven by reinforcement learning with verifiable rewards or supervised learning.
📈 可扩展性 📈 Scalability
该框架旨在支持包含数百万个智能体的系统，确保大规模系统中的高效协调、通信和资源管理。 The framework is designed to support systems with millions of agents, ensuring efficient coordination, communication, and resource management at scale.
💾 状态保持性 💾 Statefulness
智能体保留具有状态的记忆，使其能够与环境进行多步骤交互，并高效处理复杂任务。 Agents maintain stateful memory, enabling them to perform multi-step interactions with environments and efficiently tackle sophisticated tasks.
📖 代码即提示（Code-as-Prompt） 📖 Code-as-Prompt
每一行代码和注释都充当智能体的提示。 Every line of code and comment serves as a prompt for agents. 代码应编写得清晰易读，确保人类和智能体都能有效理解。 Code should be written clearly and readably, ensuring both humans and agents can interpret it effectively.

大规模智能体系统 Large-Scale Agent System
模拟多达 1M 个智能体，以研究复杂多智能体环境中的涌现行为和尺度定律。 Simulate up to 1M agents to study emergent behaviors and scaling laws in complex, multi-agent environments.
✅ ✅
动态通信 Dynamic Communication
支持智能体之间的实时交互，促进无缝协作，以处理复杂任务。 Enable real-time interactions among agents, fostering seamless collaboration for tackling intricate tasks.
✅ ✅
有状态记忆 Stateful Memory
赋予智能体保留和利用历史上下文的能力，从而改善长期交互过程中的决策。 Equip agents with the ability to retain and leverage historical context, improving decision-making over extended interactions.
✅ ✅
支持多种基准测试 Support for Multiple Benchmarks
利用标准化基准测试严格评估智能体性能，确保可复现性和比较结果的可靠性。 Utilize standardized benchmarks to rigorously evaluate agent performance, ensuring reproducibility and reliable comparisons.
✅ ✅
支持不同类型的智能体 Support for Different Agent Types
适用于多种智能体角色、任务、模型和环境，支持跨学科实验和多样化的研究应用。 Work with a variety of agent roles, tasks, models, and environments, supporting interdisciplinary experiments and diverse research applications.
✅ ✅
数据生成与工具集成 Data Generation and Tool Integration
自动创建大规模结构化数据集，同时无缝集成多种工具，简化合成数据生成和研究工作流程。 Automate the creation of large-scale, structured datasets while seamlessly integrating with multiple tools, streamlining synthetic data generation and research workflows.

从 ChatAgent 入手Starting with ChatAgent
本示例演示如何使用 CAMEL 框架创建一个 `ChatAgent`，并使用 DuckDuckGo 执行搜索查询。 This example demonstrates how to create a `ChatAgent` using the CAMEL framework and perform a search query using DuckDuckGo.
**安装工具包：** **Install the tools package:** 
  pip install 'camel-ai[web_tools]'
**设置你的 OpenAI API 密钥：** **Set up your OpenAI API key:** 
  export OPENAI_API_KEY='your_openai_api_key'
也可以使用 `.env` 文件： Alternatively, use a `.env` file: 
   cp .env.example .env
   # then edit .env and add your keys
**运行以下 Python 代码：** **Run the following Python code:** 
  from camel.models import ModelFactory
  from camel.types import ModelPlatformType, ModelType
  from camel.agents import ChatAgent
  from camel.toolkits import SearchToolkit

  model = ModelFactory.create(
    model_platform=ModelPlatformType.OPENAI,
    model_type=ModelType.GPT_4O,
    model_config_dict={"temperature": 0.0},
  )

  search_tool = SearchToolkit().search_duckduckgo

  agent = ChatAgent(model=model, tools=[search_tool])

  response_1 = agent.step("What is CAMEL-AI?")
  print(response_1.msgs[0].content)
  # CAMEL-AI is the first LLM (Large Language Model) multi-agent framework
  # and an open-source community focused on finding the scaling laws of agents.
  # ...

  response_2 = agent.step("What is the Github link to CAMEL framework?")
  print(response_2.msgs[0].content)
  # The GitHub link to the CAMEL framework is
  # [https://github.com/camel-ai/camel](https://github.com/camel-ai/camel).
