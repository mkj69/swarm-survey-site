一句话

这份定价页提供了比较包月订阅与 API 成本的厂商口径，但订阅额度无法直接换算成 swarm 的并发能力或任务吞吐。

主要内容

  • 个人订阅有共享配额。 Pro 月付 20 美元，年付一次收取 200 美元，页面标示折合每月约 17 美元；Max 每月 100 美元，五小时及每周额度均为 Pro 的 5 倍；Ultra 每月 200 美元，每周额度为 Pro 的 10 倍，已验证账户无五小时限制，但仍有周限额。
  • 订阅与 API 额度开始组合。 Max、Ultra 分别附带每月 100、200 美元 API 额度；Team 提供最高每月 500 美元的共享 API 额度。网页、桌面、移动端与 Claude Code 共用订阅额度，付费用户超额后可启用按标准 API 费率计费的用量额度。
  • 组织方案包含固定与变量成本。 Team 标准席位月付 25 美元，高级席位月付 125 美元；Enterprise 每席每月 20 美元、年付、至少 20 席，另按 API 费率收取使用费。
  • API 按模型和工作负载定价。 每百万输入／输出 token，Sonnet 5.5 为 2／10 美元，Opus 5.5 为 4／20 美元，Fable 5.1 为 10／50 美元。页面称批处理可节省 50%，并另列缓存价格。
  • 运行与工具另有费用。 Managed Agents 活跃运行时间每会话小时 0.08 美元，另计 token；网页搜索每千次 10 美元；代码执行每组织每天免费 50 小时，超出后每容器小时 0.05 美元。

证据与可信度

以上数字均直接取自所给 Anthropic 定价页抓取内容，属于厂商公布的报价与额度规则，不是性能测量，也没有独立核验。日期来自材料元数据，不能据此确认每项价格的生效时间；页面注明未含税且可调整。

“5 倍”“10 倍”描述相对使用额度，页面未提供固定 token 总量或消息数。实际消耗受模型、对话长度和文件大小影响，厂商还保留追加限制的权利。附带 API 额度的具体条件未在所给内容中完整展开，不宜直接等同现金返还。

对 swarm scaling 的意义

这份材料适合建立成本预算，不足以证明扩展收益。包月方案能否承载更多 agent，仍取决于共享额度的消耗速度；取消五小时限制也不意味着无限使用。

API 成本模型应同时计入输入、输出、缓存、工具调用和活跃运行时间。批处理与缓存提供了降低部分费用的途径，但材料没有给出并发上限、延迟、成功率或多 agent 相对单 agent 的效果，因此不能据此计算最优 swarm 规模或可靠的订阅回本点。
