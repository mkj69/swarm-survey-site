一句话

Mazur 的个人体验表明，工作区管理界面能降低并行使用编码代理的门槛，但尚不能证明规模化提效。

主要内容

  • 用 Conductor 自动创建基于 git worktree 的独立工作区，配合语音描述任务。
  • 代理先规划，人审核后实施，再测试、建 PR、合并；人穿插处理其他任务。
  • 常开 4—8 个工作区，但部分在等待人工推进，并非同等数量代理持续并行。
  • 自述迄今没有合并冲突，认知负担也没有预想中严重。

证据与可信度

4—8 个来自作者对日常工作流的自报；无冲突、疲劳可控均属个人经验。此前征询收到百余人回复，但没有系统统计。材料未提供吞吐量、质量、成本或对照测量，也无独立核验。

对 swarm scaling 的意义

案例支持通过任务隔离和分阶段审核组织并行工作。扩展对象更接近人管理的任务队列，而非自主协作的 swarm；工作区数不能直接当作并发度或效率增益。
