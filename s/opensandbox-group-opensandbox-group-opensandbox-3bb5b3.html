OpenSandbox OpenSandbox
智能体 AI 基金会（AAIF）的一个项目 An Agentic AI Foundation (AAIF) Project
**在您自己的基础设施上，通过沙箱运行 AI 智能体。** **Run AI agents in sandboxes on your own infrastructure.**
OpenSandbox 为 AI 应用提供隔离环境，用于执行代码、运行命令、管理文件以及操作浏览器或桌面。 OpenSandbox gives AI applications isolated environments to execute code, run commands, manage files, and operate browsers or desktops. 使用 Docker 在本地启动，并通过统一的沙箱 API 部署到 Kubernetes 上。 Start locally with Docker and deploy on Kubernetes through a unified sandbox API.

基于 `alpine` 镜像创建沙箱，并执行命令和脚本。 Create a sandbox from an `alpine` image and execute commands and scripts. 
import asyncio

from opensandbox import Sandbox
from opensandbox.models import WriteEntry

async def main() -> None:
    # 1. Create a sandbox from the alpine image
    sandbox = await Sandbox.create("alpine")

    try:
        # 2. Execute a shell command
        execution = await sandbox.commands.run("echo 'Hello OpenSandbox!'")
        print(execution.logs.stdout[0].text)

        # 3. Write a script file
        await sandbox.files.write_files([
            WriteEntry(
                path="/tmp/hello.sh",
                data="echo \"Hello $1\"\necho '2 + 2 =' $((2 + 2))",
                mode=755,
            )
        ])

        # 4. Read the file back
        content = await sandbox.files.read_file("/tmp/hello.sh")
        print(f"Content: {content}")

        # 5. Execute the script
        execution = await sandbox.commands.run("sh /tmp/hello.sh OpenSandbox")
        for log in execution.logs.stdout:
            print(log.text)

    finally:
        # 6. Cleanup the sandbox
        await sandbox.destroy()

if __name__ == "__main__":
    asyncio.run(main())

命令行界面（CLI）CLI
OpenSandbox 还提供 `osb`，这是一个用于常见沙箱工作流程的终端命令行工具：创建沙箱、运行命令、传输文件、查看诊断信息以及管理运行时出站访问策略。 OpenSandbox also provides `osb`, a terminal CLI for the common sandbox workflow: create sandboxes, run commands, move files, inspect diagnostics, and manage runtime egress policy.
安装： Install: 
pip install opensandbox-cli
# or
uv tool install opensandbox-cli
快速入门： Quick start: 
osb config init
osb config set connection.domain localhost:8080
osb config set connection.protocol http
osb config set connection.api_key <your-api-key>
osb sandbox create --image python:3.12 --timeout 30m -o json
osb command run <sandbox-id> -o raw -- python -c "print(1 + 1)"
完整的命令参考请参阅 [CLI README](cli/README.md)。 See the [CLI README](cli/README.md) for the full command reference.
MCPMCP
OpenSandbox MCP 服务器向 Claude Code 和 Cursor 等支持 MCP 的客户端提供沙箱创建、命令执行和文本文件操作功能。 The OpenSandbox MCP server exposes sandbox creation, command execution, and text file operations to MCP-capable clients such as Claude Code and Cursor.
安装并运行： Install and run: 
pip install opensandbox-mcp
opensandbox-mcp --domain localhost:8080 --protocol http
最简 stdio 配置： Minimal stdio config: 
{
  "mcpServers": {
    "opensandbox": {
      "command": "opensandbox-mcp",
      "args": ["--domain", "localhost:8080", "--protocol", "http"]
    }
  }
}
针对各客户端的配置方法，请参阅 [MCP README](sdks/mcp/sandbox/python/README.md)。 See the [MCP README](sdks/mcp/sandbox/python/README.md) for client-specific setup.

使用摘要（digest）固定生产环境镜像，并在部署前查阅[发布验证指南](docs/community/release-verification.md)，确认签名覆盖范围。 Pin production images by digest and check the [release verification guide](docs/community/release-verification.md) for signing coverage before deployment. 旧版按组件发布的版本支持 Cosign 签名和来源证明（provenance attestations）；当前的统一发布版本存在[已跟踪的签名和来源证明缺失问题](https://github.com/opensandbox-group/OpenSandbox/issues/2463)，不得假定其提供同等的验证证据。 Legacy per-component releases support Cosign signatures and provenance attestations; current umbrella releases have a [tracked signing and provenance gap](https://github.com/opensandbox-group/OpenSandbox/issues/2463) and must not be assumed to provide the same verification evidence.
