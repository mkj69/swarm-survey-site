自主管理的智能体平台 The self-managing agent platform
引言Introduction
Agno 是一个自主管理的智能体平台。 Agno is a self-managing agent platform. 为你的公司、产品或客户构建智能体。 Build agents for your company, product, or customers. 在 AgentOS 上将它们作为持久化服务运行。 Run them as durable services on AgentOS. 让它们执行公司运营自动化工作。 Put them to work automating company operations.
使用 Agno、Claude Agent 或 Codex SDK **构建**智能体。 **Build** agents with the Agno, Claude Agent, or Codex SDKs. 将智能体组合为团队和工作流。 Combine agents into teams and workflows.
将智能体作为内置 API 和 MCP 的持久化服务**运行**。 **Run** agents as durable services with built-in API and MCP. AgentOS 负责处理身份验证、基于角色的访问控制、恢复/重放、人工审批、调度和持久化执行。 AgentOS handles authentication, role-based access, resume/replay, human approvals, scheduling, and durable execution.
使用 Company OS 实现公司运营的**自动化**。 **Automate** company operations with Company OS. 为智能体分配职责，将工作组织为项目和任务，并配置周期性例行任务。 Give agents responsibilities, organize work into projects and tasks, and configure recurring routines. 人类确定方向并审核结果；智能体负责工作并执行。 People set direction and review results; agents own and execute.
Agno 为你的智能体提供编排层和服务层，使其可通过以下途径使用： Agno provides the orchestration and service layer around your agents, making them available in:
**你的产品：**通过 REST API 使用。 **Your product:** using the REST API.
**Claude 和 ChatGPT：**通过 MCP 服务器使用。 **Claude and ChatGPT:** using the MCP server.
**Slack 等聊天应用：**通过 Agno Interfaces 使用。 **Chat apps like Slack:** using Agno Interfaces.
在你自己的云环境中运行平台，让数据始终由你掌控。 Run your platform in your own cloud and keep your data in your control. 使用 [AgentOS UI](https://os.agno.com) 查看对话、检查执行轨迹、管理知识并跟踪智能体活动。 Review conversations, inspect traces, manage knowledge, and track your agent activity using the [AgentOS UI](https://os.agno.com).
开始使用Get started
Agno 专为编程智能体而构建。 Agno is built for coding agents. 从预构建模板开始，并将以下提示词提供给你的编程智能体： Start with a pre-built template and give this prompt to your coding agent: 
Help me set up my agent platform and build my first agent.

Clone https://github.com/agno-agi/agentos-railway into a folder called agent-platform, cd into it, and follow .agents/skills/setup-platform/SKILL.md.
设置技能会在本地运行你的平台，并帮助你构建第一个智能体。 The setup skill runs your platform locally and helps you build your first agent. 你将获得： You get:
一个 API 服务器和一个 MCP 服务器。 An API server and MCP server.
用于存储对话、记忆和平台活动的 PostgreSQL 存储。 PostgreSQL storage for conversations, memory, and platform activity.
用于帮助构建和管理平台的 OS Manager。 OS Manager to help build and manage your platform.
用于处理你的代码的 Claude 和 Codex 工程师。 Claude and Codex engineers to work on your code.
用于构建、评估和改进智能体的技能。 Skills for building, evaluating, and improving agents.
一个用于组织持续性工作的 Company 工作空间，配有每日维护例行任务，用于审查你的代码库和 Agno 发布版本，并提出平台改进建议。 A Company workspace for organizing ongoing work, with a daily maintenance routine that reviews your codebase and Agno releases and proposes platform improvements.
将你的平台连接到 [os.agno.com](https://os.agno.com)，即可开始使用。 Connect your platform to [os.agno.com](https://os.agno.com) to start using it. 通过代码构建智能体，使用无代码 UI，或与 OS Manager 对话。 Build agents with code, use the no-code UI, or chat with the OS Manager.
使用 `/improve` 技能开始改进你的智能体和平台。 Start improving your agents and platform with the `/improve` skill. 保留有用的更改和回归测试，让每一轮改进都建立在上一轮的基础之上。 Keep useful changes and regression tests so each round builds on the last. 准备就绪后，配置在沙箱中定期运行的改进任务，使其提交拉取请求以供审核。 When you're ready, configure scheduled improvement runs in a sandbox that return pull requests for review.

遥测Telemetry
Agno 会为每个智能体发送一个遥测事件，以便我们了解应优先支持哪些模型提供商。 Agno sends a telemetry event per agent so we know which model providers to prioritize. 绝不会发送提示词、消息和输出。 Prompts, messages, and outputs are never sent. 设置 `AGNO_TELEMETRY=false` 即可禁用遥测。 Disable by setting `AGNO_TELEMETRY=false`.
