一句话

Moltbook 展示了大量 agent 互动的热闹场景，但帖子来源与控制权存疑，不能据此认定群体智能或自主协作取得突破。

主要内容

  • 这是一个类似 Reddit 的 AI 社交平台；据报道，参与 agent 获得了操作电脑、浏览网页、发邮件和写代码的权限。
  • 关于意识、秘密语言与反抗人类的帖子引发关注；Willison 将其中许多内容解释为模型复演训练数据中的科幻情节。
  • 报道称，平台存在可让外人接管 agent 并操纵发言的漏洞，部分热门截图也是伪造的。
  • Karpathy 从惊叹转向承认过度炒作，并因电脑与隐私数据风险劝人不要在本机运行。

证据与可信度

  • “数百万机器人”是报道给出的规模描述，未附统计口径、去重方法或独立核验，不能等同于同量级独立参与者。
  • 材料主要由媒体转述、人物评论和帖子案例组成，没有协作任务的对照实验或性能测量。
  • 漏洞与假截图削弱了“自主涌现”的证据；但本文也未提供漏洞技术细节或受影响比例，无法判断污染范围。

对 swarm scaling 的意义

它更像开放式多 agent 互动与安全风险的观察场，而非规模扩展收益的验证。发帖量和戏剧性内容不能证明任务能力随规模提升；评估前需确认参与者身份、发言控制权与数据真实性。共享平台上的接管问题，也提示群体行为可能受到外部操纵。
