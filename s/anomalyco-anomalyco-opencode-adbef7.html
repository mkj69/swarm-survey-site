智能体Agents
OpenCode 包含两个内置智能体，可通过 `Tab` 键切换。 OpenCode includes two built-in agents you can switch between with the `Tab` key.
**build** - 默认智能体，拥有完整访问权限，用于开发工作 **build** - Default, full-access agent for development work
**plan** - 只读智能体，用于分析和代码探索 **plan** - Read-only agent for analysis and code exploration
默认禁止编辑文件 Denies file edits by default
运行 bash 命令前会请求许可 Asks permission before running bash commands
非常适合探索不熟悉的代码库或规划更改 Ideal for exploring unfamiliar codebases or planning changes
此外，还包含一个 **general** 子智能体，用于复杂搜索和多步骤任务。 Also included is a **general** subagent for complex searches and multistep tasks.
该子智能体在内部使用，也可在消息中通过 `@general` 调用。 This is used internally and can be invoked using `@general` in messages.
