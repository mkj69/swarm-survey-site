OpenAI Agents SDKOpenAI Agents SDK
The OpenAI Agents SDK is a lightweight yet powerful framework for building multi-agent workflows. It is provider-agnostic, supporting the OpenAI Responses and Chat Completions APIs, as well as 100+ other LLMs.
OpenAI Agents SDK 是一个轻量但功能强大的框架，用于构建多智能体工作流。它不依赖特定提供商，支持 OpenAI Responses 和 Chat Completions API，以及 100+ 种其他大语言模型（LLM）。
> [!NOTE]
> [!NOTE]
> Looking for the JavaScript/TypeScript version? Check out [Agents SDK JS/TS](https://github.com/openai/openai-agents-js).
> 正在寻找 JavaScript/TypeScript 版本？请查看 [Agents SDK JS/TS](https://github.com/openai/openai-agents-js)。
Core concepts:核心概念：
[**Agents**](https://openai.github.io/openai-agents-python/agents): LLMs configured with instructions, tools, guardrails, and handoffs
[**智能体（Agents）**](https://openai.github.io/openai-agents-python/agents)：配置了指令、工具、护栏和任务交接机制的大语言模型
[**Sandbox agents**](https://openai.github.io/openai-agents-python/sandbox_agents): Agents preconfigured to work with a container to perform work over long time horizons.
[**沙箱智能体**](https://openai.github.io/openai-agents-python/sandbox_agents)：预先配置为与容器协同工作、可执行长时间跨度任务的智能体。
[**Realtime agents**](https://openai.github.io/openai-agents-python/realtime/quickstart/): Build powerful voice agents with `gpt-realtime-2.1` and full agent features
[**实时智能体**](https://openai.github.io/openai-agents-python/realtime/quickstart/)：利用 `gpt-realtime-2.1` 和完整的智能体功能构建强大的语音智能体
[**Voice agents**](https://openai.github.io/openai-agents-python/voice/quickstart/): Build voice pipelines that combine speech-to-text, an agent workflow, and text-to-speech
[**语音智能体**](https://openai.github.io/openai-agents-python/voice/quickstart/)：构建结合语音转文本、智能体工作流和文本转语音的语音处理流水线
**[Agents as tools](https://openai.github.io/openai-agents-python/tools/#agents-as-tools) / [Handoffs](https://openai.github.io/openai-agents-python/handoffs/)**: Delegating to other agents for specific tasks
**[将智能体用作工具](https://openai.github.io/openai-agents-python/tools/#agents-as-tools) / [任务交接（Handoffs）](https://openai.github.io/openai-agents-python/handoffs/)**：将特定任务委派给其他智能体
[**Tools**](https://openai.github.io/openai-agents-python/tools/): Various Tools let agents take actions (functions, MCP, hosted tools)
[**工具**](https://openai.github.io/openai-agents-python/tools/)：各种工具使智能体能够执行操作（函数、MCP、托管工具）
[**Guardrails**](https://openai.github.io/openai-agents-python/guardrails/): Configurable safety checks for input and output validation
[**护栏（Guardrails）**](https://openai.github.io/openai-agents-python/guardrails/)：用于验证输入和输出的可配置安全检查
[**Human in the loop**](https://openai.github.io/openai-agents-python/human_in_the_loop/): Built-in mechanisms for involving humans across agent runs
[**人在回路（Human in the loop）**](https://openai.github.io/openai-agents-python/human_in_the_loop/)：在智能体运行过程中引入人工参与的内置机制
[**Sessions**](https://openai.github.io/openai-agents-python/sessions/): Automatic conversation history management across agent runs
[**会话**](https://openai.github.io/openai-agents-python/sessions/)：在多次智能体运行之间自动管理对话历史
[**Tracing**](https://openai.github.io/openai-agents-python/tracing/): Built-in tracking of agent runs, allowing you to view, debug and optimize your workflows
[**追踪**](https://openai.github.io/openai-agents-python/tracing/)：内置的智能体运行追踪功能，可用于查看、调试和优化工作流
Explore the [examples](https://github.com/openai/openai-agents-python/tree/main/examples) directory to see the SDK in action, and read our [documentation](https://openai.github.io/openai-agents-python/) for more details.
浏览[示例](https://github.com/openai/openai-agents-python/tree/main/examples)目录，了解 SDK 的实际用法，并阅读我们的[文档](https://openai.github.io/openai-agents-python/)以获取更多详细信息。
Get started入门
To get started, set up your Python environment (Python 3.10 or newer required), and then install OpenAI Agents SDK package.
首先，配置 Python 环境（要求 Python 3.10 或更高版本），然后安装 OpenAI Agents SDK 软件包。
venvvenv
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install openai-agents
For voice support, install with the optional `voice` group: `pip install 'openai-agents[voice]'`. For Redis session support, install with the optional `redis` group: `pip install 'openai-agents[redis]'`.
如需语音支持，请安装可选的 `voice` 依赖组：`pip install 'openai-agents[voice]'`。如需 Redis 会话支持，请安装可选的 `redis` 依赖组：`pip install 'openai-agents[redis]'`。
uvuv
If you're familiar with [uv](https://docs.astral.sh/uv/), installing the package would be even easier:
如果你熟悉 [uv](https://docs.astral.sh/uv/)，安装该软件包会更加简单：
uv init
uv add openai-agents
For voice support, install with the optional `voice` group: `uv add 'openai-agents[voice]'`. For Redis session support, install with the optional `redis` group: `uv add 'openai-agents[redis]'`.
如需语音支持，请安装可选的 `voice` 依赖组：`uv add 'openai-agents[voice]'`。如需 Redis 会话支持，请安装可选的 `redis` 依赖组：`uv add 'openai-agents[redis]'`。
Run your first agents首次运行智能体
The SDK supports four primary ways to run agents. Set the `OPENAI_API_KEY` environment variable before running any of these examples.
该 SDK 支持四种主要的智能体运行方式。运行以下任一示例之前，请设置 `OPENAI_API_KEY` 环境变量。
Run a text agent运行文本智能体
Use a text `Agent` for workflows that do not need a persistent realtime connection or a sandbox workspace.
对于不需要持久实时连接或沙箱工作区的工作流，请使用文本 `Agent`。
from agents import Agent, Runner

agent = Agent(name="Assistant", instructions="You are a helpful assistant")

result = Runner.run_sync(agent, "Write a haiku about recursion in programming.")
print(result.final_output)

Run a sandbox agent运行沙箱智能体
Use a [`SandboxAgent`](https://openai.github.io/openai-agents-python/sandbox_agents) when the agent needs to inspect files, run commands, apply patches, or preserve workspace state across longer tasks.
当智能体需要检查文件、运行命令、应用补丁，或在较长任务的执行过程中保留工作区状态时，请使用 [`SandboxAgent`](https://openai.github.io/openai-agents-python/sandbox_agents)。
This example uses `UnixLocalSandboxClient`, which is supported on macOS and Linux. On Windows, use `DockerSandboxClient` with the `openai-agents[docker]` extra or a hosted sandbox client instead; see [Sandbox clients](https://openai.github.io/openai-agents-python/sandbox/clients/) for setup details.
此示例使用 `UnixLocalSandboxClient`，它支持 macOS 和 Linux。在 Windows 上，请使用安装了 `openai-agents[docker]` 可选依赖的 `DockerSandboxClient`，或改用托管沙箱客户端；设置详情请参阅[沙箱客户端](https://openai.github.io/openai-agents-python/sandbox/clients/)。
from agents import Runner
from agents.run import RunConfig
from agents.sandbox import Manifest, SandboxAgent, SandboxRunConfig
from agents.sandbox.entries import GitRepo
from agents.sandbox.sandboxes import UnixLocalSandboxClient

agent = SandboxAgent(
    name="Workspace Assistant",
    instructions="Inspect the sandbox workspace before answering.",
    default_manifest=Manifest(
        entries={"repo": GitRepo(repo="openai/openai-agents-python", ref="main")}
    ),
)

result = Runner.run_sync(
    agent,
    "Inspect the repo README and summarize what this project does.",
    run_config=RunConfig(sandbox=SandboxRunConfig(client=UnixLocalSandboxClient())),
)
print(result.final_output)
Run a realtime agent运行实时智能体
Use a [`RealtimeAgent`](https://openai.github.io/openai-agents-python/realtime/quickstart/) for low-latency, server-side voice and multimodal experiences over WebSocket.
如需通过 WebSocket 提供低延迟的服务端语音和多模态体验，请使用 [`RealtimeAgent`](https://openai.github.io/openai-agents-python/realtime/quickstart/)。
import asyncio
from agents.realtime import RealtimeAgent, RealtimeRunner


async def main() -> None:
    agent = RealtimeAgent(
        name="Assistant", instructions="You are a helpful voice assistant. Keep responses short."
    )
    runner = RealtimeRunner(starting_agent=agent)
    session = await runner.run()

    async with session:
        await session.send_message("Say hello in one short sentence.")
        async for event in session:
            if event.type == "audio":
                # Forward or play event.audio.data.
                pass
            elif event.type == "history_added":
                print(event.item)
            elif event.type == "agent_end":
                break


if __name__ == "__main__":
    asyncio.run(main())
Run a voice agent运行语音智能体
Use a [`VoicePipeline`](https://openai.github.io/openai-agents-python/voice/quickstart/) to turn audio into text, run an agent workflow, and stream generated speech.
使用 [`VoicePipeline`](https://openai.github.io/openai-agents-python/voice/quickstart/) 将音频转换为文本，运行智能体工作流，并以流式方式输出生成的语音。
import asyncio

import numpy as np

from agents import Agent
from agents.voice import AudioInput, SingleAgentVoiceWorkflow, VoicePipeline


async def main() -> None:
    agent = Agent(name="Assistant", instructions="You are a helpful voice assistant.")
    pipeline = VoicePipeline(workflow=SingleAgentVoiceWorkflow(agent))
    audio_input = AudioInput(buffer=np.zeros(24000 * 3, dtype=np.int16))

    result = await pipeline.run(audio_input)
    async for event in result.stream():
        if event.type == "voice_stream_event_audio":
            # Forward or play event.data.
            pass


if __name__ == "__main__":
    asyncio.run(main())
