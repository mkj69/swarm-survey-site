**变更内容：** **What changed:**
**单遍、仅执行 ADD 的提取** -- 一次 LLM 调用，不执行 UPDATE/DELETE。 **Single-pass ADD-only extraction** -- one LLM call, no UPDATE/DELETE. 记忆持续累积；任何内容都不会被覆盖。 Memories accumulate; nothing is overwritten.
**智能体生成的事实享有同等地位** -- 当智能体确认某项操作时，该信息现在会以同等权重存储。 **Agent-generated facts are first-class** -- when an agent confirms an action, that information is now stored with equal weight.
**实体链接** -- 提取实体、生成其嵌入表示，并跨记忆建立链接，以增强检索效果。 **Entity linking** -- entities are extracted, embedded, and linked across memories for retrieval boosting.
**多信号检索** -- 并行计算语义、BM25 关键词和实体匹配得分，并进行融合。 **Multi-signal retrieval** -- semantic, BM25 keyword, and entity matching scored in parallel and fused.
**时间推理** -- 具备时间感知能力的检索，针对有关当前状态、过去事件和未来计划的查询，将日期适切的实例排在前列。 **Temporal Reasoning** -- time-aware retrieval that ranks the right dated instance for queries about current state, past events, and upcoming plans.

基本用法Basic Usage
Mem0 需要大语言模型（LLM）才能运行，默认使用 OpenAI 的 `gpt-5-mini`。 Mem0 requires an LLM to function, with `gpt-5-mini` from OpenAI as the default. 不过，它支持多种 LLM；详情请参阅我们的[受支持的 LLM 文档](https://docs.mem0.ai/components/llms/overview)。 However, it supports a variety of LLMs; for details, refer to our [Supported LLMs documentation](https://docs.mem0.ai/components/llms/overview).
Mem0 默认使用 OpenAI 的 `text-embedding-3-small` 作为嵌入模型。 Mem0 uses `text-embedding-3-small` from OpenAI as the default embedding model. 为了使混合搜索（语义搜索 + 关键词搜索 + 实体加权）取得最佳效果，我们建议至少使用 [Qwen 600M](https://huggingface.co/Alibaba-NLP/gte-Qwen2-1.5B-instruct) 或同等水平的嵌入模型。 For best results with hybrid search (semantic + keyword + entity boosting), we recommend using at least [Qwen 600M](https://huggingface.co/Alibaba-NLP/gte-Qwen2-1.5B-instruct) or a comparable embedding model. 配置详情请参见[受支持的嵌入模型](https://docs.mem0.ai/components/embedders/overview)。 See [Supported Embeddings](https://docs.mem0.ai/components/embedders/overview) for configuration details.
第一步是实例化记忆： First step is to instantiate the memory: 
from openai import OpenAI
from mem0 import Memory

openai_client = OpenAI()
memory = Memory()

def chat_with_memories(message: str, user_id: str = "default_user") -> str:
    # Retrieve relevant memories
    relevant_memories = memory.search(query=message, filters={"user_id": user_id}, top_k=3)
    memories_str = "\n".join(f"- {entry['memory']}" for entry in relevant_memories["results"])

    # Generate Assistant response
    system_prompt = f"You are a helpful AI. Answer the question based on query and memories.\nUser Memories:\n{memories_str}"
    messages = [{"role": "system", "content": system_prompt}, {"role": "user", "content": message}]
    response = openai_client.chat.completions.create(model="gpt-5-mini", messages=messages)
    assistant_response = response.choices[0].message.content

    # Create new memories from the conversation
    messages.append({"role": "assistant", "content": assistant_response})
    memory.add(messages, user_id=user_id)

    return assistant_response

def main():
    print("Chat with AI (type 'exit' to quit)")
    while True:
        user_input = input("You: ").strip()
        if user_input.lower() == 'exit':
            print("Goodbye!")
            break
        print(f"AI: {chat_with_memories(user_input)}")

if __name__ == "__main__":
    main()
