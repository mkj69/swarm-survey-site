HumanLayerHumanLayer
HumanLayer 在你的机器上运行编程智能体（Claude Code、Codex、OpenCode、Pi），并让你的团队在一个统一入口中引导它们：任务、会话、计划和审查内容会在桌面应用、Web 应用以及每台主机上的守护进程之间同步。 HumanLayer runs coding agents (Claude Code, Codex, OpenCode, Pi) on your machines and lets your team steer them from one place: tasks, sessions, plans, and reviews, synced between a desktop app, a web app, and a daemon on each host.
此仓库包含上述全部内容。 This repo holds all of it. 这是一个使用 [Bun](https://bun.sh) 的 [Turborepo](https://turborepo.com) 单体仓库（monorepo）。 It's a [Turborepo](https://turborepo.com) monorepo that uses [Bun](https://bun.sh).
仓库内容What's here
`apps/riptide-ui`：应用界面，既作为 Web 应用运行，也运行于桌面应用外壳中 `apps/riptide-ui`: the app, as a web app and inside the desktop shells
`apps/riptide-electron`、`apps/riptide-native`：macOS 桌面应用（Electron、Tauri） `apps/riptide-electron`, `apps/riptide-native`: the macOS desktop apps (Electron, Tauri)
`apps/riptide-daemon`：在主机上运行智能体会话的守护进程 `apps/riptide-daemon`: the daemon that runs agent sessions on a host
`apps/cli`：`humanlayer` CLI，同时附带守护进程 `apps/cli`: the `humanlayer` CLI, which also ships the daemon
`apps/riptide-api`：oRPC + Hono API `apps/riptide-api`: the oRPC + Hono API
`apps/riptide-electric-proxy`：位于 [Electric](https://electric-sql.com) 前端的身份验证代理；Electric 将 Postgres 数据同步到客户端 `apps/riptide-electric-proxy`: the auth proxy in front of [Electric](https://electric-sql.com), which syncs Postgres to clients
`apps/riptide-cloud`：管理 Web 应用（组织、邀请、设置、安装页面） `apps/riptide-cloud`: the admin web app (organizations, invites, settings, install page)
`apps/riptide-migrator`、`apps/updater-server`、`apps/stale-daemon-sweeper`、`apps/database-maintenance-function`：AWS Lambda 作业 `apps/riptide-migrator`, `apps/updater-server`, `apps/stale-daemon-sweeper`, `apps/database-maintenance-function`: AWS Lambda jobs
`apps/riptide-claude-code-plugin`、`apps/riptide-opencode-plugin`、`apps/riptide-pi-extension`：将 Claude Code、OpenCode 和 Pi 会话镜像到 HumanLayer 的插件 `apps/riptide-claude-code-plugin`, `apps/riptide-opencode-plugin`, `apps/riptide-pi-extension`: plugins that mirror Claude Code, OpenCode, and Pi sessions into HumanLayer
`apps/riptide-humanlayer-claude-plugin`：内置的 HumanLayer 技能 `apps/riptide-humanlayer-claude-plugin`: the built-in HumanLayer skills
`apps/riptide-rpi-claude-plugin`、`apps/linear-cli`：Research-Plan-Implement 技能和 Linear CLI `apps/riptide-rpi-claude-plugin`, `apps/linear-cli`: the Research-Plan-Implement skills and the Linear CLI
`apps/docs`：用户文档 `apps/docs`: the user docs
`apps/devstack`：为每个工作树运行一套完整的本地技术栈 `apps/devstack`: runs a full local stack per worktree
`packages/`：共享库（`db`、`schemas`、`ui`、`sync`、`ai`、`billing`、...） `packages/`: shared libraries (`db`, `schemas`, `ui`, `sync`, `ai`, `billing`, ...)
`contracts/`：应用之间的 oRPC 和 Effect RPC 契约 `contracts/`: the oRPC and Effect RPC contracts between the apps
开始使用Get started
你需要安装 [Bun](https://bun.sh) 和 Docker。 You need [Bun](https://bun.sh) and Docker. 构建 `apps/riptide-native` 还需要 Rust。 Building `apps/riptide-native` also needs Rust. 
bun install
cp .env.example .env
bun --bun run typecheck
bun run test
`bun --bun run devstack help` 说明了如何在本地运行整套技术栈。 `bun --bun run devstack help` explains how to run the whole stack locally. [CONTRIBUTING.md](CONTRIBUTING.md) 列出了拉取请求必须通过的所有检查。 [CONTRIBUTING.md](CONTRIBUTING.md) lists every check a pull request must pass.
从源代码构建的版本不会向我们发送任何内容：Sentry、PostHog 和 WorkOS 客户端 ID 均通过环境变量配置，未设置时，相应功能保持关闭。`.env.example` 列出了这些配置项。 A build from source sends nothing to us: Sentry, PostHog, and the WorkOS client ID come from env, and stay off when unset. `.env.example` lists them.
